# Lesson 13 雙人複習手冊 (20分鐘)

:::info[📌 複習指南]
* **對應內容**：[Lesson #13 課堂筆記](../lessons/lesson-013.md) ｜ [課後作業](../homework/lesson-013.md)
* **進行方式**：一人選「**角色 A（引導者 / 出題官）**」，一人選「**角色 B（挑戰者 / 盲測）**」。**角色 B 完全不看題庫與答案**，全由角色 A 從題庫中**隨機挑選題目**引導發問；互換角色時，第二位出題官可**挑選不同題目**，避免背答案。
* **章節結構**：
  * **主線 20 分鐘版（Part 1～3）**：必練核心（超商旅遊句型、核心過去式變形、超商實戰對話）。
  * **Optional 延伸挑戰版**：獨立章節，涵蓋本課其餘重要內容（作息時間與一日時段、剩餘 10+ 生活動詞與連音、超商詞彙與味覺補充、作息關懷對話）。
:::

## 一、 旅遊句型抽測 (7 分鐘)

> **規則**：角色 A 唸中文引導提問（可自由跳題或隨機抽考），角色 B 不看題目、3 秒內說出韓語。完成後互換分頁重來一次。

> 💡 **引導方式**：依序或隨機挑題唸出中文情境給角色 B 聽，若對方卡住可給一個單字提示，確認發音與敬語後再下一題。

1. **「店員問客人：需要袋子嗎？」**  
   ➔ <KoreanAudio text="봉투 드릴까요?" /> **봉투 드릴까요?** *(口語亦可：`봉투 드려요?`)*
2. **「客人婉拒：不用，沒關係。直接這樣拿走就好。」**  
   ➔ <KoreanAudio text="아니요, 괜찮아요. 그냥 갈게요." /> **아니요, 괜찮아요. 그냥 갈게요.**

   ➔ <KoreanAudio text="냉장고 안에 어디에 있어요?" /> **냉장고 안에 어디에 있어요?** *(口語：`냉장고 안에 어디예요?`)*

   ➔ <KoreanAudio text="저쪽 안쪽에 있어요." /> **저쪽 안쪽에 있어요.**

## 二、 核心文法攻防 (7 分鐘)

> **規則**：角色 A 從題庫中隨機點名發球（唸原形或中文），角色 B 不看題庫秒答過去式或活用形。

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（引導者 / 題庫）" default>

> 💡 **引導方式**：從以下各區隨機挑 3～5 題發球，換邊時可挑不同的題目出題。

### 1. 核心動詞過去式接球（原形 ➔ 過去式）

| 考官發球 (原形) | 挑戰者回擊 (過去式) | 糾錯重點 |
| :--- | :--- | :--- |
| **보다** (看) | <KoreanAudio text="봤어요" /> **봤어요** | 陽性合流（非 `보았어요`） |
| **먹다** (吃) | <KoreanAudio text="먹었어요" /> **먹었어요** | 連音 `[머거써요]` |
| **자다** (睡) | <KoreanAudio text="잤어요" /> **잤어요** | 陽性合流（非 `자었어요`） |
| **마시다** (喝) | <KoreanAudio text="마셨어요" /> **마셨어요** | `ㅣ + ㅓ ➔ ㅕ` |
| **일하다** (工作) | <KoreanAudio text="일했어요" /> **일했어요** | `-하다 ➔ 했어요` `[이래써요]` |
| **쉬다** (休息) | <KoreanAudio text="쉬었어요" /> **쉬었어요** | 陰性母音接 `-었어요` |

### 2. 名詞時態對抗（唸中文給 B 翻）
* **「現在多少錢？」** ➔ <KoreanAudio text="얼마예요?" /> **얼마예요?** *(無收音 `-예요`)*
* **「那時多少錢？」** ➔ <KoreanAudio text="얼마였어요?" /> **얼마였어요?** *(無收音 `-였어요`)*
* **「昨天是星期天嗎？」** ➔ <KoreanAudio text="어제 일요일이었어요?" /> **어제 일요일이었어요?** *(有收音 `-이었어요` `[이료이리어써요]`)*

### 3. 味覺不規則形容詞（唸「原形 + 好～」，讓 B 講出「너무 + 現在式」）
* **쓰다** (苦 ➔ 好苦) ➔ <KoreanAudio text="너무 써요" /> **너무 써요** *(`ㅡ` 脫落)*
* **시다** (酸 ➔ 好酸) ➔ <KoreanAudio text="너무 셔요" /> **너무 셔요** *(`ㅣ + ㅓ ➔ ㅕ`)*
* **맵다** (辣 ➔ 好辣) ➔ <KoreanAudio text="너무 매워요" /> **너무 매워요** *(`ㅂ ➔ 우`)*

## 三、 超商實戰對話 (6 分鐘)

> **規則**：全韓語情境模擬，由角色 A（店員）主導對話節奏，角色 B（顧客）依中文任務卡臨場反應，**不能看韓文答案**。第一輪結束後互換分頁演第二次。

<Tabs>
<TabItem value="p3_role_a" label="🏪 角色 A：店員（알바생｜引導者）" default>

> 💡 **引導提醒**：你是超商店員，請用韓語主動推進結帳流程；如果顧客卡住，只給單字提示，不要直接唸出對方的整句韓文。

1. **主動迎賓**：<KoreanAudio text="안녕하세요!" /> **안녕하세요!**
2. **回應位置詢問** *(等顧客問草莓牛奶在哪裡)*：  
   ➔ <KoreanAudio text="저쪽 안쪽에 있어요." /> **저쪽 안쪽에 있어요.**  
   *(✅ 檢查 B 是否說出 `냉장고 안에 어디에 있어요?`)*
3. **結帳報價** *(假設顧客拿商品結帳，報價 5,000 韓元)*：  
   ➔ <KoreanAudio text="오천 원이에요." /> **오천 원이에요.**
4. **引導問袋子** *(逼出 B 的拒袋回答)*：  
   ➔ <KoreanAudio text="봉투 드릴까요?" /> **봉투 드릴까요?**  
   *(✅ 檢查 B 是否說出 `아니요, 괜찮아요. 그냥 갈게요.`)*
5. **回應加購** *(等 B 加購交通卡並問價，拿卡報價 4,000 韓元)*：  
   ➔ <KoreanAudio text="여기 있어요. 사천 원이에요." /> **여기 있어요. 사천 원이에요.**  
   *(✅ 檢查 B 是否用 `하나 주세요` 與 `얼마예요?`)*
6. **送客道別**：<KoreanAudio text="감사합니다. 안녕히 가세요!" /> **감사합니다. 안녕히 가세요!**

</TabItem>
<TabItem value="p3_role_b" label="🎒 角色 B：顧客（손님｜盲測任務卡）">

> 🎭 **角色任務卡（無答案版）**：請聽店員（角色 A）的引導，依序用韓語完成任務！

1. **進店**：用韓語跟店員打招呼。
2. **找飲料**：詢問「草莓牛奶（`딸기우유`）在冰箱裡面的哪裡？」
3. **結帳拒袋**：店員問要不要袋子時，委婉拒絕並說「直接這樣拿走就好」。
4. **加購交通卡**：跟店員買「一張交通卡（`교통카드`）」，並問多少錢。
5. **離店**：跟店員道謝並道別（注意：對留下來的店員要說 `안녕히 계세요!`）。

</TabItem>
</Tabs>
