## 一、 旅遊句型抽測 (7 分鐘)

> **規則**：考官唸中文，挑戰者 3 秒內說出韓語。完成後互換角色。

<Tabs>
<TabItem value="p1_role_a" label="👤 角色 A（考官 / 答案）" default>

1. **需要袋子嗎？**  
   ➔ <KoreanAudio text="봉투 드릴까요?" /> **봉투 드릴까요?**  
   *(重點：`-(으)ㄹ까요?` 徵詢敬語)*

2. **不用，沒關係。直接這樣拿走就好。**  
   ➔ <KoreanAudio text="아니요, 괜찮아요. 그냥 갈게요." /> **아니요, 괜찮아요. 그냥 갈게요.**  
   *(重點：口語慣用 `그냥 갈게요`)*

3. **請問在冰箱裡的哪裡？**  
   ➔ <KoreanAudio text="냉장고 안에 어디에 있어요?" /> **냉장고 안에 어디에 있어요?**  
   *(口語亦可：`냉장고 안에 어디예요?`)*

4. **在那個方向的內側。**  
   ➔ <KoreanAudio text="저쪽 안쪽에 있어요." /> **저쪽 안쪽에 있어요.**

5. **請給我一張交通卡。**  
   ➔ <KoreanAudio text="교통카드 하나 주세요." /> **교통카드 하나 주세요.**  
   *(重點：固有數詞 `하나`)*

6. **請問多少錢？**  
   ➔ <KoreanAudio text="얼마예요?" /> **얼마예요?**

3. **詢問位置**：「請問在冰箱裡的哪裡？」
4. **店員指引**：「在那個方向的內側。」
5. **櫃檯加購**：「請給我一張交通卡。」

## 二、 核心文法攻防 (7 分鐘)

> **規則**：考官發球出題，挑戰者秒答過去式或口語變化。

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（考官 / 答案）" default>

### 1. 動詞過去式接球（原形 ➔ 過去式）

| 考官發球 (原形) | 挑戰者回擊 (過去式) | 糾錯重點 |
| :--- | :--- | :--- |
| **보다** (看) | <KoreanAudio text="봤어요" /> **봤어요** | 陽性合流（非 `보았어요`） |
| **먹다** (吃) | <KoreanAudio text="먹었어요" /> **먹었어요** | 連音 `[머거써요]` |
| **자다** (睡) | <KoreanAudio text="잤어요" /> **잤어요** | 陽性合流（非 `자었어요`） |
| **마시다** (喝) | <KoreanAudio text="마셨어요" /> **마셨어요** | `ㅣ + ㅓ ➔ ㅕ` |
| **일하다** (工作) | <KoreanAudio text="일했어요" /> **일했어요** | `-하다 ➔ 했어요`，連音 `[이래써요]` |
| **쉬다** (休息) | <KoreanAudio text="쉬었어요" /> **쉬었어요** | 陰性母音接 `-었어요` |

### 2. 名詞時態對抗

* 「**現在多少錢？**」 ➔ <KoreanAudio text="얼마예요?" /> **얼마예요?**
* 「**那時多少錢？**」 ➔ <KoreanAudio text="얼마였어요?" /> **얼마였어요?** *(無收音 + 였어요)*
* 「**昨天是星期天嗎？**」 ➔ <KoreanAudio text="어제 일요일이었어요?" /> **어제 일요일이었어요?** *(有收音 + 이었어요，連音 [이료이리어써요])*

### 3. 味覺不規則形容詞（原形 ➔ 現在式）

* **쓰다** (苦) ➔ <KoreanAudio text="너무 써요" /> **너무 써요** *(ㅡ 脫落)*
* **시다** (酸) ➔ <KoreanAudio text="너무 셔요" /> **너무 셔요** *(ㅣ + ㅓ ➔ ㅕ)*
* **맵다** (辣) ➔ <KoreanAudio text="너무 매워요" /> **너무 매워요** *(ㅂ ➔ 우)*

## 三、 超商實戰對話 (6 分鐘)

> **規則**：不看劇本、全韓語模擬。第一輪 A 店員 / B 客人；第二輪互換。

<Tabs>
<TabItem value="p3_role_a" label="🏪 店員（알바생）" default>

1. **問候**：<KoreanAudio text="안녕하세요!" /> **안녕하세요!**
2. **指引位置**（客人問草莓牛奶）：  
   ➔ <KoreanAudio text="저쪽 안쪽에 있어요." /> **저쪽 안쪽에 있어요.**
3. **結帳報價**（5,000 韓元）：  
   ➔ <KoreanAudio text="오천 원이에요." /> **오천 원이에요.**
4. **詢問袋子**：  
   ➔ <KoreanAudio text="봉투 드릴까요?" /> **봉투 드릴까요?**
5. **加購交通卡**（拿卡並報價 4,000 韓元）：  
   ➔ <KoreanAudio text="여기 있어요. 사천 원이에요." /> **여기 있어요. 사천 원이에요.**
6. **送客**：<KoreanAudio text="감사합니다. 안녕히 가세요!" /> **감사합니다. 안녕히 가세요!**

</TabItem>
<TabItem value="p3_role_b" label="🎒 顧客（손님）">

1. **打招呼**：`안녕하세요!`
2. **詢問位置**：草莓牛奶在冰箱哪裡？  
   *(提示：딸기우유 + 냉장고 안에 어디에 있어요?)*
3. **委婉拒袋**：不用，沒關係。直接這樣拿走就好。  
   *(提示：아니요, 괜찮아요. 그냥 갈게요.)*
4. **加購問價**：請給我一張交通卡，多少錢？  
   *(提示：교통카드 하나 주세요. 얼마예요?)*
5. **道謝離店**：`감사합니다. 안녕히 계세요!`

</TabItem>
</Tabs>
