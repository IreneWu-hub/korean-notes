## 一、 旅遊句型抽測 (7 分鐘)

> **規則**：考官唸中文，挑戰者 3 秒內說出韓語。完成後互換角色。

<Tabs>
<TabItem value="p1_role_a" label="👤 角色 A（考官 / 答案）" default>

1. **請問有在找什麼款式嗎？**  
   ➔ <KoreanAudio text="찾으시는 거 있으세요?" /> **찾으시는 거 있으세요?**  
   *(重點：`찾으시다` 敬語 + `-는 거 있으세요?`)*

2. **不用了，沒關係。我先自己看一下就好。**  
   ➔ <KoreanAudio text="아니요, 괜찮아요. 좀 볼게요." /> **아니요, 괜찮아요. 좀 볼게요.**  
   *(重點：自由行解圍神句 `좀 볼게요`)*

3. **這個可以試穿看看嗎？**  
   ➔ <KoreanAudio text="이거 입어 봐도 돼요?" /> **이거 입어 봐도 돼요?**  
   *(重點：`입다` + `-아/어 보다` 嘗試 + `-어도 되다` 徵詢許可)*

4. **好的，請到那邊的試衣間試穿。**  
   ➔ <KoreanAudio text="네, 저쪽 피팅룸에서 입어보세요." /> **네, 저쪽 피팅룸에서 입어보세요.**  
   *(重點：`피팅룸` Fitting room + `-에서` + `입어보세요`)*

5. **請問有其他的顏色嗎？**  
   ➔ <KoreanAudio text="혹시 다른 색깔 있어요?" /> **혹시 다른 색깔 있어요?**  
   *(重點：`혹시` 委婉開頭 + `다른` + `색깔` 顏色)*

6. **請給我比目魚和石斑魚各半！**  
   ➔ <KoreanAudio text="광어 우럭 반반 주세요!" /> **광어 우럭 반반 주세요!**  
   *(重點：水產市場內行必點組合 `광어` 比目魚 + `우럭` 石斑魚)*

7. **老闆，請再給我一點紫蘇葉！**  
   ➔ <KoreanAudio text="사장님, 깻잎 좀 더 주세요!" /> **사장님, 깻잎 좀 더 주세요!**  
   *(重點：`깻잎` 實際發音 `[깬닙]`，絕不可唸成 `[깨십]`)*

## 二、 核心文法攻防 (7 分鐘)

> **規則**：考官發球出題，挑戰者秒答冠形詞修飾、ㄹ 脫落或正確穿戴動詞。

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（考官 / 答案）" default>

### 1. 形容詞＆動詞修飾名詞（注意 `ㄹ` 遇 `ㅅ, ㄴ, ㅂ, 으` 必定脫落！）
| 考官發球 (原形 / 目標) | 挑戰者回擊 (答案) | 糾錯重點 |
| :--- | :--- | :--- |
| **크다** + 옷 (大衣服) | <KoreanAudio text="큰 옷" /> **큰 옷** | 無收音 + ㄴ |
| **작다** + 옷 (小衣服) | <KoreanAudio text="작은 옷" /> **작은 옷** | 有收音 + 은 |
| **길다** + 바지 (長褲) | <KoreanAudio text="긴바지" /> **긴바지** | ⚠️ **ㄹ 脫落**補 ㄴ（非 길은 바지） |
| **짧다** + 치마 (短裙) | <KoreanAudio text="짧은 치마" /> **짧은 치마** | 雙收音保留 + 은 |
| **팔다** ➔ 市場賣的東西 | <KoreanAudio text="시장에서 파는 것" /> **시장에서 파는 것** | ⚠️ 遇 ㄴ 語尾，**ㄹ 必脫落** |
| **만들다** ➔ 媽媽做的料理 | <KoreanAudio text="엄마가 만드는 요리" /> **엄마가 만드는 요리** | ⚠️ 遇 ㄴ 語尾，**ㄹ 必脫落** |
| **살다** ➔ 請住 / 尊敬型 (`-(으)세요`) | <KoreanAudio text="사세요" /> **사세요** | ⚠️ 遇 ㅅ 語尾，**ㄹ 必脫落**（非 살으세요） |
| **알다** ➔ 知道 (`-ㅂ니다` / `-(으)니까`) | <KoreanAudio text="압니다, 아니까" /> **압니다 / 아니까** | ⚠️ 遇 ㅂ、으 語尾，**ㄹ 必脫落** |

### 2. 穿戴動詞 8 大區分快考
| 考官發球 (中文配件) | 挑戰者回擊 (韓語名詞 + 動詞) | 身體部位 / 穿戴方式 |
| :--- | :--- | :--- |
| **穿大衣** | <KoreanAudio text="코트를 입어요" /> **코트를 입어요** | 軀幹服飾 (`입다`) |
| **穿運動鞋** | <KoreanAudio text="운동화를 신어요" /> **운동화를 신어요** | 腳部鞋襪 (`신다`) |
| **戴太陽眼鏡 / 帽子** | <KoreanAudio text="선글라스를 써요" /> **선글라스/모자를 써요** | 頭部覆蓋 (`쓰다`) |
| **戴戒指 / 隱形眼鏡** | <KoreanAudio text="반지를 껴요" /> **반지/렌즈를 껴요** | 套進、夾住 (`끼다`) |
| **戴手錶** | <KoreanAudio text="손목시계를 차요" /> **손목시계를 차요** | 扣在手腕 (`차다`) |
| **繫領帶** | <KoreanAudio text="넥타이를 매요" /> **넥타이를 매요** | 打結繫緊 (`매다`) |
| **背雙肩包** | <KoreanAudio text="배낭을 메요" /> **배낭/백팩을 메요** | 肩背扛起 (`메다`) |
| **戴耳環 / 項鍊** | <KoreanAudio text="귀고리를 해요" /> **귀고리/목걸이를 해요** | 飾品統稱 (`하다`) |

## 結算 (1 分鐘)

* **糾錯確認**：
  * **ㄹ 不規則脫落**：遇到「ㅅ, ㄴ, ㅂ, 으」時，收音「ㄹ」必定脫落！（`긴바지`, `파는 것`, `사세요`, `압니다 / 아니까`）。
  * **穿戴動詞**：鞋襪 `신다`、帽眼鏡 `쓰다`、戒指 `끼다`、手錶 `차다`、領帶 `매다`、背包 `메다`、耳環項鍊 `하다`。
  * **깻잎 [깬닙] 音變**：代表音 `[깯]` ➔ ㄴ添加 `[깯닙]` ➔ 鼻音化 `[깬닙]`。
