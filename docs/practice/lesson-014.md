## 一、 旅遊句型抽測 (7 分鐘)

> **規則**：考官唸中文，挑戰者 3 秒內說出韓語。完成後互換角色。

<Tabs>
<TabItem value="p1_role_a" label="👤 角色 A（考官 / 答案）" default>

1. **請問想找什麼樣的款式呢？ / 有在找什麼款式嗎？**  
   ➔ <KoreanAudio text="찾으시는 거 있으세요?" /> **찾으시는 거 있으세요?**  
   *(重點：`찾으시다` 敬語 + `-는 거 있으세요?`)*

2. **不用了，沒關係。我先自己看一下就好。**  
   ➔ <KoreanAudio text="아니요, 괜찮아요. 좀 볼게요." /> **아니요, 괜찮아요. 좀 볼게요.**  
   *(重點：自由行解圍神句 `좀 볼게요`)*

3. **這個可以試穿看看嗎？**  
   ➔ <KoreanAudio text="이거 입어 봐도 돼요?" /> **이거 입어 봐도 돼요?**  
   *(重點：`입다` 穿 + `-아/어 보다` 嘗試 + `-어도 되다` 徵詢許可)*

4. **好的，請到那邊的試衣間試穿。**  
   ➔ <KoreanAudio text="네, 저쪽 피팅룸에서 입어보세요." /> **네, 저쪽 피팅룸에서 입어보세요.**  
   *(重點：`피팅룸` Fitting room + `-에서` + `입어보세요`)*

5. **請問有其他的顏色嗎？**  
   ➔ <KoreanAudio text="혹시 다른 색깔 있어요?" /> **혹시 다른 색깔 있어요?**  
   *(重點：`혹시` 委婉客氣 + `다른` 冠形詞修飾 + `색깔` 顏色)*

6. **老闆，請再給我一點紫蘇葉！**  
   ➔ <KoreanAudio text="사장님, 깻잎 좀 더 주세요!" /> **사장님, 깻잎 좀 더 주세요!**  
   *(重點：`깻잎` 實際發音為 `[깬닙]`，烤肉加菜必備金句)*

## 二、 核心文法攻防 (7 分鐘)

> **規則**：考官發球出題，挑戰者秒答變形或修飾。

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（考官 / 答案）" default>

### 1. 形容詞修飾名詞（語幹 + -(으)ㄴ）
| 考官發球 (形容詞原形 + 名詞) | 挑戰者回擊 (冠形詞修飾) | 糾錯重點 |
| :--- | :--- | :--- |
| **크다** (大) + 옷 (衣服) | <KoreanAudio text="큰 옷" /> **큰 옷** | 無收音 + ㄴ |
| **작다** (小) + 옷 (衣服) | <KoreanAudio text="작은 옷" /> **작은 옷** | 有收音 + 은 |
| **길다** (長) + 바지 (褲子) | <KoreanAudio text="긴바지" /> **긴바지** | ⚠️ **ㄹ 脫落**補 ㄴ（非 길은 바지） |
| **길다** (長) + 치마 (裙子) | <KoreanAudio text="긴치마" /> **긴치마** | ⚠️ **ㄹ 脫落**補 ㄴ |

### 2. 動詞修飾現在式 & 「ㄹ 遇 ㅅ, ㄴ, ㅂ, 으 必定脫落」黃金口訣
| 考官發球 (動詞原形) | 挑戰者回擊 (目標型態) | 糾錯重點 |
| :--- | :--- | :--- |
| **먹다** (吃) ➔ 修飾「吃的東西」 | <KoreanAudio text="먹는 것" /> **먹는 것** | 一般動詞 + -는 것 |
| **팔다** (賣) ➔ 修飾「在市場賣的東西」 | <KoreanAudio text="시장에서 파는 것" /> **시장에서 파는 것** | ⚠️ 遇 ㄴ 語尾，**ㄹ 必脫落**（非 파는 것 帶 ㄹ） |
| **만들다** (製作) ➔ 修飾「製作的東西」 | <KoreanAudio text="만드는 것" /> **만드는 것** | ⚠️ 遇 ㄴ 語尾，**ㄹ 必脫落** |
| **살다** (居住) ➔ 請住 / 尊敬型 (遇 -세요) | <KoreanAudio text="사세요" /> **사세요** | ⚠️ 遇 ㅅ 語尾，**ㄹ 必脫落**（非 살으세요） |
| **알다** (知道) ➔ 最高敬語陳述 (遇 -ㅂ니다) | <KoreanAudio text="압니다" /> **압니다** | ⚠️ 遇 ㅂ 語尾，**ㄹ 必脫落**（非 알습니다） |
| **알다** (知道) ➔ 因為知道 (遇 -(으)니까) | <KoreanAudio text="아니까" /> **아니까** | ⚠️ 遇 으 語尾，**ㄹ 與 으 皆脫落** |

### 3. 市場食材與發音快問快答
* **頭足類三兄弟**：
  - 10 隻腳烏賊/魷魚 ➔ <KoreanAudio text="오징어" /> **오징어**
  - 祭祀慶典大章魚 ➔ <KoreanAudio text="문어" /> **문어**
  - 辣炒/生吃長爪小章魚 ➔ <KoreanAudio text="낙지" /> **낙지**
* **生魚片必點套餐**：
  - 「請給我比目魚和石斑魚各半」 ➔ <KoreanAudio text="광어 우럭 반반 주세요" /> **광어 우럭 반반 주세요**
* **音變大考驗**：
  - 紫蘇葉（`깻잎`）的實際正確讀音？ ➔ <KoreanAudio text="깻잎" /> **[깬닙]**  
    *(代表音 [깯] ➔ ㄴ添加 [깯닙] ➔ 鼻音化 [깬닙])*

## 三、 情境實戰對話 (6 分鐘)

> **規則**：不看劇本、全韓語模擬。第一輪 A 店員 / B 顧客；第二輪互換角色。

<Tabs>
<TabItem value="p3_role_a" label="🏪 角色 1：服飾店員（직원）" default>

1. **主動招呼問候**：  
   ➔ <KoreanAudio text="안녕하세요! 찾으시는 거 있으세요?" /> **안녕하세요! 찾으시는 거 있으세요?**
2. **客人想自己逛，親切退回櫃檯**：  
   ➔ <KoreanAudio text="네, 편하게 보세요." /> **네, 편하게 보세요.**
3. **客人拿衣服詢問試穿，指引試衣間**：  
   ➔ <KoreanAudio text="네, 저쪽 피팅룸에서 입어보세요." /> **네, 저쪽 피팅룸에서 입어보세요.**
4. **客人詢問其他顏色（告知有黑色與米色）**：  
   ➔ <KoreanAudio text="네, 블랙이랑 베이지도 있어요." /> **네, 블랙이랑 베이지도 있어요.**
5. **客人決定購買黑色款，報價結帳（35,000 韓元）**：  
   ➔ <KoreanAudio text="삼만 오천 원이에요." /> **삼만 오천 원이에요.**
6. **雙手交遞商品並禮貌送客**：  
   ➔ <KoreanAudio text="감사합니다. 또 오세요!" /> **감사합니다. 또 오세요!**

</TabItem>
<TabItem value="p3_role_b" label="🎒 角色 2：逛街顧客（손님）">

> 💡 **任務卡（無劇本盲測）**：用全韓語完成弘大服飾店購物挑戰！

1. **被店員熱情招呼時**：使用解圍金句親切婉拒（「不用了，沒關係。我先自己看一下就好。」）。
2. **看中一件漂亮的洋裝或長褲**：拿到店員面前詢問能否試穿（「這個可以試穿看看嗎？」）。
3. **試穿合身後**：詢問店員有沒有別的顏色（「請問有其他的顏色嗎？」）。
4. **決定選黑色並詢問總價**：告知店員要黑色一件並問多少錢（「請給我黑色的。請問多少錢？」）。
5. **聽取店員報價（35,000 韓元）**：完成付款並禮貌道謝道別。

</TabItem>
</Tabs>

## 結算 (1 分鐘)

* **糾錯確認**：
  * **ㄹ 不規則脫落**：遇到「ㅅ, ㄴ, ㅂ, 으」時，收音「ㄹ」必定脫落！如 `길다 ➔ 긴바지`, `팔다 ➔ 파는 것`, `살다 ➔ 사세요`, `알다 ➔ 압니다 / 아니까`。
  * **깻잎 [깬닙] 音變**：三段式轉化（代表音 [깯] ➔ ㄴ添加 [깯닙] ➔ 鼻音化 [깬닙]），絕不可發成 [깨십]！
  * **좀 볼게요**：走進韓國服飾店不想被緊迫盯人的必備禮貌防護罩。
