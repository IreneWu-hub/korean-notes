# Lesson 14 雙人複習手冊

:::info[📌 複習指南]
* **對應內容**：[Lesson #14 課堂筆記](../lessons/lesson-014.md) ｜ [課後作業](../homework/lesson-014.md)
* **進行方式**：一人選「**角色 A（考官 / 引導者）**」，一人選「**角色 B（挑戰者 / 盲測）**」。**角色 B 完全不看韓文答案**，由角色 A 隨機挑題抽考；換邊時改由對方出沒考過的題目。
* **本課策略**：以**「TOPIK 檢定高頻單字抽考」**為主軸，搭配核心文法（冠形詞修飾、`ㄹ` 脫落）與逛街試穿會話；少用詞彙先不納入，內容嚴格不超出本課範圍。
:::

### B. 服飾店實戰對話 (4 分鐘)

<Tabs>
<TabItem value="p3b_role_a" label="🏪 角色 A：服飾店員（직원｜引導者）" default>

> 💡 **引導提醒**：依序推進 1～6 步對話，檢查角色 B 是否有使用本課句型應答。

1. **主動招呼**：<KoreanAudio text="찾으시는 거 있으세요?" /> **찾으시는 거 있으세요?**
2. **等待客人婉拒** *(✅ 檢查 B 是否說出 `아니요, 괜찮아요. 좀 볼게요.`)*
3. **等待客人詢問試穿** *(✅ 檢查 B 是否說出 `이거 입어 봐도 돼요?`)*
4. **指引試衣間**：<KoreanAudio text="네, 저쪽 피팅룸에서 입어보세요." /> **네, 저쪽 피팅룸에서 입어보세요.**
5. **等待客人詢問其他顏色** *(✅ 檢查 B 是否說出 `혹시 다른 색깔 있어요?`)*
6. **告知現有顏色**：<KoreanAudio text="네, 블랙이랑 베이지도 있어요." /> **네, 블랙이랑 베이지도 있어요.**

<TabItem value="p3b_role_b" label="🎒 角色 B：逛街顧客（손님｜盲測任務卡）">

> 🎭 **角色任務卡（無答案版）**：聽店員（角色 A）的引導，依序完成 1～6 步對話！

1. **聽店員招呼**：聽懂店員問你「有在找什麼嗎？」
2. **婉拒解圍**：親切婉拒，表示「不用了，沒關係，我先自己看一下就好」。
3. **請求試穿**：拿著衣服問店員「這個可以試穿看看嗎？」
4. **聽店員指引**：聽懂店員請你去那邊的試衣間試穿。
5. **詢問其他顏色**：試穿完畢，委婉詢問「請問有其他的顏色嗎？」
6. **確認顏色**：聽懂店員告訴你有哪兩種顏色（提示：外來語顏色名稱）。
