## 一、 旅遊句型抽測 (7 分鐘)

> **規則**：考官唸中文，挑戰者 3 秒內說出韓語。完成後互換角色。

<Tabs>
<TabItem value="p1_role_a" label="👤 角色 A（考官 / 答案）" default>

1. **請問這是什麼？（手指眼前的食物）**  
   ➔ <KoreanAudio text="이게 뭐예요?" /> **이게 뭐예요?**  
   *(重點：口語主格縮寫 `이게 = 이것이`)*

2. **請給我一份蔥煎餅。**  
   ➔ <KoreanAudio text="파전 하나 주세요." /> **파전 하나 주세요.**  
   *(重點：數量詞使用固有數詞 `하나`)*

3. **在這裡吃。（吃完再走）**  
   ➔ <KoreanAudio text="여기에서 먹고 갈게요." /> **여기에서 먹고 갈게요.**  
   *(重點：最道地內用表達 `~고 가다 吃完再走`；口語亦可縮為 `여기서 먹고 갈게요`)*

4. **請問也可以刷卡嗎？**  
   ➔ <KoreanAudio text="카드도 되나요?" /> **카드도 되나요?**  
   *(重點：疑問語尾 `-나요?` 最親切婉轉；日常口語亦可用 `카드도 돼요?`)*

5. **您可以試穿一次看看喔。**  
   ➔ <KoreanAudio text="한 번 입어 보셔도 돼요." /> **한 번 입어 보셔도 돼요.**  
   *(重點：`-아/어 보다 嘗試` + `-도 되다 許可`)*

6. **那我考慮看看。（委婉婉拒）**  
   ➔ <KoreanAudio text="그럼 생각해볼게요." /> **그럼 생각해볼게요.**  
   *(口語亦常用：`좀 더 볼게요 我再多逛逛/看看`)*

## 二、 核心文法攻防 (7 分鐘)

> **規則**：考官發球出題，挑戰者秒答縮寫、文法差異與正確數詞。

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（考官 / 答案）" default>

### 1. 指示詞口語縮寫接球

| 考官發球 (視角與助詞) | 挑戰者回擊 (口語縮寫) | 糾錯重點 |
| :--- | :--- | :--- |
| **這（主格，這件事/眼前物）** | <KoreanAudio text="이게" /> **이게** | 이것이 ➔ 이게 (`이게 뭐예요?`) |
| **那（受格，請給我那個靠近你的）** | <KoreanAudio text="그거" /> **그거** | 그것을 ➔ 그거 (`그거 주세요`) |
| **那邊遠處（主題，那邊那個多少錢）** | <KoreanAudio text="저건" /> **저건** | 저것은 ➔ 저건 (`저건 얼마예요?`) |
| **場所代名詞（在這裡 / 在那邊遠處）** | <KoreanAudio text="여기 / 저기" /> **여기 / 저기** | 이곳 ➔ 여기, 저곳 ➔ 저기 |

### 2. 限定文法攻防 (`~만` vs `~밖에`)

* 「**只剩下這一個。**（客觀陳述事實）」  
  ➔ <KoreanAudio text="이거 하나만 남았어요." /> **이거 하나만 남았어요.** *(名詞 + 만 + 肯定句)*
* 「**除了這一個之外別無選擇。**（強烈限定與無奈語氣）」  
  ➔ <KoreanAudio text="이거 하나밖에 없어요." /> **이거 하나밖에 없어요.** *(名詞 + 밖에 + 固定接否定句 없어요)*

### 3. 推測語尾對抗 (`-아/어 보여요` vs `-겠다`)

* 「**你看起來很疲倦。**（外表視覺感官觀察）」  
  ➔ <KoreanAudio text="피곤해 보여요." /> **피곤해 보여요.** *(形容詞 + -아/어 보이다)*
* 「**哇！一定很好吃！**（看美食照片直覺共鳴感嘆）」  
  ➔ <KoreanAudio text="맛있겠다!" /> **맛있겠다!** *(形容詞 + -겠다)*

### 4. 數量與時間陷阱接球

* 「**花了 2 個小時。**」  
  ➔ <KoreanAudio text="두 시간 걸렸어요." /> **두 시간 걸렸어요.** *(時間量詞時間必須使用固有數詞 둘 ➔ 두，❌ 切勿講成 이시간)*
* 「**旅行了 5 天。**（請說出漢字數詞與固有天數詞兩種）」  
  ➔ <KoreanAudio text="5일 동안 여행했어요." /> **5일 [오일] 동안 여행했어요.** ｜ <KoreanAudio text="닷새 동안 여행했어요." /> **닷새 동안 여행했어요.** *(1天: 하루, 2天: 이틀, 3天: 사흘, 4天: 나흘, 5天: 닷새)*

## 三、 市場實戰對話 (6 分鐘)

> **規則**：不看劇本、全韓語模擬。第一輪 A 老闆 / B 顧客；第二輪互換。

<Tabs>
<TabItem value="p3_role_a" label="🏪 老闆（사장님）" default>

1. **問候招呼**：<KoreanAudio text="어서 오세요! 뭐 드릴까요?" /> **어서 오세요! 뭐 드릴까요?**  
   *(歡迎光臨！要給您什麼？)*
2. **回答菜名**（客人指眼前食物問 이게 뭐예요?）：  
   ➔ <KoreanAudio text="그건 순대예요." /> **그건 순대예요.**  
   *(那是血腸。)*
3. **報價**（客人指遠處展示台問 저건 얼마예요?）：  
   ➔ <KoreanAudio text="오천 원이에요." /> **오천 원이에요.**  
   *(5,000 韓元。連音發音：[오처눠nieyo])*
4. **詢問用餐方式**（客人點一份蔥煎餅 파전 하나 주세요）：  
   ➔ <KoreanAudio text="드시고 가세요, 포장해 드릴까요?" /> **드시고 가세요, 포장해 드릴까요?**  
   *(要在這裡吃，還是幫您外帶打包呢？)*
5. **回答付款**（客人問 카드도 되나요?）：  
   ➔ <KoreanAudio text="네, 돼요! 맛있게 드세요." /> **네, 돼요! 맛있게 드세요.**  
   *(可以刷卡！請慢用。若只收現金則答：죄송해요, 현금만 돼요.)*

</TabItem>
<TabItem value="p3_role_b" label="🎒 觀光客（손님）">

1. **看攤位發問**：「請問這是什麼？」（手指眼前食物）  
   *(提示：이게 뭐예요?)*
2. **詢問遠處價格**：「請問那邊那個多少錢？」  
   *(提示：저건 얼마예요?)*
3. **反應價格並點餐**：「有點貴呢。請給我一份蔥煎餅。」  
   *(提示：조금 비싸요. 파전 하나 주세요.)*
4. **交代內用**：「在這裡吃（吃完再走）。」  
   *(提示：여기에서 먹고 갈게요.)*
5. **禮貌詢問刷卡**：「請問也可以刷卡嗎？」  
   *(提示：카드도 되나요?)*

</TabItem>
</Tabs>

## 結算 (1 分鐘)

* **糾錯確認**：
  * `5,000원이에요` 連音是否唸對（`[오천원이에요 ➔ 오처눠nieyo]`）？
  * 時間「小時」量詞單位是否牢記使用固有數詞（`두 시간` ❌ 非 `이시간`）？
  * 內用表達是否能直覺脫口而出 `여기에서 먹고 갈게요`？
  * 限定詞 `-밖에` 後方是否牢記固定接否定句 `없어요`？
