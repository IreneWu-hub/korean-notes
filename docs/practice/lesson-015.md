## 二、 核心文法攻防：`에` vs `에서` & `시키다` 陷阱 (7 分鐘)

> **規則**：角色 A 唸中文句子（可隨機跳題抽考），角色 B 在 3 秒內完整說出韓語句子。特別檢查場所助詞與連音！

<Tabs>
<TabItem value="p2_role_a" label="👤 角色 A（考官 / 答案）" default>

> 💡 **引導提醒**：口訣確認——「去／來／在 (`가다/오다/있다`)」用 **`에`**；「在某地做動作」用 **`에서`**！

| 題目 (中文) | 韓語答案 & 糾錯重點 |
| :--- | :--- |
| **1. 我去學校。** | <KoreanAudio text="학교에 가요." /> **학교에 가요.** *(移動方向用 `에`)* |
| **2. 人在教室裡。** | <KoreanAudio text="교실에 있어요." /> **교실에 있어요.** *(靜態存在用 `에`)* |
| **3. 來到我們班。** | <KoreanAudio text="우리 반에 와요." /> **우리 반에 와요.** *(朝我方過來用 `오다`)* |
| **4. 在瑜珈教室做瑜珈。** | <KoreanAudio text="요가 교실에서 요가해요." /> **요가 교실에서 요가해요.** *(動作地點改用 `에서`)* |
| **5. 在書店買鉛筆。** | <KoreanAudio text="서점에서 연필을 사요." /> **서점에서 연필을 사요.** *(亦可：`책방에서`)* |
| **6. 今天買衣服。** | <KoreanAudio text="오늘 옷을 사요." /> **오늘 옷을 사요.** *(⚠️ 連音 `옷을 [오슬]`)* |
| **7. 上韓語課。** | <KoreanAudio text="한국어 수업을 들어요." /> **한국어 수업을 들어요.** *(⚠️ `듣다 ➔ 들어요`)* |
| **8. 聽音樂。** | <KoreanAudio text="음악을 들어요." /> **음악을 들어요.** *(⚠️ 連音 `[으마글]`)* |
| **9. 我跟小狗一起散步。** | <KoreanAudio text="강아지하고 산책해요." /> **강아지하고 산책해요.** *(亦可：`강아지랑`)* |
| **10. 我遛狗（讓小狗散步）。** | <KoreanAudio text="강아지를 산책 시켜요." /> **강아지를 산책 시켜요.** *(受詞 `를` + 使役 `시키다`)* |
| **11. 吃了好吃的東西。** | <KoreanAudio text="맛있는 걸 먹었어요." /> **맛있는 걸 먹었어요.** *(口語縮寫 `것을 ➔ 걸`)* |
| **12. 不好意思，請幫我們拍張照！** | <KoreanAudio text="저기요, 사진 좀 찍어 주세요!" /> **저기요, 사진 좀 찍어 주세요!** *(禮貌請求 `-어 주세요`)* |

## 三、 明洞出遊實戰對話 (7 分鐘)

> **規則**：全韓語情境模擬，由角色 A 主導問句推進，角色 B 依中文任務卡臨場反應。第一輪結束後互換角色。

<Tabs>
<TabItem value="p3_role_a" label="🗣️ 角色 A：揪團好友（引導者）" default>

> 💡 **引導提醒**：依序推進 1～6 步對話；若夥伴卡住，只給單一個中文或名詞提示，檢查對方是否正確運用過去式、`하고`、`에서` 與拍照請求句。

1. **寒暄開場（問昨天作息）**：<KoreanAudio text="어제 뭐 했어요?" /> **어제 뭐 했어요?**
2. **等待夥伴回答昨天做了什麼** *(✅ 檢查 B 是否使用過去式與 `그리고`，如 `친구를 만났어요. 그리고 쉬었어요.` 或 `집에서 한국어를 공부했어요. 맛있는 걸 먹었어요.`)*
3. **追問明天出遊計畫**：<KoreanAudio text="내일 혼자 명동에 가요?" /> **내일 혼자 명동에 가요?**
4. **等待夥伴回答同行對象與活動** *(✅ 檢查 B 是否說出 `아니요, 우리 반 친구들하고 명동에 가요. 백화점에서 쇼핑해요.`)*
5. **詢問餐廳點餐內容**：<KoreanAudio text="식당에서 뭐 시켜요?" /> **식당에서 뭐 시켜요?**
6. **等待夥伴回答點餐與請人拍照** *(✅ 檢查 B 是否說出 `건강식을 먹어요. 그리고 저기요, 사진 좀 찍어 주세요!`)*

</TabItem>
<TabItem value="p3_role_b" label="🎒 角色 B：出遊夥伴（盲測任務卡）">

> 🎭 **角色任務卡（無答案版）**：聽好友（角色 A）的提問，依序完成 1～6 步全韓語應答！

1. **聽夥伴寒暄**：聽懂對方問你「昨天做了什麼？」
2. **分享昨日行程**：用過去式回答昨天「見了朋友」（或「在家唸了韓文、吃了好吃的東西」），並用連接詞「然後」接續「休息了」。
3. **聽夥伴問明天計畫**：聽懂對方問你「明天自己一個人去明洞嗎？」
4. **回應同行對象與活動**：先否定「不是」，說明「跟我們班同學（朋友們）一起去明洞」，並補充「在百貨公司購物」。
5. **聽夥伴問點餐**：聽懂對方問你「在餐廳要點什麼呢？」
6. **回答餐點與請求拍照**：回答「吃養生健康餐（`건강식`）」，接著補一句「對了不好意思，請幫我們拍張照！」。

## 結算 (1 分鐘)

  * **助詞區分**：`학교에 가요 / 교실에 있어요` vs `요가 교실에서 요가해요` 是否不會混用？

  * **關鍵音變**：`학교 [학꾜]`、`약국 [약꾹]`、`식당 [식땅]`、`백화점 [배콰점]`、`많이 [마니]`、`옷을 [오슬]` 是否發對？
