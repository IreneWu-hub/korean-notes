## 二、 核心文法精準活用 (冠形詞修飾與「ㄹ 不規則脫落」黃金口訣)

韓語初級文法中，「形容詞/動詞修飾後方名詞」與「ㄹ 收音遇特定子音脫落」是最常考且最容易出錯的盲點。請根據規則完成下列變化與句子分析：

### 1. 形容詞修飾名詞冠形詞形：語幹 + `-(으)ㄴ`
請將下列形容詞轉為修飾後方名詞的形式：

| 形容詞原形 | 語幹收音判斷 | 修飾後方名詞（範例） | 中文意思 |
| :--- | :--- | :--- | :--- |
| **크다 (大)** | 無收音 ➔ + ㄴ | ( &emsp;&emsp;&emsp;&emsp; ) 옷 | 大衣服 |
| **작다 (小)** | 有收音 ➔ + 은 | ( &emsp;&emsp;&emsp;&emsp; ) 옷 | 小衣服 |
| **길다 (長)** | 💡 **ㄹ 收音** ➔ (脫落/保留?) | ( &emsp;&emsp;&emsp;&emsp; ) 바지 | 長褲 |
| **짧다 (短)** | 有雙收音 ➔ + 은 | ( &emsp;&emsp;&emsp;&emsp; ) 치마 | 短裙 |
| **예쁘다 (漂亮)** | 無收音 ➔ + ㄴ | ( &emsp;&emsp;&emsp;&emsp; ) 원피스 | 漂亮的洋裝 |
| **비싸다 (貴)** | 無收音 ➔ + ㄴ | ( &emsp;&emsp;&emsp;&emsp; ) 가방 | 昂貴的包包 |

---

### 2. 動詞修飾名詞現在式：語幹 + `-는 것`
請將下列動詞轉為現在式修飾名詞形式（注意包含收音「ㄹ」的動詞變化）：

1. **먹다 (吃)** ➔ 我吃的食物：내가 ( &emsp;&emsp;&emsp;&emsp;&emsp; ) 음식
2. **팔다 (賣)** ➔ 在傳統市場賣的東西：전통시장에서 ( &emsp;&emsp;&emsp;&emsp;&emsp; ) 것
3. **만들다 (製作)** ➔ 媽媽做的料理：엄마가 ( &emsp;&emsp;&emsp;&emsp;&emsp; ) 요리
4. **살다 (居住/生活)** ➔ 我住的地方：내가 ( &emsp;&emsp;&emsp;&emsp;&emsp; ) 곳

---

### 3. 「ㄹ 不規則脫落」黃金口訣大考驗
韓語文法鐵則：**「語幹結尾為收音 ㄹ 的詞，遇到開頭為 ( &emsp;&emsp; , &emsp;&emsp; , &emsp;&emsp; , &emsp;&emsp; ) 的語尾時，收音 ㄹ 必定脫落消失！」**

請根據此鐵則完成下列動詞變形：
- ① **살다 (住)** + 敬語命令句 `-(으)세요` ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ② **살다 (住)** + 最高敬語陳述句 `-(으)ㅂ니다` ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ③ **알다 (知道)** + 最高敬語陳述句 `-(으)ㅂ니다` ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ④ **만들다 (做)** + 尊稱陳述句 `-(으)세요` ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ⑤ **알다 (知道)** + 原因連接語尾 `-(으)니까` ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )

<details>
<summary>💡 點擊展開第二大題參考解析</summary>

**【解析 1】形容詞修飾名詞填空**
- 크다 ➔ **큰** 옷
- 작다 ➔ **작은** 옷
- 길다 ➔ **긴** 바지 *(⚠️ 陷阱：길다 語幹收音為 ㄹ，遇到 ㄴ 必定脫落！길 + ㄴ ➔ 긴)*
- 짧다 ➔ **짧은** 치마
- 예쁘다 ➔ **예쁜** 원피스
- 비싸다 ➔ **비싼** 가방

**【解析 2】動詞現在式修飾名詞**
- 1. 내가 **먹는** 음식 (먹 + 는)
- 2. 전통시장에서 **파는** 것 *(⚠️ 陷阱：팔다 收音 ㄹ 遇到 ㄴ 脫落 ➔ 파는 것)*
- 3. 엄마가 **만드는** 요리 *(⚠️ 陷阱：만들다 收音 ㄹ 遇到 ㄴ 脫落 ➔ 만드는 요리)*
- 4. 내가 **사는** 곳 *(⚠️ 陷阱：살다 收音 ㄹ 遇到 ㄴ 脫落 ➔ 사는 곳)*

**【解析 3】「ㄹ 不規則脫落」黃金口訣解析**
- **口訣**：凡是語幹結尾為收音「**ㄹ**」，遇到「**ㅅ, ㄴ, ㅂ, 으**」四個字母開頭的語尾，**ㄹ 必定脫落**！
- ① 살다 + -(으)세요 ➔ **사세요** (遇 ㅅ 脫落，不加 으)
- ② 살다 + -(으)ㅂ니다 ➔ **삽니다** (遇 ㅂ 脫落，直接補上 ㅂ니다)
- ③ 알다 + -(으)ㅂ니다 ➔ **압니다** (遇 ㅂ 脫落，알 ➔ 압니다)
- ④ 만들다 + -(으)세요 ➔ **만드세요** (遇 ㅅ 脫落，만들 ➔ 만드세요)
- ⑤ 알다 + -(으)니까 ➔ **아니까** (遇 으 脫落，ㄹ 與 으 皆消失 ➔ 아니까)

</details>

## 三、 服飾配件穿戴動詞與構詞拆解陷阱

中文裡不管是穿外套、戴帽子、繫領帶還是穿球鞋，都常泛用「穿」或「戴」；但韓語根據**身體部位與穿戴方式**有嚴格區分！

### 1. 穿戴動詞配對大挑戰
請從下列動詞中選出最合適的穿戴動詞填入括號內：  
`[ 입다 / 신다 / 쓰다 / 차다 / 끼다 / 매다 / 메다 / 하다 ]`

1. 날씨가 추워서 **코트**를 ( &emsp;&emsp;&emsp;&emsp; ). (天氣冷穿了大衣)
2. 운동할 때 **운동화**를 ( &emsp;&emsp;&emsp;&emsp; ). (運動時穿運動鞋)
3. 햇빛이 강해서 **선글라스**를 ( &emsp;&emsp;&emsp;&emsp; ). (陽光強戴太陽眼鏡)
4. 결혼식에서 예쁜 **반지**를 ( &emsp;&emsp;&emsp;&emsp; ). (在婚禮上戴漂亮的戒指)
5. 시간을 보려고 **손목시계**를 ( &emsp;&emsp;&emsp;&emsp; ). (為了看時間戴手錶)
6. 정장에 멋진 **넥타이**를 ( &emsp;&emsp;&emsp;&emsp; ). (西裝上繫帥氣領帶)
7. 무거운 **배낭(백팩)**을 어깨에 ( &emsp;&emsp;&emsp;&emsp; ). (把沉重的雙肩背包背在肩上)
8. 반짝이는 **귀걸이**와 **목걸이**를 ( &emsp;&emsp;&emsp;&emsp; ). (戴閃亮的耳環與項鍊)

### 2. 服飾構詞拆解密碼
請根據課堂拆解邏輯寫出下列單字的韓語：
- ① 靑(푸를 청) + 바지(褲子) = **牛仔褲** ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )
- ② 半(반) + 바지(褲子) = **短褲** ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )

<summary>💡 點擊展開第三大題參考解析</summary>

**【解析 1】穿戴動詞精準搭配**
1. **입다**：用於軀幹服飾（코트 大衣, 바지 褲子, 치마 裙子, 원피스 洋裝）。
2. **신다**：用於腳部鞋襪（운동화 運動鞋, 구두 皮鞋, 양말 襪子, 슬리퍼 拖鞋）。

4. **끼다**：用於套進、夾住的物品（반지 戒指, 장갑 手套, 렌즈 隱形眼鏡）。
5. **차다**：用於扣緊、附著在手腕或腰部的物品（손목시계 手錶, 팔찌 手鍊）。
6. **매다**：用於打結、繫緊（넥타이 領帶, 신발끈 鞋帶, 안전벨트 安全帶）。
7. **메다**：用於肩背、扛起（백팩/배낭 雙肩包, 가방 側背包）。
8. **하다**：用於飾品、佩飾統稱（귀걸이 耳環, 목걸이 項鍊, 머리핀 髮夾）。

## 四、 水產市場海鮮魚類圖鑑與「깻잎 [깬닙]」三段音變奧秘

### 1. 水產海鮮辨析與料理情境
請根據描述，寫出對應的海鮮韓語單字：

1. **頭足類 3 兄弟辨析**：
   - 體型中等、有 10 隻觸手，常烤來當下酒菜或拍成熱門影集《魷魚遊戲》：( &emsp;&emsp;&emsp;&emsp;&emsp; )
   - 體型巨大厚實、有 8 隻腳，韓國慶典祭祀常切冷盤薄片的「文魚」：( &emsp;&emsp;&emsp;&emsp;&emsp; )
   - 觸手細長柔軟，廣藏市場常生吃（산낙지）或辣炒（낙지볶음）的長爪章魚：( &emsp;&emsp;&emsp;&emsp;&emsp; )

2. **水產市場雙軌魚類記憶**：
   - 韓國生魚片（회）之王，肉質半透明且極有嚼勁的「比目魚」：( &emsp;&emsp;&emsp;&emsp;&emsp; )
   - 與比目魚並稱水產店雙璧、口感超 Q 彈的黑色「石斑魚/平鮋」：( &emsp;&emsp;&emsp;&emsp;&emsp; )
   - 濟州島名物，身型細長如銀白刀刃的「白帶魚」：( &emsp;&emsp;&emsp;&emsp;&emsp; )
   - 平民餐桌首選，油脂豐富的「鯖魚」：( &emsp;&emsp;&emsp;&emsp;&emsp; )

---

### 2. 經典音變專利：`깻잎` 為什麼唸成 `[깬닙]`？
在韓國烤肉店包肉必備的紫蘇葉「깻잎」，寫作 깻잎，但實際發音卻是 **[깬닙]**。  
請寫出此單字歷經的三步音變過程：

- **第 1 步：音節末收音代表音化**  
  `깻` 底部的收音「ㅅ」代表音為 ➔ [ &emsp;&emsp;&emsp; ]
- **第 2 步：合成詞 ㄴ 添加 (ㄴ-첨가)**  
  前字有收音，後方單字以母音「ㅣ」開頭，結合時生出 ㄴ ➔ [ &emsp;&emsp;&emsp;&emsp; ]
- **第 3 步：鼻音化 (비음화)**  
  收音遇到後方初聲鼻音「ㄴ」，被同化為鼻音 ➔ 最終發音：[ &emsp;&emsp;&emsp;&emsp; ]

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

**【解析 1】海鮮魚類名稱**
1. **頭足類 3 兄弟**：
   - 魷魚/烏賊：**오징어**
   - 大章魚：**문어**
   - 長爪章魚/小章魚：**낙지**
2. **雙軌魚類**：
   - 比目魚：**광어**
   - 黑石斑魚/平鮋：**우럭**
   - 白帶魚：**갈치**
   - 鯖魚：**고등어**  
   *(💡 水產市場點餐金句：「광어 우럭 반반 주세요! 比目魚和石斑魚請給我各半！」)*

**【解析 2】깻잎 [깬닙] 三段音變解析**
- **第 1 步（代表音化）**：`깻` ➔ **[깯]**（韓語七大代表音 ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ 中，ㅅ 歸入 ㄷ）。
- **第 2 步（ㄴ 添加）**：`[깯] + 잎` ➔ **[깯닙]**（合成詞前後結合，後字為 이/야/여/요/유 時添加 ㄴ）。
- **第 3 步（鼻音化）**：`[깯닙]` ➔ **[깬닙]**（終聲 ㄷ 遇到後方 ᄂ，受同化變為 ᄂ）。
- 烤肉實戰句：**사장님, 깻잎 좀 더 주세요!** (老闆，請再給我一點紫蘇葉！)

</details>
