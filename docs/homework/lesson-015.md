## 二、 核心文法精準辨析 (`에` vs `에서`、視角與 `ㄷ` 不規則)

### 1. 場所助詞與移動視角判斷：`에` vs `에서`、`가다` vs `오다`
請根據「靜態存在 / 移動目的地」或「動作發生地點」填入最適當的助詞（`에` 或 `에서`）與動詞：

1. **我去學校。** ➔ 학교( &emsp;&emsp; ) 가요.
2. **來到我們班（朝說話者這邊過來）。** ➔ 우리 반( &emsp;&emsp; ) ( &emsp;&emsp;&emsp; ).
3. **人在教室裡（靜態存在，無動作）。** ➔ 교실( &emsp;&emsp; ) 있어요.
4. **在瑜珈教室做瑜珈。** ➔ 요가 교실( &emsp;&emsp; ) 요가해요.
5. **在水果店買蘋果。** ➔ 과일 가게( &emsp;&emsp; ) 사과를 사요.
6. **在電影院看了很多電影。** ➔ 영화관( &emsp;&emsp; ) 영화를 많이 ( &emsp;&emsp;&emsp; ).

---

### 2. 「ㄷ 不規則變化」：`듣다` 活用挑戰
動詞 **듣다（聽、上課）** 語幹帶有收音「ㄷ」，當遇到母音開頭的語尾（如 `-어요`、`-었어요`）時會發生音變。請完成以下變形造句：

- ❓ **變化規則**：遇母音語尾時，收音「ㄷ」會變身成為「( &emsp; )」。
1. **上韓語課（現在式）**：한국어 수업을 ( &emsp;&emsp;&emsp;&emsp;&emsp; ).
2. **聽音樂（現在式）**：음악을 ( &emsp;&emsp;&emsp;&emsp;&emsp; ).
3. **昨天聽歌了（過去式）**：어제 노래를 ( &emsp;&emsp;&emsp;&emsp;&emsp; ).

<details>
<summary>💡 點擊展開第二大題參考解析</summary>

**【解析 1】場所助詞與移動視角判斷**
1. 학교**에** 가요. *(移動目的地用 `에`)*
2. 우리 반**에 와요**. *(朝說話者方向「過來」用 `오다 ➔ 와요`，不可用 `가요`)*
3. 교실**에** 있어요. *(人或物靜態存在於某處 `있다/없다`，用 `에`)*
4. 요가 교실**에서** 요가해요. *(人在該地點「做瑜珈」這個動作，必須用 `에서`)*
5. 과일 가게**에서** 사과를 사요. *(在水果店做「買」的動作，用 `에서`)*
6. 영화관**에서** 영화를 많이 **봐요 / 봤어요**. *(在電影院做「看」的動作，用 `에서`；`보다` 現在式為 `봐요`，過去式為 `봤어요`)*

**【解析 2】「ㄷ 不規則變化」解析**
- **變化規則**：`듣다` 遇母音語尾時，收音「ㄷ」會變成「**ㄹ**」（`들 + 어요 ➔ 들어요`）。
1. 한국어 수업을 **들어요**. <KoreanAudio text="한국어 수업을 들어요." />
2. 음악을 **들어요**. <KoreanAudio text="음악을 들어요." />
3. 어제 노래를 **들었어요**. <KoreanAudio text="어제 노래를 들었어요." />

</details>

### 3. 「書店」雙說法與本課生活動詞活用
- 請寫出「**在書店買鉛筆**」的兩種韓語表達（一般書店 `서점` vs 社區小書店 `책방`）：  
  ➔ __________________________________________________
- 請將括號中的動詞轉為敬語現在式，完成下列短句：
  1. 學韓語（`배우다`）：한국어를 ( &emsp;&emsp;&emsp;&emsp; ).
  2. 喝水（`마시다`）：물을 ( &emsp;&emsp;&emsp;&emsp; ).
  3. 傳訊息（`보내다`）：메시지를 ( &emsp;&emsp;&emsp;&emsp; ).

<details>
<summary>💡 點擊展開第三大題參考解析</summary>

**【解析 1】散步 vs 遛狗**
- **情境 A（跟小狗一起散步）**：<KoreanAudio text="강아지하고 산책해요. 강아지랑 산책해요." />  
  - 版本 ①：**강아지하고 산책해요.** *(`하고` 不分有無收音皆可直接接)*
  - 版本 ②：**강아지랑 산책해요.**
- **情境 B（遛狗）**：<KoreanAudio text="강아지를 산책 시켜요." /> **강아지를 산책 시켜요.**  
  *(使用受詞助詞 `을/를` ＋ 使役動詞 `시키다`，意指「讓小狗散步＝遛狗」。)*
- **收音判斷**：`강아지` 無收音接 **랑**（**강아지랑**）；`선생님` 有收音接 **이랑**（**선생님이랑**）。

**【解析 2】`시키다` 一詞雙義**
- ① `강아지를 산책 시켜요.` ➔ 表示**「使役：讓…做…（遛狗）」**。
- ② `식당에서 뭐 시켜요?` ➔ 在餐廳、咖啡廳或點外賣時，表示**「點餐、叫東西」**。

**【解析 3】書店與生活動詞活用**
- 在書店買鉛筆：**서점에서 연필을 사요.** / **책방에서 연필을 사요.** <KoreanAudio text="서점에서 연필을 사요. 책방에서 연필을 사요." />
- 動詞現在式：
  1. `배우다` ➔ **배워요** (`ㅜ + ㅓ ➔ ㅝ`)
  2. `마시다` ➔ **마셔요** (`ㅣ + ㅓ ➔ ㅕ`)
  3. `보내다` ➔ **보내요** (`ㅐ` 結尾直接加 `요`)

</details>

## 四、 城市場所音變與發音陷阱實戰

本課學了許多高頻城市生活場所與常用詞，但書寫與實際口語發音往往不同！請寫出下列詞語的**實際發音 `[ ]`**，並思考背後原因（硬音化 / 激音化 / 連音 / ㅎ 脫落）：

| 詞語 / 句子 | 中文意思 | 實際發音 | 音變提示 |
| :--- | :--- | :--- | :--- |
| **1. 학교** | 學校 | `[ 　　　 ]` | 收音 ㄱ 遇 ㄱ |
| **2. 약국** | 藥局 | `[ 　　　 ]` | 收音 ㄱ 遇 ㄱ |
| **3. 식당** | 餐廳 | `[ 　　　 ]` | 收音 ㄱ 遇 ㄷ |
| **4. 백화점** | 百貨公司 | `[ 　　　　 ]` | 收音 ㄱ 遇 ㅎ |
| **5. 은행** | 銀行 | `[ 　　　 ]` | 單獨連音 |
| **6. 많이** | 很多地（副詞） | `[ 　　　 ]` | 雙收音 `ㄶ` 遇母音 |
| **7. 오늘 옷을 사요.** | 今天買衣服 | `옷` 單唸 `[ 　 ]` / `옷을` `[ 　　 ]` | 代表音 vs 連音 |
| **8. 음악을 들어요.** | 聽音樂 | `음악을` `[ 　　　 ]` | 連續連音 |

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

**【解析】城市場所與高頻詞音變總整理**
1. **학교** ➔ **`[학꾜]`** <KoreanAudio text="학교" /> *(收音 ㄱ 後接 ㄱ 時，後方發生硬音化 ㄲ)*
2. **약국** ➔ **`[약꾹]`** <KoreanAudio text="약국" /> *(同上，硬音化 ㄲ)*
3. **식당** ➔ **`[식땅]`** <KoreanAudio text="식당" /> *(收音 ㄱ 後接 ㄷ 時，後方發生硬音化 ㄸ)*
4. **백화점** ➔ **`[배콰점]`** <KoreanAudio text="백화점" /> *(激音化：收音 `ㄱ` 與後方 `ㅎ` 相遇合併成激音 `ㅋ`)*
5. **은행** ➔ **`[으냉]`** <KoreanAudio text="은행" /> *(連音：收音 `ㄴ` 移至後方與 `ㅎ` 合流後，在字間 `ㅎ` 弱化脫落)*
6. **많이** ➔ **`[마니]`** <KoreanAudio text="많이" /> *(雙收音 `ㄶ` 遇母音時，`ㅎ` 不發音脫落，僅留 `ㄴ` 向後連音)*
7. **옷 / 옷을** ➔ `옷` 單唸為 **`[옫]`**（`ㅅ` 代表音為 `ㄷ`），但接母音助詞 `을` 時直接連音 ➔ **`[오슬]`** <KoreanAudio text="옷을 사요" />
8. **음악을** ➔ **`[으마글]`** <KoreanAudio text="음악을 들어요" /> *(`음` 的 `ㅁ` 連到 `악` 成 `[으막]`，`악` 的 `ㄱ` 再連到 `을` 成 `[으마글]`)*

</details>
