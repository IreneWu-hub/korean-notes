## 二、 TOPIK 核心文法辨析與經典病句抓錯

### 1. 限定助詞 TOPIK I 必考切換：`-만` vs `-밖에 + 否定`
請依語意填入正確的限定助詞與後方動詞，注意 **`-밖에` 後方絕對必須搭配否定詞**：
1. （肯定請求）「請只給我一個咖啡。」➔ 커피 하나( &emsp;&emsp; ) 주세요.
2. （無奈剩餘）「現在只剩下一個了。」➔ 지금 하나( &emsp;&emsp; ) ( &emsp;&emsp;&emsp;&emsp; ). *(使用 `없다`)*
3. （只有這個）「我只有這件衣服。」➔ 저는 이 옷( &emsp;&emsp; ) ( &emsp;&emsp;&emsp;&emsp; ). *(使用 `있다` 的否定)*

### 3. 問句語氣三級跳 ＆ 共鳴 `-(이)잖아요?`
1. 依情境選擇最適合的語尾（`-어요?` / `-나요?` / `-는 건가?`）完成造句：
   - 對自己或旅伴小聲猜測「這是在排隊的嗎？」➔ ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )
   - 直接向店員或路人確認「要排隊嗎？」➔ ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )
   - 柔和委婉請店員找「沒有其他顏色嗎？」➔ 다른 색깔 ( &emsp;&emsp;&emsp; )?
2. 改寫為尋求共鳴 `-(이)잖아요?`：
   - 名詞有收音：**처음이에요** ➔ 처음( &emsp;&emsp;&emsp; )? ／ 名詞無收音：**여기예요** ➔ 여기( &emsp;&emsp;&emsp; )?
   - 動詞／形容詞：**맛있어요** ➔ 맛있( &emsp;&emsp;&emsp; )?

**【解析 1】限定助詞 `-만` vs `-밖에 + 否定`**
1. 커피 하나**만** 주세요. <KoreanAudio text="커피 하나만 주세요." /> *(`-만` 後可接肯定句)*
2. 지금 하나**밖에 없어요.** <KoreanAudio text="지금 하나밖에 없어요." /> *(`-밖에` 必須搭配否定動詞 `없어요 / 안 남았어요`)*
3. 저는 이 옷**밖에 없어요.** *(`있다` 的否定即為 `없어요`)*

**【解析 2】`-(으)ㄹ게요` 病句抓錯（TOPIK 高頻）**
1. **錯誤原因**：`-(으)ㄹ게요` **只能用於第一人稱「我／我們」**，表達承諾或決定，不能用於第三人稱 `친구가`。  
   ➔ 正確寫法：我先回去囉：**제가 먼저 돌아갈게요.**（或陳述朋友計畫：`친구가 먼저 돌아갈 거예요.`）
2. **錯誤原因**：`-(으)ㄹ게요` **不能用於疑問句**，詢問客人或對方的意願須用尊稱疑問語尾。  
   ➔ 正確寫法：**손님, 뭐 드시겠어요?**（或 **뭐 드실래요?**）<KoreanAudio text="손님, 뭐 드시겠어요?" />
3. **錯誤原因**：`-밖에` 後方必須接否定，接肯定動詞 `받아요` 是錯的。  
   ➔ 正確寫法：**여기는 현금만 받아요.**（這裡只收現金）或 **현금밖에 안 받아요.**（除了現金以外都不收）<KoreanAudio text="여기는 현금만 받아요." />

**【解析 3】問句語氣三級跳 ＆ `-(이)잖아요?`**
1. 推測：**줄을 서는 건가?** ／ 直接問：**줄을 서요?** ／ 委婉問：**다른 색깔 없나요?** <KoreanAudio text="다른 색깔 없나요?" />
2. **처음이잖아요?** ／ **여기잖아요?** ／ **맛있잖아요?**（動詞／形容詞不分收音直接接 `-잖아요?`）

**【解析 4】尊稱與謙讓語主語配對**
1. **잘 어울리세요.** ➔ 「您穿起來非常好看呢！」
2. **사이즈가 잘 맞으시네~** ➔ 「哇～您的尺寸非常合身呢！」
3. **드시고 가세요?** <KoreanAudio text="드시고 가세요?" /> ➔ 原型 **`먹다`（吃／喝）的尊稱 `드시다`** ➔ 「您要內用嗎？」
4. **현금하시면 사만 원까지 해 드려요.** ➔ `해 드리다` 為 **`해주다`（幫做）的謙讓語** ➔ 「如果您付現，可以幫您算到四萬韓元。」
5. **뭐 드릴까요?** ➔ 原型 **`주다`（給）的謙讓語 `드리다`** ➔ 「請問要給您什麼（要點什麼）？」

</details>

## 三、 TOPIK 詞形變化陷阱與易混淆概念辨析

### 1. 「`ㅅ` 不規則 vs `ㅅ` 規則例外」活用實測
同樣是 `ㅅ` 收音，TOPIK 非常喜歡把「脫落」和「保留」放在一起考！請寫出下列動詞／形容詞的 **`-아/어요` 現在式**：
1. **`낫다`**（更好，ㅅ 不規則）：이거 더 ( &emsp;&emsp;&emsp; ). *（⚠️ 為何絕對不能寫成 `나요`？）*
2. **`짓다`**（蓋／煮飯，ㅅ 不規則）：밥을 ( &emsp;&emsp;&emsp; ).
3. **`벗다`**（脫衣服，**ㅅ 規則例外**）：코트를 ( &emsp;&emsp;&emsp; ).
4. **`돌다`**（逛／轉，ㄹ 收音）：現在式 ( &emsp;&emsp;&emsp; ) ／ 冠形詞「在轉的…」：( &emsp;&emsp; )
5. **`맞다`**（合身）副詞化：「這件版型本來就穿得偏合身」➔ `핏이 좀 ( 　　　 ) 입는 거예요.`

---

### 2. TOPIK 閱讀填空常客：定語時態三選一（過去 vs 現在 vs 形容詞）＆ 數詞 `하나 vs 한`
請根據前後時間與名詞性質，填入正確的修飾形（定語）：
1. **動作過去 `-(으)ㄴ`**：
   - `사다`（無收音）：剛剛買的衣服 ➔ 아까 ( &emsp;&emsp; ) 옷
   - `먹다`（有收音）：剛剛吃的食物 ➔ 아까 ( &emsp;&emsp; ) 음식
   - `만들다`（**`ㄹ` 收音脫落**）：親手做的東西 ➔ 직접 ( &emsp;&emsp; ) 것
2. **動作現在 `-는`**：最近常穿的衣服 ➔ 요즘 자주 ( &emsp;&emsp; ) 옷 *(原型 `입다`)*
3. **形容詞現在 `-(으)ㄴ`**：大一號的尺寸 ➔ `( 　　 ) 사이즈 더 ( 　　 ) 거` ／ 小一號 ➔ `더 ( 　　 ) 거`
   - ❓ 為何「單獨說多一個級距」用 `하나`，接 `사이즈` 時卻要變成 `한`？_______________________

---

### 3. 本課 5 大易混淆概念與 `-(으)로` 收音陷阱
1. **`어울리다` vs `맞다`**：顏色氣質很襯 ➔ `( 　　　　 )` ／ 肩寬腰圍剛好 ➔ `( 　　　　 )`
2. **`아까` vs `방금`**：幾十分鐘前買好的車票 ➔ `( 　　 )` ／ 才剛講完那一秒 ➔ `( 　　 )`
3. **`돌아오다` vs `돌아가다`**：逛一圈再「回來這兒」➔ `( 　　　　 )` ／ 回家「回去那兒」➔ `( 　　　　 )`
4. **`에서` vs `-(으)로`**（⚠️ 注意 `ㄹ` 收音接 `로` 不加 `으`！）：
   - 「在哪裡換乘？」➔ 어디`( 　　 )` 갈아타요?
   - 「請進來店裡面」➔ 가게 안`( 　　 )` 들어오세요.
   - 「請往這邊來」➔ 이쪽`( 　　 )` 오세요.
   - 「搭地鐵去」（`지하철` 為 `ㄹ` 收音！）➔ 지하철`( 　　 )` 가요.

**【解析 1】`ㅅ` 不規則 vs 規則例外**
1. **이거 더 나아요.** <KoreanAudio text="이거 더 나아요." /> *(`낫` 遇母音脫落 `ㅅ` 且不合併；若寫成 `나요` 會變成動詞 **`나다`**「出來、發生」)*
2. **밥을 지어요.** *(ㅅ 脫落：`짓 + 어요 ➔ 지어요`)*
3. **코트를 벗어요.** <KoreanAudio text="코트를 벗어요." /> *(⚠️ `벗다` 脫衣、`웃다` 笑、`씻다` 洗皆為 **規則動詞**，`ㅅ` 不脫落！)*
4. **돌아요**（遇 `-아/어요` 時 `ㄹ` 保留）／ **도는**（遇 `ㄴ/ㅂ/ㅅ` 時 `ㄹ` 脫落）
5. `핏이 좀 **맞게** 입는 거예요.` <KoreanAudio text="핏이 좀 맞게 입는 거예요." />

**【解析 2】定語時態與數詞**
1. 動作過去：`사다 ➔ **산**` ／ `먹다 ➔ **먹은**` ／ `만들다 ➔ **만든**` *(`ㄹ` 遇 `-ㄴ` 時脫落)*
2. 動作現在：`입다 ➔ **입는**`
3. 形容詞與數詞：**`한` 사이즈 더 `큰` 거** ／ **더 `작은` 거** *(`하나` 後面緊接單位詞須縮為 `한`；`크다` 無收音加 `-ㄴ`，`작다` 有收音加 `-은`)*

**【解析 3】易混淆概念與 `-(으)로` 規則**
1. 風格搭配 **`어울리다`** ／ 尺碼合身 **`맞다`**
2. 隔一小段時間 **`아까`** ／ 幾秒前剛發生 **`방금`**
3. 朝這裡回來 **`돌아오다`** ／ 往那裡回去 **`돌아가다`**
4. 地點動作 **`어디에서`** ／ `안` 有收音 ㄴ ➔ **`안으로`** ／ `이쪽` 有收音 ㄱ ➔ **`이쪽으로`** <KoreanAudio text="이쪽으로 오세요." /> ／ `지하철` 為 **`ㄹ` 收音**，直接接 `로` ➔ **`지하철로`** <KoreanAudio text="지하철로 가요." />

</details>

## 四、 TOPIK 聽力風格：韓幣大數字、折價計算與連音辨識

在 TOPIK I 聽力購物題中，常出現**「單價 × 數量」或「付現／多件折扣」**的計算陷阱！請寫出完整韓語讀法並作答：

| 標價 / 聽力情境 | 完整韓語讀法 / 答案 | TOPIK 避坑關鍵 |
| :--- | :--- | :--- |
| **1. `4,900원` vs `49,000원`** | `4,900`: `( 　　　　 )` / `49,000`: `( 　　　　 )` | 聽音先抓 `천` 還是 `만` |
| **2. `17,500원` / `10,000원`** | `17,500`: `( 　　　　 )` / `10,000`: `( 　　　 )` | 1 萬唸 `일만` 還是 `만`？ |
| **3. `23,800원` / `120,000원`** | `23,800`: `( 　　　　 )` / `120,000`: `( 　　　 )` | 每四位進一萬（12萬＝十萬＋二萬） |
| **4. `3,000원`（名詞簡答）** | `( 　　　　　 )` | `원` 有收音 `ㄴ` 接 `이요` |
| **5. 聽力計算題**：店員說「`한 개에 사천오백 원인데, 두 개 사시면 팔천 원까지 해 드려요.`」買兩件付多少？ | 金額：`( 　　　　 )`（漢字數字讀法：`( 　　　 )`） | 分辨原價 `4,500` × 2 與實際折扣價 |
| **6. 連音＋硬音化發音實測** | 寫出實際讀音：`안으로` `[ 　　 ]` ／ `먹을 수 있어요` `[ 　　 　 　　 ]` | 助詞連音 ＋ `-(으)ㄹ 수` 後方硬音化 |

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

**【解析】韓幣大數字聽力與音變口訣**
1. **`4,900원` vs `49,000원`**：<KoreanAudio text="사천구백 원, 사만 구천 원" /> **사천구백 원**（4千9百）vs **사만 구천 원**（4萬9千）。
2. **`17,500원` / `10,000원`**：<KoreanAudio text="만 칠천오백 원, 만 원" /> **만 칠천오백 원** ／ **만 원** *(規則：**1 萬不唸 `일만`，直接唸 `만`**)*。
3. **`23,800원` / `120,000원`**：<KoreanAudio text="이만 삼천팔백 원, 십이만 원" /> **이만 삼천팔백 원** ／ **십이만 원** *(12 萬 = `십이만`)*。
4. **`3,000원`（簡答）**：<KoreanAudio text="삼천 원이요." /> **삼천 원이요.**
5. **聽力計算題**：<KoreanAudio text="한 개에 사천오백 원인데, 두 개 사시면 팔천 원까지 해 드려요." />  
   ➔ **8,000원（팔천 원）** *(1 個原價 4,500 元，兩件原本 9,000 元，但店員說買兩個可以算到 **8,000 元**！)*
6. **連音＋硬音化讀音**：
   - `안으로` ➔ **`[아느로]`**（ㄴ 收音直接連音到後方 `으`）
   - `먹을 수 있어요` ➔ **`[머글 쑤 이써요]`**（`ㄱ` 連音成 `글`，且冠形詞 `-(으)ㄹ` 後方的 `수` 發生硬音化唸 **`쑤`**）

</details>
