**【解析 1】`ㅅ` 不規則與動詞變形**
1. **이거 더 나아요.** <KoreanAudio text="이거 더 나아요." /> *(`낫` 遇母音 `아` 時收音 `ㅅ` 脫落，且兩個 `아` 不合併：`낫 + 아요 ➔ 나아요`)*
2. **陷阱原因**：若錯寫或縮寫成 `나요`，會變成動詞 **`나다`**（出來、發生、長出）的現在式，意思完全改變！
3. **同場對比**：
   - ① `어울리다` ➔ **`어울려요`** (`리 + 어요` 母音縮寫成 `려요`)
   - ② `돌다` ➔ **`돌아요`**（`ㄹ` 收音遇 `-아/어요` 時 **`ㄹ` 保留**；遇 `ㄴ/ㅂ/ㅅ` 才脫落，例如 `도는`）
   - ③ 副詞化：`핏이 좀 **맞게** 입는 거예요.` <KoreanAudio text="핏이 좀 맞게 입는 거예요." /> *(`맞다` + `-게` 修飾後方的 `입다`)*

**【解析 2】數詞與形容詞定語**
- 句子 A：**`하나`** 더 큰 사이즈 없나요?（後面沒有直接接單位詞，單用數詞保留 **`하나`**）
- 句子 B：**`한`** 사이즈 더 큰 거 없나요?（後面緊接單位詞 `사이즈`，`하나` 必須縮寫為 **`한`**）
- 定語差別：`크다` 語幹無收音加 `-ㄴ` ➔ **`큰`**；`작다` 語幹有收音 `ㄱ` 加 `-은` ➔ **`작은`**。

**【解析 3】四大易混淆概念**
1. 風格顏色搭 ➔ **`어울리다`**；尺碼肩腰合身 ➔ **`맞다`**
2. 隔幾分鐘～數小時的剛剛 ➔ **`아까`**；就在幾秒～一兩分鐘前的剛才 ➔ **`방금`**
3. 朝說話者所在處「回來」➔ **`돌아오다`**；往另一邊「回去」➔ **`돌아가다`**
4. 動作發生地點「在哪裡吃」➔ **`어디에서`**；移動方向「往店裡」➔ `안` 有收音 `ㄴ` ➔ **`가게 안으로`** <KoreanAudio text="가게 안으로 들어오세요." />

| **5. `40,000원`（付現優惠）** | `현금하시면 ( 　　　 )까지 해 드려요.` | 「到四萬為止」的助詞是什麼？ |

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

**【解析】韓幣大數字聽讀與避坑口訣**
韓語和中文一樣是「**每四位進一萬**」，聽到價格先抓 **`만`（萬）** 或 **`천`（千）** 就不會錯！

1. **`4,900원`**：<KoreanAudio text="사천구백 원" /> **사천구백 원**  
   *(陷阱：`4,900` 是四「千」九百；`49,000` 則是 **사만구천 원** 四「萬」九千，注意別多聽少聽一個 `만`！)*
2. **`17,500원`**：<KoreanAudio text="만 칠천오백 원" /> **만 칠천오백 원**  
   *(規則必記：**1 萬不唸 `일만`，直接唸 `만`**；同理 `1,000` 唸 `천`、`100` 唸 `백`。)*
3. **`23,800원`**：<KoreanAudio text="이만 삼천팔백 원" /> **이만 삼천팔백 원**  
   *(切分口訣：`이만` 20,000 ＋ `삼천팔백` 3,800。)*
4. **`3,000원`（簡答）**：<KoreanAudio text="삼천 원이요." /> **삼천 원이요.**  
   *(名詞簡答 `N(이)요`：`원` 有收音 `ㄴ`，因此接 **`이요`**；若是無收音的品項如 `커피`，則接 `요` ➔ `커피요.`。)*
5. **`40,000원`（付現優惠）**：<KoreanAudio text="현금하시면 사만 원까지 해 드려요." /> **현금하시면 사만 원까지 해 드려요.**  
   *(助詞 `까지` 表示價格上限「到…為止」。)*

</details>
