## 一、 實戰情境對話與應答 (中翻韓口說練習)

請試著不看筆記，用韓語說出或寫出下列實戰情境句子：

1. **傳統市場點餐與交代**
   - 看到攤位上的蔥煎餅，跟老闆說：「**請給我一份煎餅。**」
   - 老闆問你是否外帶，你想表達最道地的內用句（吃完再走）：「**在這裡吃。**」
   - 付款時，用最禮貌溫和的疑問語氣詢問老闆：「**請問也可以刷卡嗎？**」

2. **服飾店試穿與委婉應對**
   - 走進服飾店，店員熱情地向你說：「**您可以試穿一次看看喔。**」
   - 店員拿衣服問你：「이거 드릴까요?（要幫您拿這件結帳嗎？）」，如果你覺得不合適想考慮一下，請寫出 **兩種不同語氣** 的客氣委婉拒絕說法：
     - 說法 ①（那我考慮看看）：
     - 說法 ②（我再多逛逛／看看）：

1. **傳統市場點餐與交代**
   - **파전 하나 주세요.** (數量詞使用固有數詞 하나，若講份數亦可用 1인분)
   - **여기에서 먹고 갈게요.** (拆解：여기에서 + 먹다 + -고 + 가다 + -(으)ㄹ게요。「吃完再走」是母語者最自然的內用說法；若外帶則是「포장해 주세요」)
   - **카드도 되나요?** (動詞 되다 接疑問語尾 -나요? 最為親切客氣；一般口語亦可用 카드도 돼요? 或 카드 돼요?)

2. **服飾店試穿與委婉應對**
   - **한 번 입어 보셔도 돼요.** (或敬語體：한 번 입어 보셔도 됩니다。)
   - 委婉說法 ①：**그럼 생각해볼게요.** (或 좀 더 생각해볼게요.)
   - 委婉說法 ②：**좀 더 볼게요.**

## 二、 核心文法精準辨析 (句型原理與語氣差異)

### 1. 限定文法辨析：`~만 있어요` vs `~밖에 없어요`
請說明或體會下列兩句話在「接續結構」與「語氣色彩」上的核心差異：
- **句子 A**：`아니요, 이거 하나만 남았어요 / 있어요.`
- **句子 B**：`아니요, 이거 하나밖에 없어요.`

> ❓ **思考題**：  
> ① 哪一句的後方**絕對只能接否定詞**（없다）？  
> ② 如果店員想強烈表達「真的很抱歉，架上真的就僅僅剩這件、別無選擇了」，使用哪一句更有這種語氣？

---

### 2. 推測語尾辨析：`-아/어 보여요` vs `-겠다`
請根據情境，選擇填入適當的語尾（`-아/어 보여요` 或 `-겠다`）：

1. 剛旅遊回國的同事走進辦公室，臉色看起來非常疲倦，你看到他的神情說：  
   ➔ **피곤해** ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )**.** （你看起來很累。）

2. 朋友傳來泰國夜市美食的照片，你看到照片直覺口水直流、感嘆這食物肯定超美味：  
   ➔ **맛있** ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; )**!** （哇！一定很好吃！）

<details>
<summary>💡 點擊展開第二大題參考解析</summary>

### 1. `~만` vs `~밖에` 解析
* **結構規則**：
  - `名詞 + 만` 後方接 **肯定句**（남았어요 / 있어요）。
  - `名詞 + 밖에`（字面意思：除了…之外）後方 **固定只能接否定詞**（없어요 / 몰라요 / 못해요）。
* **語氣差異**：
  - `하나만 있어요` 是客觀、平實地陳述「只有一個」的事實。
  - `하나밖에 없어요` 帶有強烈的限定感與無奈感，強調「除了這一個之外再也沒有其他選擇」，語氣比 `-만` 強烈許多。

### 2. 推測語尾解析
1. **피곤해 보여요.**  
   * 解析：外觀感官推測使用「**形容詞 + -아/어 보이다**」，表示說話者透過眼睛觀察對方外表所下的判斷（你看起來…）。
2. **맛있겠다!**  
   * 解析：使用「**-겠다**」表示說話者當下的直覺推測、共鳴感嘆（想必一定…！）。

</details>

## 三、 數字、時間量詞與發音陷阱

韓語的數字系統（漢字數詞 vs 固有數詞）在日常生活計量中極容易混淆，請試著回答：

1. **時間耗時陷阱**：  
   朋友問：「얼마나 걸렸어요?（花了多少時間？）」，你想回答「**花了 2 個小時**」：  
   - 請問韓語中的「小時」單位量詞（시간）前面，數字 2 要用漢字數詞（이）還是固有數詞（둘 ➔ 두）？  
   - 請寫出完整句子：__________________________________________________

2. **天數表達陷阱**：  
   「在泰國旅行了 5 天」這句話中的「5 天」，韓語有哪兩種說法？  
   - 漢字數詞說法：( &emsp;&emsp;&emsp;&emsp; )일 동안 여행했어요.  
   - 固有天數詞說法：( &emsp;&emsp;&emsp;&emsp; ) 동안 여행했어요.

3. **連音發音陷阱**：  
   「5,000韓元」寫作「`5,000원이에요`」，實際口語連音發音應該如何標註？  
   - 發音：[ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ]

<details>
<summary>💡 點擊展開第三大題參考解析</summary>

1. **시간（小時）的數詞規則**：
   - 小時必須使用 **固有數詞**（하나 ➔ 한, 둘 ➔ 두, 셋 ➔ 세, 넷 ➔ 네）。
   - 正確句子：**2시간 걸렸어요. [두 시간]** （❌ 切勿講成 이시간）。

2. **5 天的兩種表達**：
   - 漢字數詞：**5일 [오일] 동안 여행했어요.**
   - 固有天數詞：**닷새 동안 여행했어요.** (1天: 하루, 2天: 이틀, 3天: 사흘, 4天: 나흘, 5天: 닷새)。

3. **5,000원이에요 發音**：
   - **[오천원이에요 ➔ 오처눠nieyo]**  
   - 終聲 ㄴ 遇到後方母音 ㅇ 向後連音：천 + 원 ➔ [처눤]，원 + 이 ➔ [워니]。

</details>

## 四、 易混淆詞彙概念辨析

請根據中文提示，填入正確的單字（**질문** vs **문제** / **안내** vs **안내소**）：

1. 上課快結束時，老師問大家有沒有不懂的地方要發問：「( &emsp;&emsp;&emsp;&emsp; ) 있어요?」
2. 電腦突然壞掉、或是生活上遇到難題時：「( &emsp;&emsp;&emsp;&emsp; )가 있어요.」
3. 在仁川機場或明洞街頭，想找旅遊諮詢處／服務台詢問路線，要找：「관광 ( &emsp;&emsp;&emsp;&emsp; )」
4. 車廂內或商場響起廣播導覽與通知：「( &emsp;&emsp;&emsp;&emsp; ) 방송」

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

1. **질문** (提問/疑問 Question：好奇或不懂而提出的發問 ➔ 질문 있어요?)
2. **문제** (問題/麻煩/考題 Problem：困難、故障或試卷題目 ➔ 문제가 있어요)
3. **안내소** (服務處/諮詢台 ➔ 관광 안내소 觀光諮詢所)
4. **안내** (引導/通知/說明 ➔ 안내 방송 廣播通知)

</details>
