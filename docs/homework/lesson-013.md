## 二、 核心時態精準活用 (現在式 vs 過去式大辨析)

韓語的過去時態（과거시제）是初級最關鍵的分水嶺。請根據規則，完成下列變化與句子分析：

### 1. 動詞／形容詞過去式活用填空
請將下列語幹轉化為過去敬語形（`-았어요` / `-었어요` / `-했어요`）：

| 原形 | 現在式 (-아/어요) | 過去式 (-았/었어요) | 變化判斷原因 |
| :--- | :--- | :--- | :--- |
| **먹다 (吃)** | 먹어요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | 語幹母音為 ㅓ（陰性母音） |
| **사다 (買)** | 사요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | 語幹母音為 ㅏ（陽性母音） |
| **자다 (睡)** | 자요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | 語幹母音為 ㅏ（陽性母音） |
| **마시다 (喝)** | 마셔요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | 語幹母音為 ㅣ（ㅣ+ㅓ=ㅕ） |
| **바쁘다 (忙)** | 바빠요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | 語幹母音 ㅡ 脫落，看前面 ㅏ ➔ 았 |
| **알바하다 (打工)** | 알바해요 | ( &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ) | -하다 動詞固定變為 -했- |

---

### 2. 名詞過去式：`이다` ➔ `-이었어요` vs `-였어요`
請根據名詞**「是否有收音」**，將下列名詞轉化為過去式陳述或疑問句：

1. **現場詢價 vs 事後查帳**：
   - 看到架上的便當問：「이거 ( &emsp;&emsp;&emsp;&emsp;&emsp; )?」（這個現在多少錢？）
   - 拿著昨天買東西的收據想確認：「그거 ( &emsp;&emsp;&emsp;&emsp;&emsp; )?」（那個那時是多少錢？）

2. **身份過去式**：
   - 「金先生以前曾是**學生**（학생）。」➔ 김 선생님은 예전에 **학생** ( &emsp;&emsp;&emsp;&emsp;&emsp; ).
   - 「李小姐以前曾是**醫生**（의사）。」➔ 이 씨는 예전에 **의사** ( &emsp;&emsp;&emsp;&emsp;&emsp; ).

<details>
<summary>💡 點擊展開第二大題參考解析</summary>

**【解析 1】動詞／形容詞過去式活用表**
- **먹다** ➔ **먹었어요** [머거써요]
- **사다** ➔ **샀어요**
- **자다** ➔ **잤어요**
- **마시다** ➔ **마셨어요**
- **바쁘다** ➔ **바빴어요** (💡 注意：바쁘다 遇母音時 ㅡ 脫落，前面的母音是 ㅏ，因此接 았 ➔ 바빴어요)
- **알바하다** ➔ **알바했어요**

**【解析 2】名詞過去式規則解析**
- **얼마예요?** vs **얼마였어요?**  
  * `얼마` 沒有收音（받침 X），現在式接 `-예요`，過去式接 `-였어요`。
- **학생이었어요**  
  * `학생` 有收音 `ㅇ`（받침 O），因此過去式必須加上媒介音 이 ➔ `학생이었어요`。
- **의사였어요**  
  * `의사` 沒有收音（받침 X），因此過去式直接接 `-였어요`。

</details>

### 3. 五大味覺連連看
請將下列味覺與其現在式搭配寫出：
- ① 甜 (달다) ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ② 鹹 (짜다) ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; )
- ③ 辣 (맵다) ➔ ( &emsp;&emsp;&emsp;&emsp;&emsp; ) (💡 ㅂ 不規則：맵 + 어요 ➔ ?)

<details>
<summary>💡 點擊展開第三大題參考解析</summary>

**【解析 1】`쓰다 ➔ 써요` 音變解析**
- **正確句子**：**커피가 너무 써요.** (過去式：커피가 너무 썼어요.)
- **音變原理**：語幹最後一個字的母音為 **「ㅡ」** 時，若後方接續以母音開頭的語尾（如 `-아요/어요`），**母音「ㅡ」會強制脫落**。`ㅆ + 어요 ➔ 써요`。

**【解析 2】`시다 ➔ 셔요` 音變解析**
- **正確句子**：**오렌지가 너무 셔요.** (過去式：오렌지가 너무 셨어요.)
- **音變原理**：語幹母音為 **「ㅣ」**，遇到陰性語尾 `-어요` 時，兩者母音會縮合為 **「ㅕ」**（`ㅣ + ㅓ = ㅕ`），因此形成 `셔요`。

**【解析 3】味覺現在式**
- ① 달다 ➔ **달아요**
- ② 짜다 ➔ **짜요**
- ③ 맵다 ➔ **매워요** (ㅂ 不規則變為 우 + 어요 ➔ 워요)

</details>

### 3. 連音發音實戰陷阱
請標註下列兩個句子的實際口語發音（注意雙收音連音與終聲音變）：

1. **책을 읽어요 (看書)** ➔ 實際發音：[ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ]  
2. **음식이 맛있었어요 (食物很好吃)** ➔ 實際發音：[ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ]  

<details>
<summary>💡 點擊展開第四大題參考解析</summary>

**【解析 1】時間數字規則**
- **幾點鐘必須使用固有數詞**（한 시, 두 시, 세 시, 네 시...），絕不能用漢字數詞！
- **完整句子**：**새벽 3시에 잤어요. [새벽 세 시에 잤어요]** （❌ 切勿講成 새벽 삼시에 잤어요）

**【解析 2】一日時段正確順序**
1. **새벽** (凌晨，如：새벽 1시, 새벽에)
2. **아침** (早晨，如：아침에)
3. **점심** (中午，如：점심에)
4. **저녁** (傍晚，如：저녁에)
5. **밤** (深夜/夜晚，如：밤에)

**【解析 3】連音發音解析**
1. **책을 읽어요** ➔ **[채글 일거요]**  
   - `책을`：終聲 ㄱ 遇到母音 ㅇ 向後連音 ➔ [채글]。
   - `읽어요`：雙收音 `ㄺ` 遇到後方母音開頭的語尾 `-어요` 時，**左邊 ㄹ 留在原位，右邊 ㄱ 移到後方開頭連音** ➔ [일거요]。
2. **음식이 맛있었어요** ➔ **[음시기 마시써써요]**  
   - `맛있-` 的收音 ㅅ 連音至 있 ➔ [마싣-]，再遇 과거시제 었어요 連音 ➔ **[마시써써요]**。

</details>
