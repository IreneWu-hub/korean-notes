# 韓語數詞與計量單位速查表

韓語的數字系統分為**「漢字詞數字 (일, 이, 삼...)」**與**「固有詞數字 (하나, 둘, 셋...)」**兩大體系。在生活點餐、購物結帳、計算數量與報時間（點鐘）時，使用的是**固有詞數字**。

## 4. 課堂重要筆記辨析：마리 vs 머리

很多初學者在造句時容易將「動物隻數」與「頭部」混淆，請務必辨析：

:::caution[⚠️ 經典發音與用字陷阱]
* ❌ `고양이 한 머리 있어요` (錯誤說法！)
  * **머리**：人的**「頭部」**或頭上的**「頭髮」**（例如：`머리가 아파요` 頭痛、`머리를 잘라요` 剪頭髮）。
* ✅ `고양이 한 마리 있어요` (正確說法！)
  * **마리**：專門計算**動物隻數**的量詞單位（貓、狗、魚、鳥等）。
:::

## 5. 疑問冠形詞與代名詞指示系統

### ① 疑問冠形詞：무슨 + N (什麼... / 哪種...)

* <KoreanAudio text="무슨 일하세요?" label="您從事什麼工作呢？(音變: [무슨닐 하세요])" />

* <KoreanAudio text="이거 누구 거예요?" label="這是誰的？" />

* <KoreanAudio text="선생님 거예요" label="是老師的。" />

## 7. 時間花費與耗時句型：[時間量詞] + 걸리다 (Lesson 12)

描述從出發地到目的地「交通需要花費多少時間」的固定搭配動詞為 **걸리다 (花費時間)**：

> **核心句型公式**：  
> `[出發地]` + **에서** + `[目的地]` + **까지** + `[交通工具]` + **-(으)로** + `[時間]` + **걸려요 / 걸렸어요**

* **詢問耗時**：<KoreanAudio text="비행기로 얼마나 걸려요?" label="搭飛機需要花多久時間？" />
* **回答耗時**：<KoreanAudio text="비행기로 2시간 걸렸어요" label="搭飛機花了 2 個小時。(過去式 걸렸어요)" />
* **市區通勤**：<KoreanAudio text="집에서 회사까지 지하철로 40분 걸려요" label="從家裡到公司搭地鐵需要 40 分鐘。" />

## 9. 「이・그・저」指示體系三大範疇全覽 (Lesson 12)

韓語指示詞以說話者與對話方的距離為基準，全面貫穿**指物、指人與指地**三大系統：

| 指示類型 | 靠近說話者身邊 (近我) | 靠近對方 / 雙方已知 (近你) | 遠離雙方遠方 (遠) | 疑問未知 (問) |
| :--- | :--- | :--- | :--- | :--- |
| **指物 (這/那/什麼)** | **이것** (口語: 이거) | **그것** (口語: 그거) | **저것** (口語: 저거) | **무엇** (口語: 뭐) |
| **指人 (這位/那人/誰)** | **이 사람 / 이분(敬稱)** | **그 사람 / 그분** | **저 사람 / 저분** | **누구 / 어느 분** |
| **指地 (這裡/那裡/哪裡)** | **여기** | **거기** | **저기** | **어디** |

### 實用心法
* **이 (這)**：就在自己手邊或眼皮底下看得見、摸得著。
* **그 (那)**：在對方身邊，或者「剛才我們聊到的那個話題/事物」。
* **저 (那)**：兩個人都看得到，但都在遠遠的那一頭。
