# 韓語數詞與計量單位速查表

韓語的數字系統分為**「漢字詞數字 (일, 이, 삼...)」**與**「固有詞數字 (하나, 둘, 셋...)」**兩大體系。在生活點餐、購物結帳、計算數量與報時間（點鐘）時，使用的是**固有詞數字**。

---

## 4. 課堂重要筆記辨析：마리 vs 머리

很多初學者在造句時容易將「動物隻數」與「頭部」混淆，請務必辨析：

:::caution ⚠️ 經典發音與用字陷阱
* ❌ `고양이 한 머리 있어요` (錯誤說法！)
  * **머리**：人的**「頭部」**或頭上的**「頭髮」**（例如：`머리가 아파요` 頭痛、`머리를 잘라요` 剪頭髮）。
* ✅ `고양이 한 마리 있어요` (正確說法！)
  * **마리**：專門計算**動物隻數**的量詞單位（貓、狗、魚、鳥等）。
:::

## 5. 疑問冠形詞與代名詞指示系統

### ① 疑問冠形詞：무슨 + N (什麼... / 哪種...)
修飾名詞，用來詢問對方的種類、屬性或內容：

* <KoreanAudio text="무슨 영화를 봐요?" label="看什麼電影呢？" />
* <KoreanAudio text="무슨 음식을 좋아해요?" label="喜歡什麼樣的食物呢？" />
* <KoreanAudio text="무슨 일하세요?" label="您從事什麼工作呢？(音變: [무슨닐 하세요])" />

### ② 所有物詢問：누구 거예요? (這是誰的？)
* <KoreanAudio text="이거 누구 거예요?" label="這是誰的？" />
* <KoreanAudio text="제 거예요" label="是我的。(禮貌敬語)" />
* <KoreanAudio text="선생님 거예요" label="是老師的。" />

### ③ 空間方位指示代名詞 (Lesson 11)
韓語以「說話者」與「聽話者」的相對距離為基準劃分空間：

| 代名詞 | 空間相對位置 | 中文意涵 | 常用例句 |
| :--- | :--- | :--- | :--- |
| **여기** | 靠近說話者身邊 (近) | 這裡、此處 | <KoreanAudio text="여기서 드세요" label="請在這邊用。" /> |
| **거기** | 靠近聽話者 / 對話雙方已知 | 那裡 (靠近你) | <KoreanAudio text="거기 뭐가 있어요?" label="那裡有什麼？" /> |
| **저기** | 距離雙方皆較遠之可視處 | 那裡 (遠方) | <KoreanAudio text="저기 편의점이 있어요" label="那裡有一家便利商店。" /> |
| **어디** | 疑問代名詞 | 哪裡 | <KoreanAudio text="화장실이 어디예요?" label="洗手間在哪裡？" /> |
