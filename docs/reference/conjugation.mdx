# 動詞與形容詞時態變化速查表

韓文動詞與形容詞的原形皆以 **「-다」** 結尾。日常對話中最廣泛使用的非格式體尊敬階為 **「-아요 / -어요 / -여요(해요)」**。

---

## 1. 現在式基本變化：-아요 / -어요

去掉了原形結尾的 **「-다」** 之後，觀察動詞詞幹最後一個母音：

### ① 陽性母音 (ㅏ, ㅗ) ➔ 接 `-아요`
* <KoreanWord ko="가다" zh="去" /> ➔ 가 + 아요 ➔ <KoreanWord ko="가요" zh="去 (現在式)" />
* <KoreanWord ko="오다" zh="來" /> ➔ 오 + 아요 ➔ <KoreanWord ko="와요" zh="來 (現在式)" />
* <KoreanWord ko="보다" zh="看" /> ➔ 보 + 아요 ➔ <KoreanWord ko="봐요" zh="看 (現在式)" />
* <KoreanWord ko="앉다" zh="坐" /> ➔ 앉 + 아요 ➔ <KoreanWord ko="앉아요" zh="請坐/坐 (現在式)" />

### ② 陰性母音 (ㅓ, ㅜ, ㅣ, ㅡ 等非 ㅏ, ㅗ) ➔ 接 `-어요`
* <KoreanWord ko="먹다" zh="吃" /> ➔ 먹 + 어요 ➔ <KoreanWord ko="먹어요" zh="吃 (現在式)" />
* <KoreanWord ko="마시다" zh="喝" /> ➔ 마시 + 어요 ➔ <KoreanWord ko="마셔요" zh="喝 (現在式)" />
* <KoreanWord ko="배우다" zh="學" /> ➔ 배우 + 어요 ➔ <KoreanWord ko="배워요" zh="學習 (現在式)" />
* <KoreanWord ko="읽다" zh="讀" /> ➔ 읽 + 어요 ➔ <KoreanWord ko="읽어요" zh="讀 (現在式)" />

### ③ 所有 하다 結尾的動詞 ➔ 變成 `-해요`
* <KoreanWord ko="공부하다" zh="唸書" /> ➔ <KoreanWord ko="공부해요" zh="唸書 (現在式)" />
* <KoreanWord ko="일하다" zh="工作" /> ➔ <KoreanWord ko="일해요" zh="工作 (現在式)" />
* <KoreanWord ko="좋아하다" zh="喜歡" /> ➔ <KoreanWord ko="좋아해요" zh="喜歡 (現在式)" />

---

## 2. 過去式變化：-았/었어요

在現在式基礎上，將詞尾換成 **-았어요 / -었어요 / -했어요**：

| 原形 | 現在式 | 過去式 (已發生) | 點擊聽發音 |
| :--- | :--- | :--- | :--- |
| <KoreanWord ko="가다" zh="去" /> | 가요 | **갔어요** | <KoreanAudio text="어제 학교에 갔어요" label="昨天下課去了學校" /> |
| <KoreanWord ko="먹다" zh="吃" /> | 먹어요 | **먹었어요** | <KoreanAudio text="밥을 먹었어요" label="已經吃過飯了" /> |
| <KoreanWord ko="공부하다" zh="學習" /> | 공부해요 | **공부했어요** | <KoreanAudio text="한국어를 공부했어요" label="學了韓語" /> |

---

## 3. 格式體尊敬階：-ㅂ니다 / -습니다
常用於正式演講、新聞廣播、自我介紹、向長輩或初次見面商務場合：

* **詞幹無收音：** 接 `-ㅂ니다`
  * <KoreanWord ko="가다" zh="去" /> ➔ <KoreanWord ko="갑니다" zh="去 (敬語)" />
  * <KoreanWord ko="감사하다" zh="感謝" /> ➔ <KoreanWord ko="감사합니다" zh="非常感謝" />
* **詞幹有收音：** 接 `-습니다`
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="먹습니다" zh="吃 (敬語)" />
  * <KoreanWord ko="좋다" zh="好" /> ➔ <KoreanWord ko="좋습니다" zh="好 (敬語)" />

---

## 4. 表達願望：-고 싶어요 (想做...)
接在動詞詞幹後方，不論是否有收音，皆直接接 **-고 싶어요**：

* <KoreanWord ko="가고 싶어요" zh="想要去" />
* <KoreanWord ko="먹고 싶어요" zh="想要吃" />
* <KoreanWord ko="한국에 여행 가고 싶어요" zh="想去韓國旅遊" />
