# 動詞與形容詞時態變化速查表

韓文動詞與形容詞的原形皆以 **「-다」** 結尾。日常對話中最廣泛使用的非格式體尊敬階為 **「-아요 / -어요 / -여요(해요)」**。本篇統整了課堂中常用的各類時態、語氣句型及關鍵不規則變化規則。

---

## 1. 現在式基本變化：-아요 / -어요

去掉了原形結尾的 **「-다」** 之後，觀察動詞詞幹最後一個母音：

### ① 陽性母音 (ㅏ, ㅗ) ➔ 接 `-아요`
* <KoreanWord ko="가다" zh="去" /> ➔ 가 + 아요 ➔ <KoreanWord ko="가요" zh="去 (現在式)" />
* <KoreanWord ko="오다" zh="來" /> ➔ 오 + 아요 ➔ <KoreanWord ko="와요" zh="來 (現在式)" />
* <KoreanWord ko="보다" zh="看" /> ➔ 보 + 아요 ➔ <KoreanWord ko="봐요" zh="看 (現在式)" />
* <KoreanWord ko="앉다" zh="坐" /> ➔ 앉 + 아요 ➔ <KoreanWord ko="앉아요" zh="請坐/坐 (現在式)" />

### ② 陰性母音 (ㅓ, ㅜ, ㅣ, ㅡ 等非 ㅏ, ㅗ) ➔ 接 `-어요`
* <KoreanWord ko="먹다" zh="吃" /> ➔ 먹 + 어요 ➔ <KoreanWord ko="먹어요" zh="吃 (現在式)" />
* <KoreanWord ko="마시다" zh="喝" /> ➔ 마시 + 어요 ➔ <KoreanWord ko="마셔요" zh="喝 (現在式)" />
* <KoreanWord ko="배우다" zh="學" /> ➔ 배우 + 어요 ➔ <KoreanWord ko="배워요" zh="學習 (現在式)" />
* <KoreanWord ko="읽다" zh="讀" /> ➔ 읽 + 어요 ➔ <KoreanWord ko="읽어요" zh="讀 (現在式)" />

### ③ 所有 하다 結尾的動詞 ➔ 變成 `-해요`
* <KoreanWord ko="공부하다" zh="唸書" /> ➔ <KoreanWord ko="공부해요" zh="唸書 (現在式)" />
* <KoreanWord ko="일하다" zh="工作" /> ➔ <KoreanWord ko="일해요" zh="工作 (現在式)" />
* <KoreanWord ko="좋아하다" zh="喜歡" /> ➔ <KoreanWord ko="좋아해요" zh="喜歡 (現在式)" />

## 2. 過去式變化：-았/었어요

在現在式的母音基礎上，將詞尾換成 **-았어요 / -었어요 / -했어요**：

| 原形 | 現在式 | 過去式 (已發生) | 點擊聽發音 |
| :--- | :--- | :--- | :--- |
| <KoreanWord ko="가다" zh="去" /> | 가요 | **갔어요** | <KoreanAudio text="어제 학교에 갔어요" label="昨天下課去了學校" /> |
| <KoreanWord ko="먹다" zh="吃" /> | 먹어요 | **먹었어요** | <KoreanAudio text="밥을 먹었어요" label="已經吃過飯了" /> |
| <KoreanWord ko="공부하다" zh="學習" /> | 공부해요 | **공부했어요** | <KoreanAudio text="한국어를 공부했어요" label="學了韓語" /> |

### 💡 名詞過去式：-이었어요 / -였어요 (那時是...) (Lesson 13)
當描述「過去那時的身份、狀況或價格」時，名詞的過去式不是接 `-았/었어요`，而是接 **-이었어요 / -였어요**：

* **名詞有收音：** 接 `-이었어요`
  * <KoreanWord ko="방학" zh="放假" /> ➔ <KoreanWord ko="방학이었어요" zh="那時是放假" />
  * <KoreanWord ko="선생님" zh="老師" /> ➔ <KoreanWord ko="선생님이었어요" zh="以前是老師" />
* **名詞無收音：** 接 `-였어요`
  * <KoreanWord ko="휴가" zh="休假" /> ➔ <KoreanWord ko="휴가였어요" zh="那時是休假" />
  * <KoreanWord ko="의사" zh="醫生" /> ➔ <KoreanWord ko="의사였어요" zh="以前是醫生" />

> **🛒 旅遊買東西問價對比：**
> * 現在問價：<KoreanAudio text="이거 얼마예요?" label="這個多少錢？(現在式 -예요)" />
> * 買完/回國後詢問：<KoreanAudio text="그거 얼마였어요?" label="那個那時候買多少錢？(過去式 -였어요)" />

## 3. 未來式與打算：-(으)ㄹ 거예요

常用於表達「未來的個人打算、意志或預計行程」。

:::tip[🔊 發音重點]
書寫為 **거예요**，但在韓國人的口語中習慣發濃音（硬音化），讀成 **[꺼예요]**！
:::

* **詞幹無收音 或 ㄹ收音：** 接 `-ㄹ 거예요`
  * <KoreanWord ko="가다" zh="去" /> ➔ <KoreanWord ko="갈 거예요" zh="打算去 / 將要去" />
  * <KoreanWord ko="하다" zh="做" /> ➔ <KoreanWord ko="할 거예요" zh="打算做" />
  * <KoreanWord ko="만들다" zh="製作 (ㄹ收音)" /> ➔ <KoreanWord ko="만들 거예요" zh="打算做" />
* **詞幹有收音 (除ㄹ外)：** 接 `-을 거예요`
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="먹을 거예요" zh="打算吃 [머글 꺼예요]" />
  * <KoreanWord ko="읽다" zh="讀" /> ➔ <KoreanWord ko="읽을 거예요" zh="打算讀 [일글 꺼예요]" />

### 常用情境例句
* <KoreanWord ko="주말에 뭐 할 거예요?" zh="週末打算做什麼？" />
* <KoreanWord ko="친구랑 저녁을 먹을 거예요." zh="打算和朋友吃晚餐。" />
* <KoreanWord ko="한국에 여행 갈 거예요." zh="打算去韓國旅遊。" />

## 4. 格式體尊敬階：-ㅂ니다 / -습니다
常用於正式演講、新聞廣播、自我介紹、向長輩或初次見面商務場合：

* **詞幹無收音：** 接 `-ㅂ니다`
  * <KoreanWord ko="가다" zh="去" /> ➔ <KoreanWord ko="갑니다" zh="去 (敬語)" />
  * <KoreanWord ko="감사하다" zh="感謝" /> ➔ <KoreanWord ko="감사합니다" zh="非常感謝" />
* **詞幹有收音：** 接 `-습니다`
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="먹습니다" zh="吃 (敬語)" />
  * <KoreanWord ko="좋다" zh="好" /> ➔ <KoreanWord ko="좋습니다" zh="好 (敬語)" />

## 5. 表達願望：-고 싶어요 (想做...)

* <KoreanWord ko="가고 싶어요" zh="想要去" />
* <KoreanWord ko="먹고 싶어요" zh="想要吃" />

## 6. 義務與必須：-아/어야 돼요 (得... / 必須...)

表達義務、必要性或「必須做某事」。口語中常將 `되다` 寫為 `돼요`（或替換為 `해요`）：

* **陽性母音 (ㅏ, ㅗ)：** 接 `-아야 돼요`
  * <KoreanWord ko="가다" zh="去" /> ➔ <KoreanWord ko="가야 돼요" zh="得去 / 必須去" />
  * <KoreanWord ko="내리다" zh="下車" /> (ㅓ母音) ➔ <KoreanWord ko="내려야 돼요" zh="應該下車" />
  * <KoreanWord ko="사다" zh="買" /> ➔ <KoreanWord ko="표를 사야 돼요" zh="必須買票" />
* **陰性母音：** 接 `-어야 돼요`
  * <KoreanWord ko="벗다" zh="脫掉" /> ➔ <KoreanWord ko="신발을 벗어야 돼요" zh="必須脫鞋" />
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="밥을 먹어야 돼요" zh="必須吃飯" />
* **하다 動詞：** 變為 `-해야 돼요`
  * <KoreanWord ko="환승하다" zh="轉乘" /> ➔ <KoreanWord ko="환승해야 돼요" zh="必須換乘" />
  * <KoreanWord ko="충전하다" zh="儲值" /> ➔ <KoreanWord ko="교통카드를 충전해야 돼요" zh="得儲值交通卡" />

## 7. 許可與請求：-아/어도 돼요? (可以...嗎？)

請求對方許可做某事。常翻成「我可以……嗎？」：

* <KoreanWord ko="가다" zh="去" /> ➔ <KoreanWord ko="화장실에 가도 돼요?" zh="我可以去洗手間嗎？" />
* <KoreanWord ko="앉다" zh="坐" /> ➔ <KoreanWord ko="여기 앉아도 돼요?" zh="可以坐這裡嗎？" />
* <KoreanWord ko="사진을 찍다" zh="拍照" /> ➔ <KoreanWord ko="사진을 찍어도 돼요?" zh="可以拍照嗎？" />

### 💡 延伸「嘗試句型」：-아/어 보다 (嘗試做某事)
當 `-아/어 보다`（試試看）與 `-도 돼요?` 結合，便成為旅遊購物與品嚐美食的萬能句型：

| 句型 | 中文釋義 | 實用例句 |
| :--- | :--- | :--- |
| **입어 봐도 돼요?** | 可以試穿看看嗎？ | <KoreanAudio text="한번 입어 봐도 돼요?" label="可以試穿一次看看嗎？" /> |
| **먹어 봐도 돼요?** | 可以試吃看看嗎？ | <KoreanAudio text="이거 먹어 봐도 돼요?" label="這個可以試吃看看嗎？" /> |
| **신어 봐도 돼요?** | 可以試穿鞋子看看嗎？ | <KoreanAudio text="이 신발 신어 봐도 돼요?" label="這雙鞋可以試穿嗎？" /> |

## 8. 移動目的表達：-(으)러 가다 / 오다 (去做某事)

接在動詞後方，與移動動詞（`가다`, `오다`, `다니다`）搭配，表示「前往某地是為了做某件事」：

* **無收音 或 ㄹ收音：** 接 `-러 가다 / 오다`
  * <KoreanWord ko="보다" zh="看" /> ➔ <KoreanWord ko="콘서트를 보러 가요" zh="去看演唱會" />
  * <KoreanWord ko="사다" zh="買" /> ➔ <KoreanWord ko="옷을 사러 가요" zh="去買衣服" />
  * <KoreanWord ko="놀다" zh="玩 (ㄹ收音)" /> ➔ <KoreanWord ko="놀러 가요" zh="去玩" />
* **有收音 (除ㄹ外)：** 接 `-으러 가다 / 오다`
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="밥 먹으러 가요" zh="去吃飯" />
  * <KoreanWord ko="찾다" zh="領取/尋找" /> ➔ <KoreanWord ko="돈을 찾으러 가요" zh="去領錢" />

* **有收音：** 接 `-으려면`
  * <KoreanWord ko="먹다" zh="吃" /> ➔ <KoreanWord ko="먹으려면" zh="如果要吃的話" />

## 11. 形容詞修飾名詞冠詞形：-(으)ㄴ + N

形容詞原形修飾後方名詞時，將原形結尾的 **「-다」** 轉化為冠詞形：

* **詞幹無收音：** 接 `-ㄴ`
  * <KoreanWord ko="크다" zh="大" /> ➔ <KoreanWord ko="큰 옷" zh="大件的衣服" />
  * <KoreanWord ko="예쁘다" zh="漂亮" /> ➔ <KoreanWord ko="예쁜 가방" zh="漂亮的包包" />
  * <KoreanWord ko="바쁘다" zh="忙碌" /> ➔ <KoreanWord ko="바쁜 사람" zh="忙碌的人" />
* **詞幹有收音：** 接 `-은`
  * <KoreanWord ko="작다" zh="小" /> ➔ <KoreanWord ko="작은 사이즈" zh="小尺寸" />
  * <KoreanWord ko="많다" zh="多" /> ➔ <KoreanWord ko="많은 사람" zh="很多人" />
* **`있다 / 없다` 結尾的形容詞：** 一律接 `-는`
  * <KoreanWord ko="맛있다" zh="好吃" /> ➔ <KoreanWord ko="맛있는 음식" zh="好吃的食物" />
  * <KoreanWord ko="재미있다" zh="有趣" /> ➔ <KoreanWord ko="재미있는 영화" zh="好看的電影" />

## 12. 關鍵不規則與母音脫落活用規則

### ① ㅂ 不規則 (Lesson 07)
詞尾收音為 **ㅂ** 的形容詞，在遇到母音開頭的詞尾時，**ㅂ 會轉化為 우**（우 + 어요 ➔ **워요**）：

* <KoreanWord ko="쉽다" zh="簡單 (ㅂ不規則)" /> ➔ 쉽 + 우 + 어요 ➔ <KoreanWord ko="쉬워요" zh="很簡單" />
* <KoreanWord ko="어렵다" zh="困難" /> ➔ 어렵 + 우 + 어요 ➔ <KoreanWord ko="어려워요" zh="很難" />
* <KoreanWord ko="즐겁다" zh="愉快" /> ➔ <KoreanWord ko="즐거워요" zh="很愉快" />
* ⚠️ **特別對比規則動詞**：<KoreanWord ko="쉬다" zh="休息 (無收音規則動詞)" /> ➔ 直接接 `-어요` ➔ <KoreanWord ko="쉬어요" zh="休息 (現在式)" />

### ② ㅡ 脫落現象 (Lesson 10)
詞幹母音為 **ㅡ** 的動詞或形容詞，遇到母音詞尾時，**ㅡ 會脫落**：

* <KoreanWord ko="크다" zh="大" /> ➔ ㅡ 脫落後接 `-어요` ➔ <KoreanWord ko="커요" zh="很大" />
* <KoreanWord ko="예쁘다" zh="漂亮" /> ➔ ㅡ 脫落，觀察前一音節 예(陰性) ➔ <KoreanWord ko="예뻐요" zh="很漂亮" />
* <KoreanWord ko="바쁘다" zh="忙碌" /> ➔ ㅡ 脫落，觀察前一音節 바(陽性) ➔ <KoreanWord ko="바빠요" zh="很忙" />

### ③ 르 不規則 (Lesson 10)
詞幹以 **르** 結尾的字，遇到母音開頭詞尾時，前一個字會**補上 ㄹ 收音**，且 르 轉化為 **라 / 러**：

* <KoreanWord ko="다르다" zh="不同/別的" /> ➔ 前字補 ㄹ，接 아요 ➔ <KoreanWord ko="달라요" zh="不同" />（修飾名詞形：<KoreanWord ko="다른 옷" zh="別的衣服" />）
* <KoreanWord ko="모르다" zh="不知道" /> ➔ 前字補 ㄹ，接 아요 ➔ <KoreanWord ko="몰라요" zh="不知道" />
* <KoreanWord ko="빠르다" zh="快速" /> ➔ 前字補 ㄹ，接 아요 ➔ <KoreanWord ko="빨라요" zh="很快" />
* <KoreanWord ko="고르다" zh="挑選" /> ➔ 前字補 ㄹ，接 아요 ➔ <KoreanWord ko="골라요" zh="挑選" />

## 13. 出門去回與生活寒暄動詞辨析 (Lesson 11)

表達「出門、去某地並返回」的三種層次與習慣用語：

| 表達方式 | 語意層次說明 | 常用情境 |
| :--- | :--- | :--- |
| **갔어요** | 單純過去式，「去了某地」（未強調是否回來）。 | <KoreanAudio text="어제 명동에 갔어요" label="昨天去了明洞。" /> |
| **갔다 왔어요** | 口語去去就回，「去了一趟回來了」。 | <KoreanAudio text="화장실에 갔다 왔어요" label="去了一趟洗手間回來了。" /> |
| **다녀왔어요** | 標準敬語報備句，「我回來了！」。 | <KoreanAudio text="다녀왔습니다" label="我出門回來了！(進家門)" /> |

### 路上叮嚀與問候金句
* **送對方出門**：<KoreanAudio text="잘 다녀오세요" label="祝一路平安順心！慢走～" />（敬語寒暄） / <KoreanAudio text="잘 갔다 와요" label="路上小心，快去快回！" />（親切口語）
* **問對方玩得如何**：<KoreanAudio text="잘 놀았어요?" label="玩得開心嗎？" /> / <KoreanAudio text="재미있었어요?" label="好玩嗎？(口語縮寫: 재밌었어요?)" />

## 14. 萬用生活動詞「되다」的多樣活用 (Lesson 12)

「되다」是韓語生活中使用頻率極高的萬用動詞，具備「可以、可行、行得通、辦成、完成」等多種含義：

| 活用形態 | 時態與語氣 | 中文釋義 | 經典生活例句 |
| :--- | :--- | :--- | :--- |
| **돼요** | 現在式肯定/疑問 | 可以、行 | <KoreanAudio text="카드 돼요?" label="可以刷卡嗎？" /><br/><KoreanAudio text="포장 돼요?" label="可以外帶嗎？" /> |
