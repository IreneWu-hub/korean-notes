## 🚀 待收錄課堂內容預覽 (Lesson 07 ~ 11)

每隔數堂課會進行一次跨課堂的批次大統整，目前待收錄的重點主題包含：

1. **Lesson 07**：
   - 節慶連假祝福（`즐거운 연휴 보내세요`）
   - `에서 ~까지`（從...到...）
   - `ㅂ` 不規則形容詞變化（`쉽다 ➔ 쉬워요` vs `쉬다 ➔ 쉬어요`）
   - 反問語氣 `N-은/는요?`
2. **Lesson 08**：
   - 核心文法：義務 `-(으)아/어야 돼요`（必須/得要）vs 許可 `-아/어도 돼요?`（可以...嗎？）
   - 嘗試句型：`-아/어 보다` ➔ `입어 봐도 돼요?`（可以試穿嗎？）
   - 交通意圖句型：`-(으)려면`（如果要前往...的話）
   - 交通手段助詞：`-(으)로`
3. **Lesson 09**：
   - 未來式與個人規劃：`-(으)ㄹ 거예요` [發音：꺼예요]
   - 疑問詞 `무슨 + N` 與所有物詢問 `누구 거예요?`
   - **韓語固有數詞專題**：`하나 ~ 열` (1~10) 以及接量詞縮短形（`한, 두, 세, 네, 스무`）
   - 常用單位量詞（`개, 잔, 병, 마리, 명` 等，強調 `마리` vs `머리`）
4. **Lesson 10**：
   - 移動目的句型：`-(으)러 가다 / 오다`（去做某事 / 來做某事）
   - 能力與許可句型：`-(으)ㄹ 수 있다 / 없다`（能/不能；可以/不可以）
   - 形容詞修飾名詞冠詞形：`-(으)ㄴ + N`（`큰 옷`, `작은 옷`, `다른 옷`）
   - `ㅡ` 脫落與 `르` 不規則變化（`커요`, `달라요`, `몰라요`）
   - 地鐵購票、交通卡儲值與服飾店購物殺價詞彙庫
5. **Lesson 11**：
   - 空間指示代名詞（`여기 / 거기 / 저기`）與 11 大核心空間方位詞（`앞, 뒤, 옆, 위, 아래/밑, 안, 밖...`）
   - 空間存在句型：`[名詞] + 은/는 [위치] + 에 있어요`
   - 出門去回三層次（`갔어요 / 갔다 왔어요 / 다녀왔어요`）與寒暄金句（`잘 다녀오세요`）
   - 生活計量（`두 개, 두 잔`）與便利商店情境實用句（`담아 주세요`, `버려 주세요`）
