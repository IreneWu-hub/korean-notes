## 💡 使用指南與複習建議

1. **查動詞原形與變化**：前往 [動詞與時態變化速查表](./conjugation.mdx)，可依陽性/陰性母音迅速查出現在式、過去式、未來式及三大不規則音變規則。
2. **釐清語法成分與助詞**：前往 [常用助詞速查表](./particles.mdx)，辨析主題 `은/는` 與主格 `이/가`，或確認交通工具與方向助詞 `-(으)로` 的接續方式。
3. **生活點餐與買幾杯幾碗**：前往 [數詞與計量單位速查表](./numbers.mdx)，掌握固有詞數量與縮寫（例如：`커피 두 잔`, `사과 세 개`）。
4. **旅行出發前詞彙速記**：前往 [旅遊日常高頻單字庫](./vocabulary.mdx)，點擊小喇叭 🔊 即時聆聽地鐵搭乘、服飾試穿與便利商店常用情境真人發音。
