Lesson #12
旅遊韓語會話馬上開口說

(I.S)의 한국어 수업 2026.10.29

🎯 本堂學習重點

  • 市場逛街與小吃實戰點餐：掌握傳統市場問物名「이게 뭐예요?」、問價格「저건 얼마예요?」、品項指定與數量「파전 하나 주세요」，並學會內用道地說法「여기에서 먹고 갈게요」與外帶句型。
  • 指示代名詞 (이/그/저) 與助詞縮寫系統：融會貫通指物三兄弟視角（이 這、그 那-近對方/已知、저 那-遠方），徹底掌握口語高頻助詞縮寫（主格 이게/그게/저게、受格 이거/그거/저거、主題 이건/그건/저건）與場所代名詞（여기/거기/저기）。
  • 服飾血拼應答與庫存文法辨析：掌握試穿許可（한 번 입어 보셔도 돼요）、尺碼詢問（사이즈 몇이에요?）、確認全新貨（새거 있어요?）與考慮逛逛的委婉推託；並深度辨析限定句「~만 있어요（只有）」與「~밖에 없어요（除了…別無）」的語氣差異。
  • 付款詢問與「되다」核心用法：解析生活萬用動詞「되다（行/可以）」的活用形態，掌握刷卡詢問的三種語氣（카드 돼요? / 카드도 돼요? / 카드도 되나요?）。
  • 旅遊經驗分享與推測語尾：精通出行祝福「잘 다녀오세요」與平安返國「잘 다녀왔어요」，流暢問答旅遊天數（며칠 동안 / 5일 = 닷새）與交通耗時（2시간 걸렸어요），並掌握外觀推測「~아/어 보여요」與直覺感嘆「~겠다」。
Part 1

傳統市場與街頭小吃實戰會話 (시장 구경과 길거리 음식)

在首爾的廣藏市場、通仁市場或釜山的國際市場，攤位上擺滿了各式香氣四溢的道地美食。走進市場，如何詢問食物名稱、確認價錢、指名點餐與選擇用餐方式？讓我們一次掌握最實用的對話！

🔍 初學者超詳細文法拆解專區：「여기에서 먹고 갈게요」

在韓國店家點餐時，店員常會問「드시고 가세요?（要內用嗎？）」。如果要內用，這句話就是最標準自然的回答。這句話是由四個核心成分巧妙組合而成：

處所代名詞 + 助詞
여기에서
在這邊 (口語常縮為 여기서)
動詞詞幹
먹-
吃 (原形：먹다)
順序連接詞尾
-고
……之後、然後
動詞 + 意志語尾
갈게요
가다 + -(으)ㄹ게요 (我會離開)
💡 母語者思維解析：為什麼不是說「여기에서 먹어요」？

雖然講「여기에서 먹을게요」對方也能聽懂，但母語者更習慣使用「~고 가다（做完某事再走）」的複合句構。「먹고 갈게요」字面意思是「吃完再走」，完整傳達了「我會在店裡享用完畢後再離開」的完整動作鏈，聽起來非常流暢且極具母語感！

🍽️ 內用表達方式 (여기서 식사) 店內享用

여기에서 먹고 갈게요.
在這裡吃。（最常用）
먹고 갈 거예요.
打算吃完再走。 (將來時制 -(으)ㄹ 거예요)

🥡 外帶表達方式 (포장하기) 打包帶走

포장해 주세요.
請幫我打包外帶。（포장 = 包裝）
가지고 갈게요. (가져갈게요)
我帶走吃。（가지다 + -고 가다）

付款詢問：動詞「되다（可以／行得通）」的三種問法

在韓國傳統市場或路邊攤，許多攤位已普及刷卡機，但仍有部分只收現金。詢問「可不可以刷卡」時，核心動詞是「되다（原形：成為、行、可以）」，現在式活用為「돼요」：

카드 돼요?
日常口語 (簡潔直率)

可以刷卡嗎？直接詢問最普遍。

카드도 돼요?
加入助詞 -도 (也)

（除了現金外）也可以刷卡嗎？

카드도 되나요?
推薦！最禮貌婉轉

請問也可以刷卡嗎？語尾 -나요? 親切柔和。

🏪 攤販常見回答：
⭕ 可刷卡： 네, 돼요. / 네, 카드 돼요.
❌ 僅收現金： 죄송해요, 현금만 돼요. (不好意思，只收現金)
Part 2

指示代名詞視角與助詞縮寫系統 (이・그・저 指示體系)

指示詞視角三兄弟：이（這）、그（那）、저（那）

韓語的指示冠詞「이、그、저」本身不能單獨作主語，必須與代表「物品」的名詞（것 ➔ 口語縮寫 거）或「場所」名詞（곳 / 기）結合：

이 (i)
靠近說話者 (近)

這……（This）

手邊摸得到或眼前的物品

그 (geu)
靠近聽話者 / 對話已知 (中)

那……（That - near you）

靠近對方，或雙方皆知之事物

저 (jeo)
雙方皆遠處 (遠)

那……（That over there）

離雙方都遠、目視可及的遠處

核心文法對比：限定表達「~만 있어요（只有）」vs「~밖에 없어요（除了…別無）」

當架上只剩展示品，店員常會說「只剩這一個」。韓語中有兩種表達方式，語意重點與語氣強烈程度有所不同：

肯定句搭配：명사 + 만 客觀陳述「只有」
아니요, 이거 하나만 남았어요 / 있어요.

沒有，只剩下這一個了。 / 只有這一個。

解析：助詞「-만」接在名詞後，後方接肯定句（있어요 / 남았어요），語氣客觀平實。
否定句搭配：명사 + 밖에 + 없다 強烈語氣「除了…別無」
아니요, 이거 (하나)밖에 없어요.

沒有，除了這個之外沒有別的了。（只有這件了）

解析：「밖（外）」＋「-에（在）」，後方固定接否定詞（없다 / 모르다 / 못하다），強調「極限、無奈、別無選擇」。

推測與感嘆：外觀推測「~아/어 보여요」vs 直覺感嘆「~겠다」

看見剛回國的朋友神情、或是看見朋友拍的泰國美食照片時，母語者會使用不同的語尾表達感受：

視覺外觀判斷：형용사 + -아/어 보이다
피곤해 보여요.

你看起來很疲倦。（피곤하다 疲倦 ➔ 피곤해 보이다）

맛있어 보여요.

看起來很好吃。（맛있다 好吃 ➔ 맛있어 보이다）

直覺推測與感嘆：형용사 + -겠다!
맛있겠다!

哇！一定很好吃！（口水直流、直覺感嘆）

피곤하겠다!

你一定累壞了吧！（將心比心的共鳴感嘆）

Part 5

易混淆詞彙辨析與課堂花絮 (어휘와 수업 에피소드)

詞彙精準辨析：질문 (Question 提問) vs 문제 (Problem 難題／考題)

中文都常說「問題」，但韓語中有著非常明確的概念劃分，千萬不能混用：

질문 [質問] (Question)
因為好奇或不懂而「發問」

常用搭配： 질문 있어요? (大家有疑問／要提問嗎？)

動詞結合： 질문하다 (提問、發問)

문제 [問題] (Problem / Trouble / Exam)
困難、疑難雜症或試卷考題

疑難困難： 문제가 있어요. (出問題了／有麻煩了)

試卷試題： 문제를 풀어요. (解答題目)

漢字詞：案內
안내 [案內]

指引、導覽、通知。（如：안내 방송 廣播通知）

漢字詞：案內所
안내소 [案內所]

服務台、詢問處、旅遊諮詢中心。（如：관광 안내소 觀光諮詢所）
