📖 核心文法專題 (문법 정리)

重點 1 ㅂ 不規則變化 (ㅂ 불규칙)

部分以「ㅂ」結尾的形容詞或動詞，遇到母音開頭的文法（如 -아요/어요）時，語幹底下的 ㅂ 會變成「우」 (極少數變成 오)。

맵다 (辣)
➔
매워요 (맵 + 우 + 어요)
싱겁다 (清淡)
➔
싱거워요 (싱겁 + 우 + 어요)

重點 2 否定語氣對比：안 vs 못

雖然兩者都表示否定，但背後隱含的原因截然不同，是韓國人非常重視的語感差異。

안 主觀意願的否定 (不...)
表達「我有能力做，但我不想/我不做」。
Q: 저녁을 먹었어요? (吃晚餐了嗎？)
A: 안 먹었어요. 다이어트해요. (沒吃。我在減肥。) ➔ 主觀選擇不吃。
못 客觀能力的否定 (無法... / 不能...)
表達「我想做，但因為外部因素或能力不足而無法達成」。
Q: 저녁을 먹었어요? (吃晚餐了嗎？)
A: 못 먹었어요. 바빴어요. 시간이 없어요. (沒吃。太忙了。沒有時間。) ➔ 想吃但客觀條件不允許。
A: 매운 거 못 먹어요. (我不敢/無法吃辣。)

重點 3 構詞法：動詞名詞化 (-(으)ㅁ)

將動詞語幹加上「ㅁ」或「음」，可以將動作轉換為「名詞」狀態。許多韓式料理的名稱都是這樣來的！

비비다 (拌)
비빔 (拌料)
➔ 비빔밥 (拌飯)
볶다 (炒)
볶음 (炒料)
➔ 볶음밥 (炒飯)
그리다 (畫 - 動詞)
그림 (圖畫 - 名詞)
➔ 그림을 그리다 (畫畫)

💬 實用句型與情境 (상황별 대화)

📍 情境：連續點餐與連接詞

句型 1
칼국수 하나랑 메밀국수 하나 주세요.
請給我一份刀削麵和一份蕎麥麵。(口語常用 -랑/이랑)
句型 2
칼국수 하나하고 메밀국수 하나 주세요.
請給我一份刀削麵和一份蕎麥麵。(萬用連接詞 -하고)
句型 3
칼국수 하나 주세요. 그리고 메밀국수(도) 하나 주세요.
請給我一份刀削麵。然後/還有(也)請給我一份蕎麥麵。(分句補充)
💡
連續點餐時，也可以直接用逗號連接，如：
칼국수 하나, 메밀국수 하나, 잔치국수 하나 주세요.

📍 情境：詢問經驗與客製化口味

經驗
가 봤어요? / ____ 먹어 봤어요?
有去過嗎？ / 有吃過____嗎？
(보다(看) -> 봐요 -> 봤어요：加上 -아/어 보다 表示「嘗試、經驗」)
回應
네, 먹어 봤어요. / 아니요, 안(못) 먹어 봤어요.
有，我吃過。 / 沒有，我不曾(沒機會)吃過。
推薦
꼭 한 번 먹어 보세요.
請務必吃吃看一次。
口味
덜 맵게 해주세요.
請幫我弄得比較不辣。 (덜 = 比較少、不及)
提問
안 짜요? / 매운 거 잘 먹어요?
不會太鹹嗎？ / 你很能吃辣的東西嗎？

📚 主題分類單字與發音 (어휘 및 발음)

👅 五味形容詞

  • 싱겁다 ➔ 싱거워요 清淡 (ㅂ不規則)

  • 잘 모르겠어요 我不太清楚/我不知道

🗣️ [補充發音秘訣] 複合收音發音口訣：「2027 念右邊」

韓文有許多由雙子音組成的「複合收音 (겹받침)」。通常我們念「左邊」的子音，但您可以記住一個口訣：遇到 「ㄺ, ㄻ, ㄿ」 時，原則上要發 右邊 的音！

ㄹㄱ (念ㄱ) ➔ 例：닭 [닥] (雞)
ㄹㅁ (念ㅁ) ➔ 例：젊다 [점따] (年輕)
ㄹㅍ (念ㅂ) ➔ 例：읊다 [읍따] (吟詠)
⚠️ ㄹㅂ 例外 ➔ 通常念左邊 (ㄹ)，如 여덟 [여덜] (八)
