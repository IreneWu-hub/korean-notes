Lesson #11
旅遊韓語會話馬上開口說

(I.S)의 한국어 수업 2026.10.19

🎯 本堂學習重點

  • 空間指示與核心方位體系：精通指示代名詞視角（여기 這裡、저기 那裡-遠處、거기 那裡-近處/對方處），並掌握 11 個核心空間方位詞（앞, 뒤, 옆, 위, 아래/밑, 안, 밖, 왼쪽, 오른쪽, 가운데, 구석）與東南西北四大方向。
  • 空間存在句型「~에 있어요/없어요」：靈活運用核心問句「어디에 있어요?」詢問位置，並能流暢描述物品位置，包括「~하고 ~사이에 있어요」（在……與……之間）及「거실 구석에 있어요」（在客廳角落）。
  • 連音與「의」音變規律：解析「편의점 [펴니점]」的發音秘密（非字首「의」弱化讀為 [이]，搭配終聲 ㄴ 向後連音），掌握自然流暢的母語者發音技巧。
  • 出門去回與生活寒暄金句庫：辨析「갔어요」、「갔다 왔어요」、「다녀왔어요」的語意層次，熟記出門送行叮嚀（잘 다녀오세요）與平安歸來慰問（잘 갔다 왔어요? / 잘 놀았어요?），以及感想縮寫（재미있었어요? = 재밌었어요）。
  • 生活計量與點餐交遞：掌握數字 2（둘 ➔ 두）搭配量詞（두 개、두 잔）的修飾變化，以及交付物品時的親切金句「네, 여기 있어요」與對話轉折詞「그럼」。
Part 1

指示代名詞與空間方位系統 (위치와 방향)

空間指示代名詞：這裡、那裡（近處/遠處）

韓語的位置指示代名詞以「說話者」與「聽話者」的相對距離為核心基準，主要分為三大範疇：

여기
說話者身邊 (近)

這裡、此處

靠近說話者的空間範圍

거기
聽話者身邊 / 對話已知 (近處)

那裡（靠近對方）

靠近聽者的位置，或雙方皆知之處

저기
雙方皆遠處 (遠處)

那裡（遠方）

距離雙方皆較遠、可目視之遠處

💡 老師精闢解惑：아래 vs 밑 的細微差異

  • 아래（廣義的下方）：泛指空間上的較低處、樓下，或抽象地位、年齡、職級較低。例如：樓下 (아래층)。
  • 밑（狹義的底部/正下方）：特別指物體的「正下方、緊貼底部或被遮蓋的陰影處」。例如：汽車底下 (자동차 밑)、箱子底部 (박스 밑)、樹蔭底下 (나무 밑)。在日常口語中兩者很多時候可互換，但講到「底部、正下方」時韓國人極常使用 밑。

四大方位（東西南北）與地理延伸詞彙

韓語的方向詞後面加上「쪽（邊、向）」即為具體方位。

동쪽
東邊 (East)
서쪽
西邊 (West)
남쪽
南邊 (South)
북쪽
北邊 (North)
課堂實用延伸詞彙
동남아시아 여행 東南亞旅行（동남아 + 여행）
북한 北韓（北韓稱「조선」；南韓稱「북한」）
Part 2

空間存在句型與生活造句解析 (어디에 있어요?)

核心文法句型公式

主詞 (名詞) + 이/가 (은/는) + 位置/方位名詞 + 에 있어요 / 없어요
表示「某物在／不在某處」
A 하고 B 사이에 있어요
表示「在 A 和 B 之間」
核心問句 어디에 있어요? （在哪裡？）
컴퓨터 본체는 모니터하고 프린터 사이에 있어요.

中文翻譯：電腦主機在螢幕和印表機之間。

🔍 初學者文法拆解
컴퓨터 본체 電腦主機 는 主題助詞 모니터 螢幕 하고 和/與 (連接助詞) 프린터 印表機 사이 之間 에 地點助詞 (在) 있어요 有 / 存在
고양이가 자동차 밑에 있어요.

中文翻譯：貓咪在汽車底下。

🔍 初學者文法拆解
고양이 貓咪 가 主格助詞 (無收音) 자동차 汽車 밑 底下 / 底部 에 地點助詞 있어요 在 / 有
집은 편의점 위에 있어요.

中文翻譯：我家在便利商店樓上。

🔍 初學者文法拆解
집 家 / 房子 은 主題助詞 (有收音 ㅂ) 편의점 便利商店 [펴니점] 위 上面 / 樓上 에 地點助詞 있어요 在
소파가 거실 구석에 있어요.
沙發在客廳角落。 (거실 = 客廳 / 구석 = 角落)
책상 위에 있어요.
在書桌上面。 (책상 = 書桌)
농구가 의자 뒤에 있어요.
籃球在椅子後面。 (농구 = 籃球 / 의자 = 椅子)
농구가 박스 안에 있어요.
籃球在箱子裡面。 (박스 = 箱子、盒子)

🔊 發音特別解析：편의점 為什麼唸成 [펴니점]？

步驟 1（의 的非字首讀音）：複合母音「의」當它出現在詞中非第一個字時，標準發音弱化發為 [이]。因此「편의」實質發音變成「편이」。

步驟 2（連音現象 연음 법칙）：前一個字「편」帶有終聲收音 ㄴ，後一個音節是以無聲子音 ㅇ 起始的「이」。因此收音 ㄴ 順勢移到後方發音，拼成 [펴니]。

✨ 總結演變公式：편의점 ➔ 편[이]점 ➔ [펴니점]（在韓國生活或旅遊購物時，請自信唸出 [펴니점] 即可！）

Part 3

出門去回與生活寒暄金句庫 (가다 / 다녀오다)

「去」與「去去就回」的三大層次

韓語中表達外出、去某處或辦完事回來的動詞變化非常細膩，請依照語境與語氣精準選擇：

갔어요.
一般過去式 (가다)

去了。

單純描述「人已經前往某地」，未強調是否有回來。

갔다 왔어요.
去去就回 (口語常用)

去了一趟回來了。

갔다가 오다 的縮寫，強調「出門後已經順利回到原點」。

다녀왔어요.
禮貌慣用語 (다녀오다)

我回來了！

回家、旅行或出差返家時最標準、有禮貌的報備句。

👋 送對方出門 / 路上祝福

祝你一路順風、出門順利

잘 갔다 오세요.
路上小心！好好去玩 / 辦事快回（口語親切）。
잘 다녀오세요～～～
祝一路平安順心！慢走～（尊稱禮貌，對長輩、同事、出國旅遊者使用）。
🏠 對方回來時 / 見面寒暄

詢問行程與玩樂體驗

잘 갔다 왔어요?
順利去回來了嗎？/ 去得還順利嗎？
잘 놀았어요?
玩得開心嗎？玩得好嗎？（놀다 = 玩耍、遊玩）

體驗感想問答：好玩嗎？(過去式 vs 現在式口語縮寫)

在韓語口語中，재미있다（有趣、好玩）極常縮寫為 재밌다。時態表達也是出國旅遊回國後聊天必備重點：

過去式 (已結束的旅行/活動)
재미있었어요? = 재밌었어요.

問句：（那時候）好玩嗎？/ 有趣嗎？
答句：很棒、很好玩！

現在式 (正在進行的活動/常態)
재미있어요. = 재밌어요?

問句：好玩嗎？（目前當下）
答句：很有趣、很好玩！

Part 4

生活計量、點餐購物與實用詞彙庫

固有詞數量詞：둘 ➔ 두 的修飾形規則

韓語固有詞數字 1~4（하나, 둘, 셋, 넷）接在單位量詞前面時會產生簡化變形。本課重點掌握數字 2（둘 ➔ 두）：

두 개
兩個（通用物體量詞，如：香蕉、火腿、麵包）
개 = 個
두 잔
兩杯（飲品量詞，如：咖啡、茶、果汁）
잔 = 杯

情境會話：超商與咖啡廳實用交接對話

가
커피 두 잔 주세요.
請給我兩杯咖啡。
가
그럼 바나나도 두 개 주세요.
那麼也請給我兩根香蕉。（그럼 = 那麼 / -도 = 也）
나
네, 여기 있어요.
好的，在這裡（將商品拿給顧客時的標準應答用語）。
