🎯 本堂學習重點

  • 地鐵搭乘與交通問路實戰：學會詢問下車站點（무슨 역에서 내려야 돼요?）、指引搭乘方向（이쪽/저쪽/어느 쪽）、月台搭乘句型（이쪽에서 타시면 돼요）以及 T-money 交通卡現金儲值（만원/이만원 충전해 주세요）。
  • 服飾店購物、試穿與殺價金句：掌握請店員拿取架上衣服（저기 걸려 있는 옷 좀 보여 주실래요?）、詢問試穿許可（한번 입어 봐도 돼요?）、更衣室單字（탈의실 / 피팅룸）以及付現殺價密技（현금이면 얼마예요? / 좀 깎아 주세요）。
  • 兩大核心旅遊文法深度掌握： 徹底理解表示「移動目的」的 -(으)러 가다/오다（旅行、看演唱會、出差），以及表示「能力與許可」的 -(으)ㄹ 수 있다/없다（可以/不能）。
  • 形容詞冠詞形與不規則變化：精熟修飾名詞冠詞形（-ㄴ/은），釐清 크다 ➔ 커요 (ㅡ脫落) ➔ 큰 옷、작다 ➔ 작아요 ➔ 작은 옷、以及 다르다 ➔ 달라요 (르不規則) ➔ 다른 옷。

1. 상황 회화 ① 지하철 타고 이동하기 (搭乘地鐵移動與問路)

🚇 課本情境對話：東大門歷史文化公園站與買票

💬 對話 1：詢問下車站點 (내리는 역 묻기) 首爾地鐵實戰
가

동대문 패션 타운에 가려면 무슨 역에서 내려야 돼요?

如果要去東大門時尚城，應該要在哪一站下車？

나

동대문역사문화공원역에서 내리세요.

請在東大門歷史文化公園站下車。(首爾地鐵 2/4/5 號線轉乘大站)

💬 對話 2：詢問購票處與使用售票機 (표 사기) 票務問答
가

표는 어디에서 사야 돼요?

請問我應該去哪裡買票？

나

발권기를 이용하세요.

請使用售票機。(발권기 售票機/發券機，이용하다 利用/使用)

🔍 初學者超詳細文法與成分拆解專區

句型拆解 ①：동대문 패션 타운에 가려면 무슨 역에서 내려야 돼요?
目的地 + 方向助詞 동대문 패션 타운에 到東大門時尚城
動詞 + -(으)려면 條件 가려면 如果想要去的話
疑問冠詞 + 名詞 + 場所助詞 무슨 역에서 在哪一站（地點動作）
動詞 + -아/어야 되다 義務 내려야 돼요? 應該要下車嗎？
單字功能解析 ②：名詞與敬語尾詞
  • 동대문역사문화공원역：東大門歷史文化公園站（Dongdaemun History & Culture Park Station）。
  • 내리다 + -(으)세요 ➔ 내리세요：請下車（尊敬階祈使句）。
  • 발권기 (發券機)：自動售票機；이용하다 + -(으)세요 ➔ 이용하세요：請使用。

🧭 課堂補充拓展：搭乘位置、方向與指路金句庫

在韓國地鐵站換線或找月台時，除了問「哪一站下車」，更常用到「在哪裡搭」、「往哪一邊走」：

❓ 問句：應該在哪裡搭？往哪一邊？
어디에서 타야 돼요?

應該在哪裡搭乘？(타다 搭乘 + -아야 되다)

어느 쪽에서 타야 돼요?

應該在哪一邊 / 哪一個方向搭乘？

文法重點：어느 (哪一個) + 쪽 (方向邊側)
어느 나라

哪一個國家？（課堂延伸：어느 用於多者中指定選擇）

👉 回應：指引方向與位置句型
이쪽으로 오세요.

請往這邊來。(이쪽 + -(으)로 方向助詞)

이쪽에서 타세요.

請在這邊搭乘。

이쪽에서 타시면 돼요.

在這邊搭乘就可以了。(-(으)시면 되다 只要...就可以)

저쪽에 있어요.
在那邊。(遠處方向)
저기 있어요.
在那裡。(具體地點)

💳 韓國自由行必備：T-money 交通卡現金儲值金句 (충전하기)

在首爾搭乘地鐵與公車必備 T-money (티머니)。在便利商店 (GS25, CU, 7-Eleven) 或地鐵站自動儲值機儲值時，只須把卡片和現金交給店員並說：

儲值 1 萬韓元

tmoney 만원 충전해 주세요.

請幫我儲值 T-money 一萬韓元。

儲值 2 萬韓元

tmoney 이만원 충전해 주세요.

請幫我儲值 T-money 兩萬韓元。

💡 小錦囊：金額使用的是漢字詞數字：만원 (10,000)、이만원 (20,000)、삼만원 (30,000)。충전하다 為「充電、儲值」之意，-아/어 주세요 為「請幫我...」。

2. 상황 회화 ② 쇼핑하기(의류) (服飾購物、試穿與殺價實戰)

🛍️ 課本情境對話：挑選衣服與試穿

💬 服飾店實戰對話：看衣服與試穿 (옷 구경 및 피팅) 購物必備
가

저기 걸려 있는 옷 좀 보여 주실래요?

可以讓我看一下掛在那裡的那件衣服嗎？

나

이 옷이요?

這件嗎？

가

한번 입어 봐도 돼요?

請問可以試穿嗎？(한번 一次/試試 + 입어 보다 試穿 + -도 되다 可以...嗎？)

나

네, 저기서 입어 보세요.

當然，請到那裡試穿。(저기서 = 저기에서 的縮寫；입어 보세요 請穿穿看)

🔍 深度語法拆解：如何優雅地請店員「拿給我看」？

저기 걸려 있는 옷 좀 보여 주실래요?

저기 那裡（指示代名詞）
걸려 있는 掛著的 (걸리다 被掛 + -어 있다 狀態 + -는 現在修飾)
옷 좀 衣服 + 좀 (口氣緩和副詞：稍微/請)
보여 주실래요? 可以給我看嗎？(보이다 展現 + 주다 + -(으)시- 敬語 + -ㄹ래요? 徵詢)
💡 課堂補充：請店員拿東西看的禮貌層次與句型代換
直接禮貌請求
저 옷 좀 보여 주세요.
請給我看那件衣服。
指著特定物品
저거 좀 보여 주세요.
請給我看一下那個。(저거 = 저것)
更加委婉客氣 (極推)
저거 좀 보여 주실래요?
可以請您讓我看一下那個嗎？
店員拿給你時會說：

여기 있어요.

在這裡 / 這邊請。(遞交物品時標準用語)

🚪 試穿必備場所：「更衣室」韓文雙璧

탈의실

脫衣室 (更衣室) [漢字詞]

源自漢字「脫衣室」，標牌或游泳池、傳統服飾店、體育館常見。發音注意：의 讀作 [이] 或 [의]。

피팅룸

Fitting Room (試衣間) [外來語]

源自英文 Fitting room，在韓國現代百貨公司、潮牌選品店（如 Musinsa、Ader Error）與連鎖快時尚最普及！

💰 逛東大門、地下街血拼必備：殺價與付款實戰金句

在韓國傳統市場、東大門批發商場或地下街購物時，善用以下金句可以幫你省下不少旅費：

直接拜託

좀 싸게 해 주세요.

請算便宜一點。(싸다 ➔ 싸게 便宜地)

超委婉商量 (強力推薦)

좀 싸게 해 주실 수 있어요?

能算便宜一點嗎？(結合 -(으)ㄹ 수 있다)

現金大絕招

현금이면 얼마예요?

如果付現的話是多少錢？(付現通常有折扣)

道地殺價動詞

(좀) 깎아 주세요.

請(稍微)算便宜一點 / 幫我折價。(깎다 削、折)

3. 핵심 문법 심화 분석 (核心文法深度解析)

🎯 문법 ①: 목적 표현 -(으)러 가다 / 오다 (去做某事 / 來做某事)

接在動詞詞幹後方，專門與移動動詞（가다, 오다, 다니다 等）搭配，表示「前往某地的目的」。

無收音 或 ㄹ收音 ➔ 接 -러 가다/오다
  • 보(다) + -러 가다 ➔ 보러 가요 (去看)
  • 사(다) + -러 가다 ➔ 사러 가요 (去買)
  • 하(다) ➔ 하러 가요 (去做)
有收音 (除ㄹ外) ➔ 接 -으러 가다/오다
  • 먹(다) + -으러 가다 ➔ 먹으러 가요 (去吃)
  • 찾(다) + -으러 가다 ➔ 찾으러 가요 (去領/去找)
  • 입(다) + -으러 가다 ➔ 입으러 가요 (去穿)

🗣️ 課堂精彩情境實例 (問出國與旅遊目的)：

여행하러 가요?

要去旅行嗎？(여행하다 ➔ 여행하러 가다)

콘서트를 보러 가요?

要去看演唱會嗎？(K-pop 追星旅遊必備句型！)

Q. 詢問原因

상하이에 왜 가요?

為什麼去上海？(상하이 上海)

A1. 去出差 (출장하다)

출장하러 가요.

去出差。(출장하다 出差 ➔ 출장하러 가요)

A2. 去旅行 (여행하다)

여행하러 가요.

去旅行。(여행하다 旅行 ➔ 여행하러 가요)

태국 어디에 가요? ➔ 방콕

去泰國哪裡？ ➔ 曼谷 (태국 泰國，방콕 曼谷)

⚡ 문법 ②: 능력 및 가능 -(으)ㄹ 수 있다 / 없다 (能/不能，可以/不可以)

接在動詞詞幹後，表示具備做某件事的「能力」，或是客觀情況下「具備可行性 / 許可」。

肯定：可以 / 能夠

-(으)ㄹ 수 있어요

  • 갈 수 있어요. 可以去。 / 能去。
  • 할 수 있어요. 可以做。 / 能做到。 (I can do it!)
否定：無法 / 不能

-(으)ㄹ 수 없어요

  • 갈 수 없어요. 不能去。 / 無法去。
  • 할 수 없어요. 做不到。 / 沒辦法做。
🌟 課堂亮點：將「可能性」化為「極致客氣的請求」

當我們把 -(으)ㄹ 수 있다 結合尊稱詞綴 -(으)시-，就能問出比命令或直接請求更加優雅、讓人無法拒絕的委婉問句：

좀 싸게 해 주실 수 있어요? 可以請您幫我算便宜一點嗎？ (해 주다 + -(으)시- + -ㄹ 수 있어요?)

4. 단어 형태 변화 & 불규칙 규칙 (單字形態變化與文法規則)

📏 形容詞修飾名詞冠詞形 (-ㄴ/은) 與 ㅡ 脫落、르 不規則

在挑衣服時常說「大件的衣服」、「小件的衣服」、「別的款式」。韓語形容詞修飾名詞時，必須將原形結尾的 -다 換成冠詞形 -ㄴ/은，並注意特殊的音變脫落規則！

크다 (大) ㅡ 脫落現象
  • 現在非格式體：
    커요
    很大 (크 + 어요 ➔ ㅡ 脫落變 커요)
  • 修飾名詞冠詞形：
    큰 옷
    大件的衣服 (無收音加 -ㄴ)
작다 (小) 規則變化
  • 現在非格式體：
    작아요
    很小 (母音 ㅏ 接 -아요)
  • 修飾名詞冠詞形：
    작은 옷
    小件的衣服 (有收音接 -은)
다르다 (不同/別的) 르 不規則
  • 現在非格式體：
    달라요
    不同 (르 遇母音添 ㄹ 變 달라요)
  • 修飾名詞冠詞形：
    다른 옷
    別的衣服 / 不同的衣服

🛍️ 高頻填空句型：다른 _____ 좀 보여 주세요. (請給我看一下別的___)

架上的衣服不喜歡、尺寸不對或想換顏色時，只要套入名詞即可輕鬆表達：

다른 옷 別的衣服
다른 색 別的顏色 (색 = 顏色)
다른 거 別的/其他款式 (거 = 것)
