第一站

🚇 出發搭地鐵：旅伴同行與話題起手式

1. 客觀陳述「-이에요」vs 尋求共鳴「-(이)잖아요?」

🎥 語氣升級
📘 客觀陳述事實

우리 셋이 가는 게 처음이에요.

我們三個人一起去是第一次。

向還不知道這件事的人平鋪直敘說明事實。

🎥 喚起共同記憶「不是嘛」

우리 셋이 가는 게 처음이잖아요?

我們三個人一起去，這不是第一次嘛？

對方也知道的事實，語氣帶點撒嬌或提醒：「對吧！我們仨這不是第一次一起出國嗎！」

🔍 初學者逐詞拆解：`우리 셋이 가는 게 처음이잖아요?`

우리 셋이 我們三個人 固有數詞 셋 + 主格 이
가는 게 「去」這件事 가다 + -는 것 + 이 ➔ 가는 게
처음 第一次 名詞（有收音 ㅁ）
-이잖아요? 不是…嘛？ 名詞接 -(이)잖아요；動詞/形容詞直接接 -잖아요

2. 開啟話題「있잖아?」・過去定語「산」・時間副詞「아까 vs 방금」

아까 산 교통 카드 있잖아?

對了，剛剛買的那張交通卡不是嗎？（半語開啟話題）

① 過去定語 산：사다（買，無收音）+ -ㄴ ➔ 산（買了的）。對比：사는（正在買的）。
② 話題起手 있잖아?：跟熟人突然想到某件事時使用（敬語對不熟的人用 있잖아요）。
아까 幾分鐘～幾小時前

剛剛、剛才（已隔一小段時間）

情境：在超商買完交通卡，走進地鐵站後才拿出來問。

방금 就在剛才一瞬間

才剛剛（幾秒～一兩分鐘前）

情境：話才剛講完、結帳才剛刷完卡那一刻。

第二站

👗 服飾店試穿全攻略：語氣・尺寸・版型・抉擇

💡 買衣服最容易混用的兩大動詞：先分清楚「人好看」還是「尺寸剛剛好」

어울리다

適合、相配（看風格、顏色、氣質搭不搭）

例：這件顏色很襯你的膚色 ➔ 用 어울리다。

맞다

合身、剛剛好（看肩寬、腰圍、尺碼對不對）

例：穿起來不會太緊或太鬆 ➔ 用 맞다。

Step 1｜穿起來好看嗎？「어울리다」三種對象語氣對照

🎥 語氣分級
① 問朋友／旅伴（半語）

잘 어울려?

（我穿這樣）好看嗎？

從更衣室走出來問同行朋友最自然。

② 一般敬語變形

어울리다 ➔ 어울려요.

很適合／很好看。

變化規則：리 + 어요 母音縮寫成 려요。

③ 店員稱讚客人（尊稱）

잘 어울리세요.

您穿起來非常好看呢！

店員對客人加尊稱 -(으)시-：어울리 + 세요 ➔ 어울리세요。

Step 2｜尺寸確認與換尺寸：語氣「-어요? vs -나요?」＆ 數詞「하나 vs 한」

📘 課本 ➔ 實戰比較
📘 課本基礎問尺寸

사이즈 어때요?

尺寸怎麼樣？（店員問客人 / 同伴互問）

📘 直接問有無更大號

좀 더 큰 사이즈 없어요?

沒有再大一點的尺寸嗎？（좀 稍微 + 더 更）

🔍 實戰升級：「大一號 / 小一號」三種問法對比（改用 -나요? 更委婉！）

單用數詞：하나

하나 더 큰 사이즈 없나요?

沒有再大一個級距的尺寸嗎？

後面沒直接接單位詞，保留 하나。

接單位詞：한 + 사이즈

한 사이즈 더 큰 거 없나요?

沒有大一號的那件嗎？

하나 ➔ 한；크다(無收音) ➔ 큰。

換小一號：작다 ➔ 작은

한 사이즈 더 작은 거 없나요?

沒有小一號的那件嗎？

작다(有收音 ㄱ) ➔ 작은；거 = 것。

💬 為什麼店員或禮貌客人都用 없나요?？ — 없어요? 比較直接（像單純問有沒有貨）；改用 없나요? 語氣瞬間變柔和，有「請問方便幫我找找看有沒有…嗎？」的委婉感！

Step 3｜合身度回應「맞다」＆ 店員解釋版型「핏（Fit）」

🎥 店員實戰話術
客人自己說（一般敬語）

사이즈가 잘 맞아요.

尺寸很合身！

向店員表達「這件大小剛剛好，不用換號了」。

店員看見後讚嘆（尊稱＋感嘆）

사이즈가 잘 맞으시네~

哇～您的尺寸非常合身呢！

拆解：맞(合身) + 으시(尊稱) + 네(當下親眼看到的驚嘆語尾)。

핏 （英文 Fit ➔ 衣服的「版型、剪裁輪廓」）

當你覺得衣服好像偏貼身時，韓國店員常會這樣跟你解釋這款衣服原本的版型設計：

핏이 좀 맞게 입는 거예요.

這件的版型本來就是要穿得比較合身一點的。

핏이 版型（主詞） 핏 有收音 ㅅ ➔ 接 이
좀 稍微／一點 조금 縮寫，語氣更柔和
맞게 合身地 맞다 + 副詞化 -게（修飾穿）
입는 거예요 原本就是這樣穿的 입다 + -는 거예요（說明穿法）

Step 4A｜挑兩件比較：낫다（ㅅ 不規則）

高頻易錯
낫다 ➔ 나아요. 更好／比較好

變化重點：詞幹 낫 遇母音時 收音 ㅅ 脫落，且兩個 아 不合併！
낫 + 아요 ➔ 나 + 아요 ➔ 나아요
⚠️ 陷阱提醒：不能縮寫成「나요」，否則會變成「出來／發生（나다）」的意思！

이거 더 나아요. 這個更好／這件比較好看！

Step 4B｜想先逛別家：돌다 家族與方向

方向動詞
돌다 ➔ 돌아요. 轉、繞、逛

遇母音 -아/어요 時 ㄹ 保留；遇 ㄴ/ㅂ/ㅅ 才脫落（例：도는）。

돌아오다 回來（朝向這兒）
돌아가다 回去（往那邊去）
한 번 돌아보고 올게요. 我先去逛一圈看看再回來！ 拆解：한 번(先/一次) + 돌아보고(逛逛看) + 올게요(我會再回來)

💸 殺價攻防與價格數字聽讀挑戰

💬 結帳談判對話：委婉殺價 ➔ 付現折扣 ➔ 拍板決定

가
🎥 更委婉請求 좀 싸게 해 주실 수 없나요?

請問不能幫我算便宜一點嗎？（-(으)실 수 없나요? 詢問對方能否破例）

📘 課本直接請求 좀 싸게 해 주세요. 請算便宜一點！
나
🎥 店員付現條件回覆 현금하시면 ___원까지 해 드려요.

如果您付現的話，可以幫您算到 ___ 元。

현금하시면（현금 하다 付現 + 尊稱 -시- + -(으)면 如果）+ 까지（到…為止）+ 해 드려요（謙讓語「幫您算到」）。

第四站

🍜 排隊、點餐與入店用餐實戰

1. 門口排隊三階段（原型 ➔ 直接問 ➔ 推測自語）

줄을 서다 排隊（原型動詞） 줄(線/隊伍) + 서다(站立)
줄을 서요? 要排隊嗎？ 直接向店員或排隊路人確認
줄을 서는 건가? 這是在排隊的嗎？ -는 건가?（-는 것인가 推測猜想）

2. 聽懂店員點餐三連問

뭐 드릴까요? 要給您什麼呢？（請問要點什麼？） 드리다 = 주다(給) 的謙讓語
주문 도와드릴까요? 需要幫您點餐嗎？ 도와드리다（幫您）— 咖啡廳/餐廳高頻
주문하시겠어요? 您現在要點餐了嗎？ 주문하다 + 尊稱 -시겠어요?

3. 萬用簡答「___ N ___ (이)요.」＆ 只要一份

規則：名詞有收音接 이요，無收音接 요（例：커피요 咖啡）。直接報人數、金額或品項：

두 명이요. 兩位！ 명 有收音 ㅇ ➔ 接 이요
3000원이요. (삼천 원이요) 三千韓元！ 원 有收音 ㄴ ➔ 接 이요
하나만 주세요. 請只要給我一個／一份就好。 -만（只、僅僅）接在名詞後

4. 問座位與招呼入店（助詞 에서 vs -(으)로）

어디에서 먹을 수 있어요? 可以在哪裡吃呢？ 어디에서（在某地進行動作）+ 먹을 수 있어요?（可以吃嗎）
가게 안으로 들어오세요. 請進來店裡面！ 가게 안(店裡，有收音 ㄴ) + 으로(往…方向) + 들어오세요(請進來)
第五區

🧠 橫向語法系統總整理（考前 1 分鐘速查盤）

系統盤 A｜店員尊稱升級「-(으)시-」

韓國店員對客人講話，動詞/形容詞幾乎都會多加一個 -(으)시-！

一般敬語 店員尊稱（實戰）
어울려요
잘 어울리세요.
잘 맞아요
잘 맞으시네~
현금하면
현금하시면
주문해요?
주문하시겠어요?
해 줄 수 있어요?
해 주실 수 없나요?

系統盤 B｜問句語氣三級跳

同樣在問問題，語尾換一下，禮貌度與語感完全不同！

① 直接詢問：-어요?

없어요? / 줄을 서요?

最基本直白的課本問句。

② 客氣求問店員：-나요?

없나요? / 해 주실 수 없나요?

語氣變得柔和委婉，請店員找尺寸或殺價超好用。

③ 自言自語推測：-는 건가?

줄을 서는 건가?

看到隊伍不確定時，對自己或旅伴小聲猜測「該不會是在排隊吧？」。
