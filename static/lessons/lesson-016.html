第一站

🚇 出發搭地鐵：旅伴同行與話題起手式

1. 客觀陳述「-이에요」vs 尋求共鳴「-(이)잖아요?」

🎥 語氣升級
📘 客觀陳述事實

우리 셋이 가는 게 처음이에요.

我們三個人一起去是第一次。

向還不知道這件事的人平鋪直敘說明事實。

🎥 喚起共同記憶「不是嘛」

우리 셋이 가는 게 처음이잖아요?

我們三個人一起去，這不是第一次嘛？

對方也知道的事實，語氣帶點撒嬌或提醒：「對吧！我們仨這不是第一次一起出國嗎！」

🔍 初學者逐詞拆解：우리 셋이 가는 게 처음이잖아요?

우리 셋이 我們三個人 固有數詞 셋 + 主格 이
가는 게 「去」這件事 가다 + -는 것 + 이 ➔ 가는 게
처음 第一次 名詞（有收音 ㅁ）
-이잖아요? 不是…嘛？ 名詞接 -(이)잖아요；動詞/形容詞直接接 -잖아요

💡 舉一反三：「不是…嘛！」-(이)잖아요 旅遊高頻應用

✨ 延伸補充
名詞有收音 ➔ -이잖아요

오늘이 마지막 날이잖아요.

今天不是最後一天嘛！

名詞無收音 ➔ -잖아요

여기잖아요!

不就是這裡嘛！（找到店時）

動詞／形容詞 ➔ -잖아요

여기 맛있잖아요!

這家不是很好吃嘛！（推坑旅伴）

2. 開啟話題「있잖아?」・過去定語「산」・時間副詞「아까 vs 방금」

아까 산 교통 카드 있잖아?

對了，剛剛買的那張交通卡不是嗎？（半語開啟話題）

① 過去定語 산：사다（買，無收音）+ -ㄴ ➔ 산（買了的）。對比：사는（正在買的）。
② 話題起手 있잖아?：跟熟人突然想到某件事時使用（敬語對不熟的人用 있잖아요）。
아까 幾分鐘～幾小時前

剛剛、剛才（已隔一小段時間）

情境：在超商買完交通卡，走進地鐵站後才拿出來問。

방금 就在剛才一瞬間

才剛剛（幾秒～一兩分鐘前）

情境：話才剛講完、結帳才剛刷完卡那一刻。

📌 動詞過去定語「已經…的」-(으)ㄴ + 名詞 舉一反三

✨ 延伸規則
無收音 ＋ -ㄴ 사다 ➔ 산 옷 買了的衣服（가다 ➔ 간 곳）
有收音 ＋ -은 먹다 ➔ 먹은 음식 吃過的食物（입다 ➔ 입은 옷）
ㄹ 收音 ➔ ㄹ 脫落＋ㄴ 만들다 ➔ 만든 것 做的東西（팔다 ➔ 판 물건）

3. 旅伴人數講法 ＆ 搭地鐵／交通卡實戰補充

✨ 實戰延伸

👥 延伸「우리 셋이（我們三個人）」— 固有數詞同行人數講法：

혼자 獨自一人
둘이 兩個人一起
셋이 三個人一起
넷이 四個人一起

교통 카드 충전해 주세요.

請幫我儲值交通卡。（충전하다 儲值）

어디에서 갈아타요?

要在哪裡轉乘？（갈아타다 換乘）

몇 번 출구로 나가요?

要從幾號出口出去？（출구 出口）

거기까지 얼마나 걸려요?

到那裡大概要花多久時間？（걸리다 耗時）

第二站

👗 服飾店試穿全攻略：語氣・尺寸・版型・抉擇

💡 買衣服最容易混用的兩大動詞：先分清楚「人好看」還是「尺寸剛剛好」

어울리다

適合、相配（看風格、顏色、氣質搭不搭）

例：這件顏色很襯你的膚色 ➔ 用 어울리다。

맞다

合身、剛剛好（看肩寬、腰圍、尺碼對不對）

例：穿起來不會太緊或太鬆 ➔ 用 맞다。

Step 1｜穿起來好看嗎？「어울리다」三種對象語氣對照

🎥 語氣分級
① 問朋友／旅伴（半語）

잘 어울려?

（我穿這樣）好看嗎？

從更衣室走出來問同行朋友最自然。

② 一般敬語變形

어울리다 ➔ 어울려요.

很適合／很好看。

變化規則：리 + 어요 母音縮寫成 려요。

③ 店員稱讚客人（尊稱）

잘 어울리세요.

您穿起來非常好看呢！

店員對客人加尊稱 -(으)시-：어울리 + 세요 ➔ 어울리세요。

Step 2｜尺寸確認與換尺寸：語氣「-어요? vs -나요?」＆ 數詞「하나 vs 한」

📘 課本 ➔ 實戰比較
📘 課本基礎問尺寸

사이즈 어때요?

尺寸怎麼樣？（店員問客人 / 同伴互問）

📘 直接問有無更大號

좀 더 큰 사이즈 없어요?

沒有再大一點的尺寸嗎？（좀 稍微 + 더 更）

🔍 實戰升級：「大一號 / 小一號」三種問法對比（改用 -나요? 更委婉！）

單用數詞：하나

하나 더 큰 사이즈 없나요?

沒有再大一個級距的尺寸嗎？

後面沒直接接單位詞，保留 하나。

接單位詞：한 + 사이즈

한 사이즈 더 큰 거 없나요?

沒有大一號的那件嗎？

하나 ➔ 한；크다(無收音) ➔ 큰。

換小一號：작다 ➔ 작은

한 사이즈 더 작은 거 없나요?

沒有小一號的那件嗎？

작다(有收音 ㄱ) ➔ 작은；거 = 것。

💬 為什麼店員或禮貌客人都用 없나요?？ — 없어요? 比較直接（像單純問有沒有貨）；改用 없나요? 語氣瞬間變柔和，有「請問方便幫我找找看有沒有…嗎？」的委婉感！

Step 3｜合身度回應「맞다」＆ 店員解釋版型「핏（Fit）」

🎥 店員實戰話術
客人自己說（一般敬語）

사이즈가 잘 맞아요.

尺寸很合身！

向店員表達「這件大小剛剛好，不用換號了」。

店員看見後讚嘆（尊稱＋感嘆）

사이즈가 잘 맞으시네~

哇～您的尺寸非常合身呢！

拆解：맞(合身) + 으시(尊稱) + 네(當下親眼看到的驚嘆語尾)。

핏 （英文 Fit ➔ 衣服的「版型、剪裁輪廓」）

當你覺得衣服好像偏貼身時，韓國店員常會這樣跟你解釋這款衣服原本的版型設計：

핏이 좀 맞게 입는 거예요.

這件的版型本來就是要穿得比較合身一點的。

핏이 版型（主詞） 핏 有收音 ㅅ ➔ 接 이
좀 稍微／一點 조금 縮寫，語氣更柔和
맞게 合身地 맞다 + 副詞化 -게（修飾穿）
입는 거예요 原本就是這樣穿的 입다 + -는 거예요（說明穿法）
🏷️ 韓國逛街常聽見的「핏」版型關鍵字速查 ✨ 實戰延伸
오버핏 寬鬆版型
슬림핏 修身貼身版
와이드핏 寬褲／寬管版
프리 사이즈 均碼（Free）

Step 4A｜挑兩件比較：낫다（ㅅ 不規則）

高頻易錯
낫다 ➔ 나아요. 更好／比較好

變化重點：詞幹 낫 遇母音時 收音 ㅅ 脫落，且兩個 아 不合併！
낫 + 아요 ➔ 나 + 아요 ➔ 나아요
⚠️ 陷阱提醒：不能縮寫成「나요」，否則會變成「出來／發生（나다）」的意思！

이거 더 나아요. 這個更好／這件比較好看！

💡 延伸必記：同樣是 ㅅ 收音，小心誰脫落、誰不脫落！

• ㅅ 不規則（脫落）：짓다 ➔ 지어요（蓋／煮飯）、붓다 ➔ 부어요（倒水／水腫）

• ㅅ 規則（保留！）：벗다 ➔ 벗어요（脫衣服）、웃다 ➔ 웃어요（笑）、씻다 ➔ 씻어요（洗）

Step 4B｜想先逛別家：돌다 家族與方向

方向動詞
돌다 ➔ 돌아요. 轉、繞、逛

遇母音 -아/어요 時 ㄹ 保留；遇 ㄴ/ㅂ/ㅅ 才脫落（例：도는）。

돌아오다 回來（朝向這兒）
돌아가다 回去（往那邊去）
한 번 돌아보고 올게요. 我先去逛一圈看看再回來！ 拆解：한 번(先/一次) + 돌아보고(逛逛看) + 올게요(我會再回來)
그냥 구경하고 있어요. 我只是先隨便看看喔！（店員熱情推銷時超好用）

Step 5｜試穿前後完整應對：借試衣間・形容太緊太鬆・問別色與拿新品

✨ 逛街實戰延伸

이거 입어 봐도 돼요?

這件可以試穿嗎？（입어 보다 試穿 + -아/어도 돼요?）

탈의실이 어디예요?

請問試衣間在哪裡？（탈의실 試衣間 / 피팅룸）

다른 색깔 없나요?

沒有其他顏色嗎？（直接套用本課委婉 -나요?）

새 걸로 주세요.

請給我全新的一件！（새 것 新的東西 ➔ 새 걸로）

📏 試穿後回覆「사이즈 어때요?」的 6 種不合身形容詞（前面加 좀 語氣更委婉）：

좀 커요. 有點大（크다）
좀 작아요. 有點小（작다）
좀 길어요. 有點長（길다）
좀 짧아요. 有點短（짧다）
좀 꽉 껴요. 有點緊繃（꽉 끼다）
좀 헐렁해요. 有點太鬆（헐렁하다）

💸 殺價攻防與價格數字聽讀挑戰

💬 結帳談判對話：委婉殺價 ➔ 付現折扣 ➔ 拍板決定

가
🎥 更委婉請求 좀 싸게 해 주실 수 없나요?

請問不能幫我算便宜一點嗎？（-(으)실 수 없나요? 詢問對方能否破例）

📘 課本直接請求 좀 싸게 해 주세요. 請算便宜一點！

현금하시면（현금 하다 付現 + 尊稱 -시- + -(으)면 如果）+ 까지（到…為止）+ 해 드려요（謙讓語「幫您算到」）。

✨ 結帳延伸

買兩個的話請折價一點！（깎아 주다 殺價／折價）

봉투 하나 주세요. / 영수증은 괜찮아요.

第四站

🍜 排隊、點餐與入店用餐實戰

1. 門口排隊三階段（原型 ➔ 直接問 ➔ 推測自語）

줄을 서다 排隊（原型動詞） 줄(線/隊伍) + 서다(站立)
줄을 서요? 要排隊嗎？ 直接向店員或排隊路人確認
줄을 서는 건가? 這是在排隊的嗎？ -는 건가?（-는 것인가 推測猜想）

⏱️ 延伸實戰：候位詢問 ＆ 聽懂店員問「內用還是外帶？」

✨ 餐廳延伸
얼마나 기다려야 돼요? 大概要等多久？（기다리다 等）
드시고 가세요? 您要內用嗎？（店員尊稱 드시다）
먹고 갈게요. / 포장해 주세요. 我要內用。／請幫我外帶。

2. 聽懂店員點餐三連問

뭐 드릴까요? 要給您什麼呢？（請問要點什麼？） 드리다 = 주다(給) 的謙讓語
주문 도와드릴까요? 需要幫您點餐嗎？ 도와드리다（幫您）— 咖啡廳/餐廳高頻
주문하시겠어요? 您現在要點餐了嗎？ 주문하다 + 尊稱 -시겠어요?

3. 萬用簡答「___ N ___ (이)요.」＆ 只要一份

規則：名詞有收音接 이요，無收音接 요（例：커피요 咖啡）。直接報人數、金額或品項：

두 명이요. 兩位！ 명 有收音 ㅇ ➔ 接 이요
3000원이요. (삼천 원이요) 三千韓元！ 원 有收音 ㄴ ➔ 接 이요
하나만 주세요. 請只要給我一個／一份就好。 -만（只、僅僅）接在名詞後
혼자요. 一位！（無收音 요）
포장이요. 外帶！（有收音 이요）

4. 問座位與招呼入店（助詞 에서 vs -(으)로）

어디에서 먹을 수 있어요? 可以在哪裡吃呢？ 어디에서（在某地進行動作）+ 먹을 수 있어요?（可以吃嗎）
가게 안으로 들어오세요. 請進來店裡面！ 가게 안(店裡，有收音 ㄴ) + 으로(往…方向) + 들어오세요(請進來)

🛎️ 延伸實戰：聽懂店員帶位方向「-(으)로」＆ 餐廳呼喚結帳 3 句

✨ 用餐延伸
이쪽으로 오세요. 請往這邊來！（帶位必聽）
저기요! 주문할게요. 不好意思！我要點餐。
물 좀 주세요. 請給我水。（물 水）
계산해 주세요. 請幫我結帳。（계산 結帳）

📌 方向助詞規則複習：名詞有收音接 으로（안 ➔ 안으로、이쪽 ➔ 이쪽으로）；無收音或 ㄹ 收音接 로（밖 ➔ 밖으로 / 여기 ➔ 여기로、지하철 ➔ 지하철로）。

🧠 橫向語法系統總整理（考前 1 分鐘速查盤）

A｜店員尊稱升級「-(으)시-」

韓國店員對客人講話，動詞/形容詞幾乎都會多加一個 -(으)시-！

一般敬語 店員尊稱（實戰）
어울려요
잘 어울리세요.
잘 맞아요
잘 맞으시네~
현금하면
현금하시면
주문해요?
주문하시겠어요?
해 줄 수 있어요?
해 주실 수 없나요?

B｜問句語氣三級跳

同樣在問問題，語尾換一下，禮貌度與語感完全不同！

① 直接詢問：-어요?

없어요? / 줄을 서요?

最基本直白的課本問句。

② 客氣求問店員：-나요?

없나요? / 해 주실 수 없나요?

語氣變得柔和委婉，請店員找尺寸或殺價超好用。

③ 自言自語推測：-는 건가?

줄을 서는 건가?

看到隊伍不確定時，對自己或旅伴小聲猜測「該不會是在排隊吧？」。

C｜全課 5 大易混詞組速查

考前一眼掃過，徹底根除最常混用的成對概念！

✨ 系統統整
對比組 一句話秒分關鍵
어울리다 vs 맞다 風格顏色好看搭 vs 尺碼肩腰剛剛好
아까 vs 방금 已隔幾分～數小時的剛剛 vs 幾秒前的才剛
하나 vs 한 後面沒單位留 하나 vs 接單位縮 한（한 사이즈）
에서 vs -(으)로 動作發生地點（어디에서）vs 移動方向（안으로）
주다・드리다・드시다 一般「給」・謙讓「給您」・尊稱「您吃／喝」

第六區

🏆 TOPIK 檢定考點直擊（從旅遊口語對接檢定高頻題）

考點 1｜限定助詞「-만」vs「-밖에 + 否定」

TOPIK I 必考

本課點餐句 하나만 주세요 用了 -만；考試超常把 -만 換成 -밖에 考你後方動詞搭配！

• 하나만 있어요.（有／只買一個，接肯定或否定皆可）
• 하나밖에 없어요.（只有一個，後方絕對必須接否定 없다/안/못！）

考點 2｜「-(으)ㄹ게요」主詞只能是「我」

TOPIK I-II

本課出現 이걸로 할게요、돌아보고 올게요，表達說話者的決定與承諾，考試最常考人稱與問句限制：

• ⭕ 제가 할게요.（我來做／我買這個 — 只能第一人稱陳述句）

• ❌ 친구가 갈게요.（錯！第三人稱不可用 -(으)ㄹ게요）

• ❌ 뭐 먹을게요?（錯！不能用於疑問句，問對方要改用 드실래요? / 드시겠어요?）

考點 3｜定語時態辨析（過去 vs 現在 vs 形容詞）

TOPIK 填空常客

TOPIK 閱讀填空超愛在「名詞前方」挖空，考你分不分得出動詞現在與動詞過去：

• 動詞過去「-(으)ㄴ」：어제 산 옷（昨天買的衣服）

• 動詞現在「-는」：요즘 자주 입는 옷（最近常穿的衣服）

• 形容詞現在「-(으)ㄴ」：큰 사이즈 / 작은 거（形容詞表狀態直接用 -(으)ㄴ）

考點 4｜尊稱「드시다」vs 謙讓「드리다」

TOPIK 聽力高頻

聽力對話出現店員或晚輩對長輩說話時，考「誰對誰做動作」：

• 主語是客人／長輩（抬高對方）：드시다（吃喝）、주무시다（睡）、계시다（在）

• 主語是我／店員（放低自己給對方）：드리다（給）、여쭤보다（問）、모시다（帶／接）

• 例句：할머니께 선물을 드렸어요.（我送禮物給奶奶）

自我檢測

Q1. （　　　）에 맞는 것을 고르세요.｜가: 손님, 이 옷 어때요? 나: 좀 큰데, 한 사이즈 더 작은 거 (　　　)?

① 없어요　　② 없나요　　③ 있을게요　　④ 나아요

Q2. 下列哪一個句子在韓語文法上完全正確？（考不規則變化與限定助詞）

① 이거 더 나요.　　② 하나밖에 있어요.　　③ 아까 산 모자예요.　　④ 손님이 이걸로 할게요.

Q3. 聽力計算題：店員說「한 개에 사천오백 원인데, 두 개 사시면 팔천 원까지 해 드려요.」請問買兩件一共付多少錢？

① 4,500원　　② 8,000원　　③ 9,000원　　④ 18,000원

💡 點擊展開 TOPIK 快篩 3 題解析與發音

Q1 答案：②（或 ①，但實戰委婉選 ② 없나요） — ③ 있을게요 主詞與疑問句錯誤；④ 나아요 語意「更好」不合前後文。最道地委婉問店員有沒有貨用 없나요?。

Q2 答案：③ 아까 산 모자예요. — ① 낫다 不可縮寫成 나요，應為 나아요；② -밖에 必須接否定 없어요；④ -(으)ㄹ게요 只能用於第一人稱，不能用 손님이（客人）。

Q3 答案：② 8,000원（팔천 원） — 原價 1 個 4,500 韓元（사천오백 원），買 2 個（두 개 사시면）優惠到 8,000 韓元（팔천 원까지 해 드려요）！
