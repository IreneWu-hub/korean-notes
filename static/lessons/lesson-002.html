📖 核心文法專題 (문법 정리)

重點 1 現在式與敬語結尾 (-아요 / -어요 / -해요)

這是韓文中最常見的生活敬語（해요체）。決定要接哪一個，全看「動詞/形容詞語幹的最後一個母音」是什麼：

母音判斷規則 原形動詞 變化結果
ㅏ, ㅗ ➔ -아요 알다 (知道) 알아요
가다 (去) 가요
오다 (來) 와요
그 외 모음 (其他) ➔ -어요 읽다 (讀) 읽어요
배우다 (學) 배워요
마시다 (喝) 마셔요
하다 ➔ 해요 공부하다 (讀書) 공부해요
일하다 (工作) 일해요
📝 課本例句 (예문)：
  • • 아야나는 자요. (Ayana在睡覺。)
  • • 에릭은 운동해요. (Eric在運動。)
  • • 다니엘은 샌드위치 먹어요. (Daniel在吃三明治。)
  • • 유진 씨는 뭐 해요? 저는 커피 마셔요. (Yujin你在做什麼？我在喝咖啡。)

重點 2 意願與承諾 (-(으)ㄹ게요)

用於向對方表達「我會做某事 / 由我來做某事」，常用於點餐、結帳等情境。

  • 주문할게요.
    我要點餐。 (주문하다)
  • 계산할게요.
    我要結帳。 (계산하다)
  • 따로따로 계산할게요.
    我們會分開結帳。

重點 3 請求許可 (-아/어도 돼요?)

用於詢問「可以...嗎？/這樣做也沒關係嗎？」。

  • 카드 돼요?
    可以刷卡嗎？ (最口語直接的問法)
  • 화장실에 가도 돼요?
    我可以去洗手間嗎？
    💡 老師貼心校正：筆記上的「해요」應改為「돼요 (可以)」才對喔！
  • 네, 가도 돼요.
    好的，可以去喔。

重點 4 發音規則：口蓋音化 (구개음화)

當單字的收音是 「ㄷ」或「ㅌ」，而後面緊接的字是 「이」 字母時，為了發音方便省力，發音會自動變成 「지」和「치」。

ㅌ ➔ 치
같이 [가치]
一起 (Together)
ㄷ ➔ 지
굳이 [구지]
硬要、偏要 (例：왜 굳이 해야 돼요? 為什麼硬要這麼做？)

💬 實用情境與對話 (상황별 대화)

📍 情境一：餐廳點餐與要求服務

顧客
중국어 메뉴판 있나요?
請問有中文菜單嗎？ (중국어로 된 메뉴판 = 用中文寫成的菜單)
顧客
반찬 더 주세요. / 이거 더 주세요.
請再給我多一點小菜。 / 這個請再給我一點。
店員
서비스입니다. / 서비스예요.
這是招待的。(免費送的)
客訴
이건 안 시켰어요.
這個我沒有點喔。
(이건 = 이거는 這是口語縮寫)

📍 情境二：結帳與付款

顧客
따로따로 계산할게요. (또는: 따로 계산해 주세요)
我們要分開結帳。 (따로 = 分開/個別)
店員
따로따로요?
要分開結嗎？ (確認語氣)
顧客
카드 돼요?
可以刷卡嗎？ (若用文法完整說法：카드로 계산할게요 / 카드로 해도 돼요?)

📚 主題分類單字庫 (어휘 정리)

🔢 點餐必備：數字與量詞對照

韓國點餐時，「幾人份 (인분)」通常搭配「漢語數詞 (일, 이, 삼...)」；
而點「幾個 (개)」時，必須搭配「純韓語數詞 (한, 두, 세...)」。

漢語數詞 + 인분 (人份)
  • 일 인분 1人份
  • 이 인분 2人份
  • 삼 인분 3人份
  • 사 인분 4人份
  • (數字基底：일, 이, 삼, 사, 오...)
純韓語數詞 + 개 (個)
  • 한 개 / 하나 1個
  • 두 개 2個
  • 세 개 3個
  • 네 개 4個
  • 다섯 개 5個
  • ⚠️ 1~4 遇到量詞時會變形 (하나 ➔ 한, 둘 ➔ 두...)

🍽️ 餐廳與飲食單字

  • 메뉴판 菜單 (Menu board)
  • 반찬 小菜
  • 셀프 (Self) 自助式 (셀프입니다: 採自助式)
  • 서비스 招待、沙必思 (店家免費提供)

🛠️ 文法與實用副詞

  • 따로 / 따로따로 分開地、個別地
  • 같이 [가치] 一起
  • 굳이 [구지] 偏偏、硬要
  • n.(으)로 用...方式 / 搭乘... / 往...方向
