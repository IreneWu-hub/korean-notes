• -어도 되다 (可以做某事、徵求許可)

韓國校園文化特輯：연세 점퍼 & 과잠 (棒球外套)

在韓國，「점퍼 (Jumper)」常指棒球夾克或短防風外套。各大名校大學生（如延世大學的 연세 점퍼、首爾大、高麗大）都會訂製繡有校徽、入學年份與科系名稱的專屬外套，俗稱「과잠 (학과 점퍼 科系夾克外套)」。

💬 走在首爾街頭、新村或弘大，常會看到韓國大學生人手一件繡著代表英文字母的「과잠」，兼具保暖與強烈歸屬感！

🧠 第二單元：核心文法解析與音變專題

核心文法公式

形容詞與動詞修飾名詞（冠形詞形）與「ㄹ 脫落」

當動詞或形容詞要放在名詞前面當作形容語時，會加上特定的冠形詞語尾：

1. 形容詞修飾名詞：語幹 + -(으)ㄴ
• 無收音：크다 ➔ 큰 옷 (大衣服)
• 有收音：작다 ➔ 작은 옷 (小衣服)
⚠️ 遇到「ㄹ 收音」時必脫落：

길다 (長) + -(으)ㄴ ➔ 語幹末尾 ㄹ 消失，補上 ㄴ ➔ 긴

• 긴바지 (長褲) · 긴치마 (長裙)
2. 動詞修飾名詞現在式：語幹 + -는 것
• 一般動詞：먹다 ➔ 먹는 것 (吃的東西)
• 一般動詞：입다 ➔ 입는 옷 (穿的衣服)
⚠️ 遇到「ㄴ 開頭」語尾時 ㄹ 必脫落：

팔다 (賣) + -는 것 ➔ 語幹末尾 ㄹ 消失 ➔ 파는 것

• 시장에서 파는 것 (在市場賣的東西)
🌟 韓語文法鐵則：ㄹ 不規則脫落「黃金口訣」

凡是語幹結尾為收音「ㄹ」的動詞或形容詞，遇到開頭為「ㅅ, ㄴ, ㅂ, 으」的語尾時，收音「ㄹ」必定脫落消失！

遇 ㄴ (冠形詞)
팔다 ➔ 파는
길다 ➔ 긴
遇 ㅂ (格式體)
살다 ➔ 삽니다
알다 ➔ 압니다
遇 ㅅ (尊稱語尾)
살다 ➔ 사세요
만들다 ➔ 만드세요
遇 으 (連接語尾)
알다 ➔ 아니까
（으 直接省略）
發音特輯

깻잎 為什麼唸成 [ 깬닙 ]？三步音變大解密

在韓國烤肉店包肉必備的紫蘇葉「깻잎」，寫作 깻잎，但實際唸法卻是「[깬닙]」！這在韓語語音學中融合了三個經典音變現象：

第 1 步：代表音化
깻 ➔ [깯]

底部的收音「ㅅ」在音節末端時，還原為七大代表音之「ㄷ」。

第 2 步：ㄴ 添加 (ㄴ-첨가)
[깯] + 잎 ➔ [깯닙]

合成詞後方字首以「ㅣ」開頭時，結合處自動生出「ㄴ」音。

第 3 步：鼻音化 (비음화)
[깯닙] ➔ [깬닙]

前字收音「ㄷ」遇到後字聲母鼻音「ㄴ」，被同化為鼻音「ㄴ」！

🥩 烤肉實戰加菜金句：「사장님, 깻잎 좀 더 주세요! (老闆，請再給我一點紫蘇葉！)」

韓國青年流行語大揭秘：꿀알바（神仙打工 / 爽缺兼職）

在韓國年輕人的日常對話與求職論壇中，「꿀알바」是指工作輕鬆、薪水優渥、不用勞碌奔波的「夢幻爽兼職」（如同中文的肥缺、涼缺、神仙打工）！

🍯 꿀 (蜂蜜 / Honey) 的流行語用法

韓國年輕人把「꿀」放在名詞前面，表示「極度甜美、超讚、賺到、超輕鬆」！
• 꿀팁 (Honey + Tip) = 超神撇步 / 實用小秘訣
• 꿀잠 (Honey + 睡) = 睡得超香甜的一覺

💼 알바 (兼職 / 打工) 結合實戰

德語 Arbeit ➔ 아르바이트 (兼職) 的口語縮寫。
• 꿀알바 = 蜂蜜般甜美的兼職 = 爽缺打工！
🗣️ 「이번 방학에 꿀알바 구했어요! (我這次放假找到了超爽的兼職！)」
