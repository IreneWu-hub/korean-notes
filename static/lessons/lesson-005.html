📖 核心文法專題 (문법 정리)

重點 1 ㄹ 消失規則 (ㄹ 변형 규칙)

當動詞或形容詞的語幹以 「ㄹ」 結尾時，若遇到後方連接以 「ㅅ、ㄴ、ㅂ」 開頭的文法，語幹的「ㄹ」必須省略。我們稱之為「ㄹ 消失規則」。

📌 公式推導：팔다 (賣) + -(으)세요 (請...)
  • 1. 去掉原形字尾 다 ➔ 語幹為 팔
  • 2. 語幹有收音(ㄹ)，本應加 -으세요，但因為遇到 ㅅ，觸發 ㄹ 消失規則。
  • 3. 語幹的 ㄹ 消失 ➔ 變成 파
  • 4. 因為 ㄹ 消失後視同無收音，直接接上 -세요。
  • ✨ 結果：파 + 세요 ➔ 파세요. (請賣)
💡 情境應用： 離開餐廳時對老闆說「많이 파세요.」，字面意思是「請多賣一點」，實際是韓國人極常用的寒暄語：「祝您生意興隆！」。

重點 2 名詞合成音變規則：사이시옷 ( ㅅ )

當兩個單字結合成一個新名詞時（純韓文+純韓文，或純韓文+漢字詞），如果前面的單字沒有收音（母音結尾），為了標示後面單字的首個子音發音會變緊繃（發成濃音），會在前面單字底下墊上一個 「ㅅ」，這稱為 사이시옷 規則。

單字 A + 單字 B 合成結果 實際發音
만두 (餃子) + 국 (湯) 만둣국 [만둗꾹 / 만두꾹]
고기 (肉) + 집 (店/家) 고깃집 [고긷찝 / 고기찝]
바다 (海) + 가 (邊) 바닷가 [바닫까]
⚠️
為什麼「빵집（麵包店）」沒有加 ㅅ？
因為 사이시옷 規則只適用於「純韓文」與「漢字詞」。而 빵 (麵包) 其實是來自葡萄牙語 (pão) 的外來語！外來語合成詞不補 ㅅ，所以維持原樣寫成 빵집。

💬 情境對話與禮貌用語 (상황별 대화)

📍 場景：入座與點餐

店員
몇 분이세요?
請問有幾位？ (분 是對人的敬語量詞)
顧客
두 명이요. / 두 명이에요.
兩位。(요 體為口語常用簡答，이에요 也是禮貌表達)
店員
몇 개 드릴까요?
請問要給您幾個？
顧客
토마토(를) 빼고 주세요.
請不要加番茄給我。 (把番茄排除在外後給我)
*變化句型：치즈를 빼 주세요. (請幫我把起司拿掉 / 去掉起司)

📍 場景：結帳與離開

顧客
많이 파세요.
祝您生意興隆！ (字面：請多賣一點)
店員
또 오세요.
歡迎下次光臨。 (字面：請再來)
오다 (來) ➔ 와요 (現在式) ➔ 오세요 (請...)
顧客
또 올게요.
我會再來的。 (-ㄹ게요 表達個人的意願與約定)
