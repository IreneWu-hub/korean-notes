🎯 本堂學習重點

  • 核心文法：韓語過去時態大解密（-았/었/했어요 & 名詞 이었어요/였어요）：徹底掌握動詞與形容詞陽性母音 (+았어요)、陰性母音 (+었어요) 與 -하다 (+했어요) 的過去時態規則；並深入解析名詞過去式「이다 ➔ -이었어요 / -였어요」，精熟問價對比「얼마예요?（現在多少）」vs「얼마였어요?（那時是多少）」。
  • 首爾大 1A 日常核心動詞庫與打工縮寫文化：掌握 14 大日常生活高頻動詞（보다, 먹다, 읽다, 마시다, 자다, 사다, 일하다 等）之原型與敬語現在/過去式變化，並解密台韓共通青年文化詞彙「아르바이트하다 ➔ 口語縮寫 알바해요 / 알바생（工讀生）」。
  • 超商實戰服務對話與冰箱位置詢問：精通韓國便利商店必備情境單字（교통카드, 삼각김밥, 쓰레기봉투, 도시락, 종이봉투），聽懂店員袋子詢問句「봉투 드려요? / 봉투 드릴까요?」，並學會在冷藏櫃尋物問句「냉장고 안에 어디에 있어요?」。
  • 作息關懷、深夜時間表達與味覺不規則形容詞：熟練時間問答句型「몇 시에 잤어요? ➔ 새벽 3시에 잤어요」，釐清韓語一天時段劃分（새벽, 아침, 점심, 저녁, 밤）；並掌握母音脫落與合流不規則形容詞「쓰다 ➔ 너무 써요（好苦）」與「시다 ➔ 너무 셔요（好酸）」。

⏳ 第一單元：核心文法解析（韓語過去時態 -았/었/했어요 & 名詞 이었어요/였어요）

文法公式

動詞與形容詞的過去時態（과거시제）：語幹 + -았/었/했어요

判斷方式與現在式「-아/어요」完全相同，端看動詞或形容詞語幹最後一個字的母音：

規則 1：陽性母音
母音為 ㅏ, ㅗ ➔ +았어요
  • 가다 (去) ➔ 갔어요
  • 사다 (買) ➔ 샀어요
  • 보다 (看) ➔ 봤어요
  • 좋다 (好) ➔ 좋았어요
  • 자다 (睡) ➔ 잤어요
規則 2：陰性母音
母音非 ㅏ, ㅗ ➔ +었어요
  • 먹다 (吃) ➔ 먹었어요
  • 읽다 (讀) ➔ 읽었어요
  • 맛있다 (好吃) ➔ 맛있었어요
  • 배우다 (學) ➔ 배웠어요
  • 바쁘다 (忙) ➔ 바빴어요 (ㅡ脫落)
規則 3：하다 動詞/形容詞
하다 ➔ 했어요
  • 좋아하다 ➔ 좋아했어요
  • 일하다 ➔ 일했어요
  • 공부하다 ➔ 공부했어요
  • 전화하다 ➔ 전화했어요
  • 피곤하다 ➔ 피곤했어요
重點難點

名詞的過去式：이다 (是) ➔ -이었어요 / -였어요

現在式是「이에요 / 예요」，那「過去是…」或「那時多少錢」該怎麼說呢？請依照名詞是否有收音區分：

有收音名詞 + 이었어요 받침 O
  • 선생님 + 이었어요 ➔ 선생님이었어요

    過去曾是老師。（現在可能退休或轉職）

  • 학생 + 이었어요 ➔ 학생이었어요

    過去那時是學生。

無收音名詞 + 였어요 받침 X
  • 얼마 + 였어요 ➔ 얼마였어요?

    （問過去買的價格）那時候是多少錢呢？

  • 의사 + 였어요 ➔ 의사였어요

    過去曾是醫生。

🔥 旅遊問價實戰辨析：現在 vs 過去
現場詢價 (現在式) 이거 얼마예요?

這個（現在）多少錢？

事後回憶/查帳 (過去式) 그거 얼마였어요?

那個（那時買的）是多少錢來著？

結帳詢問袋子：봉투 드릴까요? vs 봉투 드려요?

직원
봉투 드릴까요? / 봉투 드려요?

需要袋子嗎？ / 要幫您裝袋嗎？

💡 深度語氣辨析：「봉투 드려요?」是口語極常見的直爽問法；而「봉투 드릴까요?」使用了「-(으)ㄹ까요?（徵詢對方意願）」，更顯客氣親切。
손님
네, 종이봉투 하나 주세요.

好的，請給我一個紙袋。

아니요, 괜찮아요. 그냥 갈게요.

不用了，沒關係。我直接拿走就可以。

🔍 尋找冷藏飲品或食品位置：냉장고 안에 어디에 있어요?

在超商找不到某樣特定優格或飲料時，可以這樣詢問店員：

提問方式 A (強調在何處) 냉장고 안에 어디에 있어요?

在冰箱裡面的哪裡呢？

提問方式 B (口語簡潔版) 냉장고 안에 어디예요?

冰箱裡面是在哪個位置呢？

👉 店員標準回答句型：[位置]에 있어요. 例如：저쪽 안쪽에 있어요. (在那個方向的內側。)
💼

打工文化小解密：아르바이트하다 ➔ 알바해요 & 알바생

韓文的兼職/打工源自德語 Arbeit，正式寫法為「아르바이트하다」。 但在日常生活與超商等情境中，韓國年輕人 99% 都會使用口語簡稱：

알바해요. [알바해요] 我正在打工 / 我做兼職。
알바생 [알바생] 打工生 / 工讀生（알바 + 生）。

🍋 第三單元：味覺形容詞活用與不規則母音變化

在超商買了黑咖啡覺得太苦？或是吃了柳橙覺得很酸？這兩個高頻味覺形容詞在母音活用時有非常重要的音變規則：

母音 ㅡ 脫落現象

쓰다 (苦) ➔ 써요

☕

語幹結尾為母音「ㅡ」時，遇到母音開頭的語尾「-아요/어요」，母音「ㅡ」會直接脫落：
쓰 + 어요 ➔ 써요

커피가 너무 써요. 咖啡太苦了。（過去式：썼어요）
母音 ㅣ + ㅓ = ㅕ 合流

시다 (酸) ➔ 셔요

🍊

語幹母音為「ㅣ」時，與「-어요」結合會縮合為「ㅕ」：
시 + 어요 ➔ 셔요

오렌지가 너무 셔요. 柳橙太酸了。（過去式：셨어요）
💡 韓語五大基本味覺速查表
甜 달다 ➔ 달아요
鹹 짜다 ➔ 짜요
辣 맵다 ➔ 매워요
苦 쓰다 ➔ 써요
酸 시다 ➔ 셔요
