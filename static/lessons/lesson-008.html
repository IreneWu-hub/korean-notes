1. 교통 및 길 찾기 (交通與問路萬用句型)

🚇 [目的地] + 에 가려면... (如果要前往...)

🔍 文法深度解析：-(으)려면 (如果打算.../想要...)

這個文法是由 -(으)려고 하다 (打算做...) 加上 -(으)면 (如果...) 結合縮寫而成的。用來表達「假設某個意圖或目的」。
在問路或尋求建議的情境中，後面超級常搭配 -아/어야 돼요 (必須/應該)，形成：「如果想要...，就必須/應該...」的完美句型。

無收音 (直接加) 가다 ➔ 가려면 如果要去
有收音 (加上 으) 먹다 ➔ 먹으려면 如果要吃
동대문 패션 타운에 가려면
무슨 역에서 내려야 돼요?

💡 助詞小提醒： -(으)로 的用法

-(으)로 可以用來表示「往...(方向)」或「以...(方式/手段, by)」。
例如：출구로 나가요 (往出口出去)。

💡 初學者必看：這 5 個句型的通用拆解與單字筆記

這五個句型的前半段結構完全一致：[目的地] + 에(到/往) + 가려면(如果打算去)。
核心重點在於後半段的疑問詞、助詞與動詞變化 (-아/어야 돼요 = 應該/必須...)：

1. 무슨 역에서 내려야 돼요?
  • • 무슨：什麼 / 哪種 (疑問形容詞)
  • • 역 + 에서：車站 + 在/從（地點助詞，表示動作產生的地點）
  • • 내려야 돼요：내리다(下車) + -어야 돼요(應該...) ➔ 縮寫為 내려야 돼요（應該下車）
2. 뭘 타야 돼요?
  • • 뭘：무엇을 的口語縮寫（무엇 什麼 + 受詞助詞 을/를 ➔ 뭐 + ㄹ）
  • • 타야 돼요：타다(搭乘，母音是 ㅏ) + -아야 돼요(應該...) ➔ 縮寫為 타야 돼요（應該搭乘）
3. 몇 호선을 타야 돼요?
  • • 몇 호선 + 을：幾號선 (號線) + 受詞助詞（호선有收音接 을）
  • • 타야 돼요：타다(搭乘) + -아야 돼요(應該...) ➔ 應該搭乘
4. 몇 번 출구로 나가야 돼요?
  • • 몇 번 출구：幾號出口
  • • 로：方向/手段助詞 -(으)로（無收音接 로，表示「往...方向」）
  • • 나가야 돼요：나가다(出去) + -아야 돼요(應該...) ➔ 應該出去
5. 걸어서 얼마나 걸려요?
  • • 걸어서：걷다(走路，ㄷ不規則變化為 걸어) + -아서(動作方式) ➔ 走路去
  • • 얼마나：多久 / 多少
  • • 걸려요：걸리다(花費時間) + -어/아요 ➔ 花費 (時間)

2. 핵심 문법 (核心文法：義務 vs 許可)

📌 動詞變化規則 (共通套用)

這兩個核心文法都接在動詞後，且都需要經過 「母音判斷 (아/어/해)」 規則變化：

ㅏ, ㅗ 母音
加上 -아야 / -아도
가다 ➔ 가야 / 가도
其他母音 (ㅓ, ㅜ, ㅣ...)
加上 -어야 / -어도
먹다 ➔ 먹어야 / 먹어도
하다 結尾
變成 -해야 / -해도
하다 ➔ 해야 / 해도

⚠️ -아/어야 돼요 (必須/應該)

表達義務、必須做某事。常翻成「得...、要...」。
口語中常將 되다 變為 돼요。

  • 나가다 (出去) ➔ [母音ㅏ] + 아야 돼요

    나가야 돼요.

    必須出去 / 得出去。

  • 타다 (搭乘) ➔ [母音ㅏ] + 아야 돼요

    뭘 타야 돼요?

    我應該搭什麼？

✅ -아/어도 돼요? (可以...嗎？)

請求對方許可。常翻成「...也可以嗎？ / 我能...嗎？」

  • 가다 (去) ➔ [母音ㅏ] + 아도 돼요

    화장실에 가도 돼요?

    我可以去洗手間嗎？

  • 입어 보다 (試穿) ➔ [母音ㅗ] + 아도 돼요

    한번 입어 봐도 돼요?

    我可以試穿看看嗎？(보다+아도 ➔ 봐도)

🎁 實用語句拆解：請求嘗試 (試穿/試吃/試做)

當你想要求「嘗試」某件事，先將動詞變為 -아/어 보다 (試著...)，搭配 한번 (一次)，再加上許可文法 -아/어도 돼요? (可以嗎)，這就是最道地的韓語句型！

3. 상황별 회화 (情境對話)

📍 情境一：借用洗手間 (禮貌請求)
가

죄송한데 좀 급해서 화장실에 가도 돼요?

不好意思，我有點急，可以去一下洗手間嗎？

※ 發音提醒：급해서 ➔ [그패서]

나

네, 가도 돼요.

好的，可以去。

📍 情境二：連假後的閒聊 (中秋節過得好嗎？)
가

추석 잘 보냈어요? 추석 연휴 뭐 했어요?

中秋節過得好嗎？中秋連假做了什麼？

나

네, 추석 잘 보냈어요.

是的，中秋節過得很好。

가

바비큐 했어요?

有烤肉(BBQ)嗎？

나

안 했어요.

沒有烤。(안 = 主觀不去做)

💡 發音特別解析 (발음 주의)

為什麼 맛없어요 會唸成 [마덥써요]？

這是一個韓國人連音與雙收音結合的經典發音變化，拆解如下：

  1. 맛 的收音 ㅅ 在遇到有意思的名詞(없다)時，會先還原發成代表音 [ㄷ] ➔ [맏]。
  2. [맏] 碰上後面的 업，ㄷ 會連音過去 ➔ [마덥]。
  3. 업 後面的 없어요 (雙收音 ㅄ)，ㅂ發音保留，ㅅ連音到後面並硬音化 ➔ [써요]。

綜合起來，맛없어요 正確且自然的發音就是 👉 [마덥써요]
