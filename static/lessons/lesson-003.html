📖 核心文法專題 (문법 정리)

重點 1 韓語四大基礎助詞 (조사)

韓文是「黏著語」，名詞後面必須黏著「助詞」來標示它在句子裡的角色（主詞、受詞或主題）。

이 / 가
主格助詞：單純標示主詞（S）
搭配否定句型：S(이/가) 아니에요. (不是...)
은 / 는
主題助詞：標示說話的主題，帶有「強調、對比、切換話題」的功能。
例：저는 학생이에요. (我呢，是學生。)
을 / 를
受格助詞：接在動作作用的對象（受詞 O）後面。
公式：O(을/를) + V. (動詞) ➔ 커피를 좋아해요. (喜歡咖啡。)

重點 2 多功能地點助詞：에서

「에서」接在地點名詞後，有兩種常見且實用的翻譯方式：

用法 A：從... (From)
  • 어디에서 왔어요?
    你從哪裡來？
  • 저는 대만에서 왔어요.
    我從台灣來。
用法 B：在... (At) + 進行動作
  • 집에서 커피를 마셔요.
    在家裡喝咖啡。 (後面必須接動詞)

重點 3 反問與共鳴 (도 / 은,는요?)

도 (也)
取代主格或主題助詞，表達同理。
• 저도요. / 나도~ 나도~ (我也是 / 比較口語的我也是)
• 저도 대만 사람이에요. (我(也)是台灣人。)
은/는요? (那...呢？)
承接上個話題，反問對方。
• ___씨는요? (那___先生/小姐呢？)
• 선생님은요? (那老師您呢？)

💬 情境對話與禮貌用語 (상황별 대화)

📍 情境：初次見面 — 道地提問與敬語升級

雖然課本常常教「什麼(뭐)」，但對韓國成人或不熟的人直接用 뭐 會顯得不太禮貌或生硬。請熟記右側的「道地/禮貌升級版」！

直白說法 (較生硬)
이름이 뭐예요?
(名字是什麼？)
➔
禮貌升級 (推薦使用) ✨
성함이 어떻게 되세요?
(請問尊姓大名是怎麼稱呼的呢？)
直白說法 (較生硬)
국적이 뭐예요?
(國籍是什麼？)
➔
道地說法 (韓國人最常用) ✨
어느 나라 사람이에요?
(請問是哪一個國家的人呢？)
直白說法 (較生硬)
직업이 뭐예요?
(職業是什麼？)
➔
💼
道地說法 (韓國人最常用) ✨
무슨 일하세요? [무슨 닐 하세요]
(請問您從事什麼工作呢？)

📍 情境：課堂互動與道別

老師
질문이 있어요?
有問題想問嗎？
學生
아니요, 질문이 없어요.
沒有，我沒有問題。 (없어요 = 沒有)
下課
안녕히 계세요.
再見。
(對著留在原地的人說，字面意思是「請平安地留下來」。)

📚 主題分類單字與發音 (어휘 및 발음)

🧑‍💼 身分與國籍 (신분/국적)

  • 선생님 老師

  • 좋아하다 ➔ 좋아해요 喜歡

🗣️ 發音與漢字特別標註 (발음 주의)

📝
질문 [질문]
漢字詞為「質問」，發音與字面相同，意思是「問題、提問」。
⚠️
무슨 일 [무슨 닐]
當前面單字有收音 (무슨)，後面遇到「이, 야, 여, 요, 유」開頭的字 (일) 時，會產生「添加 ㄴ 音」的規則，因此發音會變成 [무슨 닐]。
