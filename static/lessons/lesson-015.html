🧭 第一單元：核心文法黃金雙璧 — 에 vs 에서 場所助詞攻略

💡

一句口訣秒分「에」與「에서」

初學韓語最容易搞混「在某地」要用 에 還是 에서！記住核心判斷法： 只要後面接「去/來/在 (가다/오다/있다)」就用 에；如果人在那個場所「做某個動作 (吃、買、看、學、做瑜珈)」，就用 에서！兩者皆不分前面名詞有無收音直接加上即可。

移動目的地 / 靜態存在

場所 + 에 가다 / 오다 / 있다

📍

• 方向移動：接在場所後，表示「去／來」某地。

• 靜態存在：搭配 있다 / 없다 表示人或物在某處。

• 가다 vs 오다 視角：以「說話者現在位置」為準！離開去遠處用 가다，朝自己這邊過來用 오다。

학교에 가요.
我去學校。（前往目的地）
우리 반에 와요.
來到我們班。（朝我方過來）
교실에 있어요.
人在教室裡。（靜態存在，無動作！）
動作發生地點

場所 + 에서 + 動詞

🏃

• 動態舞台：表示某個具體動作是在哪裡發生的（「在某地做…」）。

• 常見搭配：사요 (買)、봐요 (看)、공부해요 (讀書)、요가해요 (做瑜珈)、먹어요 (吃)。

• 特別注意：「在教室裡」用 교실에 있어요，但「在瑜珈教室做瑜珈」有動作就要換成 에서！

요가 교실에서 요가해요.
在瑜珈教室做瑜珈。
집에서 핸드폰을 봐요.
在家看手機。（보다 ➔ 봐요）
과일 가게에서 사과를 사요.
在水果店買蘋果。
課堂補充例句精選

🛍️ 採買句型：在某處買某物（에서 + 을/를 사요）

문구점에서 가방을 사요.

在文具店買包包。

문구점（文具店）＋ 에서 ／ 가방（包包）＋ 을

서점에서 연필을 사요.

在書店買鉛筆。

💡 書店也可說 책방에서（책방 = 書房／社區溫馨書店）

오늘 옷을 사요.

今天買衣服。

發音提醒：옷(單唸 [옫]) ＋ 을 連音 ➔ [오슬]

음식을 사요. / 쇼핑해요.

買食物。 / 購物逛街。

如去市場買食物：시장에서 음식을 사요.

⚡ 第二單元：ㄷ不規則變化、시키다 雙義與生活動詞拆解

必考動詞音變

🎧 「ㄷ 不規則變化」：듣다 (聽) ➔ 들어요

動詞 듣다（聽、上課）的語幹收音是「ㄷ」。當它遇到母音開頭的語尾（如現在式 -어요、過去式 -었어요）時，收音「ㄷ」會變身成為「ㄹ」：

듣다（原形） ➔ 들 + 어요 ➔ 들어요（現在式） / 들었어요（過去式）
수업을 들어요.

上課 / 聽課

例：한국어 수업을 들어요.（上韓語課）

음악을 들어요.

聽音樂

發音提醒：음악 + 을 連音 ➔ [으마글]

노래를 들어요.

聽歌（歌曲）

노래（歌，無收音）＋ 를

和／跟誰一起 + 遛狗對比

🐶 散步 vs 遛狗：助詞決定主從關係！

강아지하고 / 강아지랑 산책해요.

我「跟」小狗（一起）散步。

• 하고：接名詞後表「和、跟」，不分有無收音皆可用。
• (이)랑：口語最常用！無收音接 랑（강아지랑）、有收音接 이랑（선생님이랑）。

강아지를 산책 시켜요.

我「帶／讓」小狗散步（＝遛狗）。

搭配受詞助詞 을/를 ＋ 시키다（使役：讓…做…），意思才是道地的「遛狗」！

一詞多義 × 旅遊神句

🍽️ 시키다 雙重用法 & 📷 請人拍照神句

뭐 시켜요?

要點什麼餐？ / 要點什麼？（點餐・叫外送）

시키다 除了當「使役（讓…散步）」，在餐廳、咖啡廳或點外賣時最常用來表示「點餐、叫東西」！（뭐 = 무엇 的口語簡稱）

사진(을) 좀 찍어 주세요.

請幫我拍張照。（旅遊必備萬用金句！）

逐詞拆解：
• 사진을 찍다（拍照，을 口語常省略）
• 좀（조금 縮寫：稍微、麻煩一下，讓語氣更客氣！）
• 찍어 주세요（찍다 + -어 주다 幫我拍 + -(으)세요 請…）
口語縮寫 + 動詞活用總表

🔄 口語縮寫「걸」與本堂必背動詞活用（原形 ➔ 現在式 ➔ 過去式）

맛있는 걸 먹었어요.

吃了好吃的東西。

口語縮寫秘訣：것을 ➔ 걸（把「東西 것 + 受詞 을」縮成一個字，韓國人超愛這樣講！）
배우다

學習（배워요）

한국어를 배워요.（學韓語）

마시다

喝（마셔요）

물을 마셔요.（喝水）

보내다

傳送／寄（보내요）

메시지를 보내요.（傳訊息）

만나다

見面（만나요 / 만났어요）

친구를 만났어요.（見了朋友）

쉬다

休息（쉬어요 / 쉬었어요）

그리고 쉬었어요.（然後休息了）

전화하다 / 찍다

打電話 / 拍（照）

전화해요. / 사진을 찍어요.
